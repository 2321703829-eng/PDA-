# feat-main-4b 接入与验收说明

## 一、接入目标

本功能线用于把正式主链对象接入 Odoo 项目主业务库，重点补足：

- `logistics_base`
- `logistics_dispatch`
- `logistics.dispatch.wave`
- `logistics.dispatch.batch`
- `logistics.dispatch.waybill`
- `logistics.dispatch.waybill.order.line`

## 二、接入顺序

建议顺序：

1. 将 `feat-main-4b/addons/` 加入 `addons_path`
2. 先安装 `Logistics Base`
3. 再安装 `Logistics Dispatch`
4. 确认菜单、模型、序列、视图正常
5. 再和 `logistics_trace_core`、`logistics_trace_evidence` 联调

## 三、验收要点

- `wave / batch / waybill / order line` 主对象可正常创建
- 编号规则可正常生成
- 批次、运单、订单行关系能正确建立
- 可与留痕、证据模块形成正式主链承接关系
- 不破坏当前 `feat-image-4a` 已跑通的小程序图片链
