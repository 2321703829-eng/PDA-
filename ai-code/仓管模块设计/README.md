# 仓管模块设计

本目录用于承接基于 Odoo 的仓管模块设计资料。

当前阶段定位：

- 以`讨论稿`和`启动稿`为主
- 先收敛模块边界、对象划分、原生复用策略
- 再进入规则细化、接口定义、状态流转和落地联调

建议阅读顺序：

1. `00_导航与总纲/`
2. `01_模块设计/`
3. `02_跨模块规范/`
4. `03_落地与联调/`
5. `04_来源资料与历史草图/`
6. `05_提交包/`

目录说明：

- `00_导航与总纲/`：仓管模块启动说明、总体边界、一期范围讨论
- `01_模块设计/`：按业务模块拆分的正式设计稿
- `02_跨模块规范/`：对象、编码、状态、权限、接口等跨模块规则
- `03_落地与联调/`：P0 范围、调研清单、验证清单、联调安排
- `04_来源资料与历史草图/`：会议记录、截图、表格来源及当前理解
- `05_提交包/`：后续整理给评审或交付的正式输出
- `99_待归档/`：暂存尚未归类的材料
