# versioning

## 1. 目录目的

本目录用于集中存放当前项目与版本、tag、基线说明相关的正式文档，避免它们散落在执行规范或单次任务文档里。

适用内容包括：

- tag 命名与治理规范
- baseline / milestone / release 说明文档
- 项目阶段基线说明
- 后续版本说明模板与正式版本记录
