# docs/topic_design

`docs/topic_design/` 是专题设计体系在 `docs/` 主文档链里的正式入口层。

它的职责不是替代 `ai-code/专题设计/` 下的正文，而是把专题设计纳入统一治理口径。

## 入口职责

这里主要负责：

- 解释专题体系和 `docs/` 主体系的边界
- 指向当前专题正文入口
- 说明专题文档的分级、生效和归档口径

## 默认规则

1. 项目主基线、架构边界、正式治理规则，优先回到 `docs/`
2. 专题方案、阶段方案、验收清单、专题草图，优先放在 `专题设计/`
3. 专题结论一旦上升为系统正式基线，需要同步回灌到 `context/`、`architecture/` 或 `spec/`
