# 2026-04-18 入库单异常补充状态轻量枚举预留方案补入讨论稿

## 本次变更

更新文档：
- `仓管模块设计/00_导航与总纲/仓管模块设计启动讨论稿.md`

补充了关于异常补充状态统一枚举的当前建议：

- 一期应预留统一枚举，而不是只为 `receipt_terminated` 临时加孤立值
- 但当前不建议一开始预留过大的一组异常枚举

同时补充了当前建议一期先预留的 3 个轻量枚举：

- `terminated`
- `exception`
- `pending_action`

并补充了这 3 个枚举各自的当前建议口径，以及当前不建议一期优先预留过多异常枚举的原因。

## 变更目的

把入库单异常补充状态从“是否存在”进一步推进到“统一枚举的轻量预留范围”，为后续确定一期到底启用哪些枚举建立统一前提。
