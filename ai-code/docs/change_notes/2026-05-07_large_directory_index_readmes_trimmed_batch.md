# 第六轮大目录索引收口

## 本轮目标

继续按目录索引模板，把仍然偏长的高频入口目录批量收口成“核心文件索引版”，避免索引表继续膨胀。

## 本轮变更

1. 将以下目录从全量表格调整为“核心文件索引 + 其余文件处理规则”：
   - `专题设计/前端设计/四期前端优化设计/02_跨模块规范/01_接口与数据/`
   - `专题设计/前端设计/一期前端相关设计/00_导航与总纲/`
   - `专题设计/前端设计/四期前端优化设计/02_验收与联调/`
   - `专题设计/前端设计/三期前端优化设计/00_导航与总纲/`
   - `专题设计/前端设计/三期前端优化设计/02_验收与联调/`
   - `专题设计/前端设计/二期前端优化设计/05_提交包/`
2. 为每个目录补了“其余文件处理规则”，明确未列入核心索引的材料如何理解。
3. 统一强调高频入口优先保留阅读顺序，而不是追求把所有 `.md` 文件都堆进主表。

## 结果

- 前端专题里的几个超大或持续增长目录，现在更适合作为稳定入口阅读。
- 后续继续加文件时，可以在不破坏入口可读性的前提下持续扩容。
