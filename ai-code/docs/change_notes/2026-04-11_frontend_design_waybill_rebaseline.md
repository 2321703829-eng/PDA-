# 2026-04-11 前端相关设计运单主对象回调记录

## 变更背景

基于《Odoo19物流留痕系统运单主对象与留痕主流程设计》，前端相关设计需要进一步统一到“运单是追溯主对象、批次是聚合对象、订单退到运单内明细层”的口径。

## 本次回调范围

- `前端相关设计/后台信息架构图.md`
- `前端相关设计/后台页面改造清单.md`
- `前端相关设计/批次追溯列表页草图.md`
- `前端相关设计/批次详情页草图.md`
- `前端相关设计/页面字段清单.md`
- `前端相关设计/后台接口_查询消费清单.md`
- `前端相关设计/运单追溯列表页草图.md`
- `前端相关设计/搜索与筛选规范.md`

## 核心调整

1. 将批次页中的“关联订单 / 订单总数 / 异常单数 / 高风险订单”等表述统一回调为运单口径。
2. 将信息架构中的菜单 ID、动作 ID、页面编码从 `order` 语义切到 `waybill` 语义。
3. 将字段映射中的 `order_id`、`order_name`、`source_order_status`、`total_order_count` 等旧口径统一回调为运单口径。
4. 将接口清单中的主模型依赖从 `logistics.order` 语义回调为 `logistics.waybill` 语义，并补充历史命名兼容说明。
5. 将运单列表草图的搜索项与搜索规范重新对齐，补入店铺、司机等搜索维度。

## 结果

当前 `ai-code/前端相关设计` 目录下，面向阅读链和页面设计的核心文档已基本统一到“运单主对象”口径，后续可以继续在此基础上做字段细化、接口契约细化和实际 Odoo 视图落地设计。
