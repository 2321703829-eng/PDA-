## 文档目标

针对当前系统的下一阶段优化方向，补充一份可执行设计稿，覆盖：

- 天枢科技品牌化后台重构
- 淡紫色向蓝色系的视觉切换
- 用户可见字段命名向“天枢科技字段体系”迁移
- 隐藏 `讨论` 与 `联系人` 模块入口
- 新增首页，整合仪表盘、数据看板与系统引导
- 增强物流统计指标设计
- 将订单导入重设计为“运单 -> 客户 -> 货物”三级结构
- 标准导入模板优先方案

## 关键结论

1. “彻底摆脱 Odoo 痕迹”应优先作用于用户可见层，而不是一期直接重命名底层 ORM 技术名。
2. 首页应成为默认入口页，而仪表盘和数据看板应分别承担“工作入口”和“分析页”职责。
3. `讨论` 与 `联系人` 当前建议只隐藏入口，不删除底层依赖。
4. 订单导入建议采用“标准模板优先，自由导入兼容”的双轨方案。
5. 运单详情页后续建议重构为“运单概览 / 客户明细 / 货物明细 / 留痕与证据 / 异常处理 / 操作记录”结构。
