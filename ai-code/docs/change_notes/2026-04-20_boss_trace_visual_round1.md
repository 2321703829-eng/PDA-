# 2026-04-20 管理看板第一轮页面优化

## 目标

- 把管理看板从基础摘要页提升为三期统一视觉系统中的正式总览页。
- 让管理看板更偏“经营判断”和“异常聚焦”，避免重复做成另一张统计页。
- 统一管理看板的空态、错误态和无权限态表达。

## 本轮完成

- 页头升级为独立 hero，并补了管理层视角 badge 和工作方向说明卡。
- 风险概览摘要卡补了说明文案和语义色，形成首页层的第一层判断入口。
- 新增“重点提醒”区块，优先展示当前最值得管理层关注的异常对象。
- 新增“入口分组”区块，把异常、批次、运单三个入口集中成看板内的决策跳板。
- 新增“管理判断”分析区，把看板重心放到经营判断和异常聚焦，而不是趋势图堆叠。
- 新增责任人关注和严重级别聚合，帮助快速判断是否需要升级处理。
- 统一加载态、错误态、空态显示。
