# 2026-04-17 执行页左侧待处理表格默认排序方案补入讨论稿

## 本次变更

更新文档：
- `仓管模块设计/00_导航与总纲/仓管模块设计启动讨论稿.md`

补充了本轮已确认的内容：

- 一期执行页左侧待处理表格默认采用稳定排序
- 默认排序优先按主业务顺序，其次按明细行号
- 若无明确行号时的兜底口径
- 当前不建议作为默认排序的几类智能口径
- 默认排序与完成态、筛选之间的关系建议

## 变更目的

把执行页左侧列表的动态行为从“自动切下一条”进一步收紧到“默认排序规则”，为后续确定顶部最小筛选和搜索范围建立统一前提。

## 当前说明

本次更新仍属于讨论稿沉淀，后续还会继续细化：

- 左侧表格顶部最小筛选和搜索
- 用户主动切换排序时的行为边界
- 筛选与自动切换下一条的联动口径
