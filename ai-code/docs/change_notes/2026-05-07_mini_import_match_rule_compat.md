## Summary

### 1. 与旧 Excel 模板保持一致

已核实旧模板 `template` 表中的匹配方式本质上是：

- 用门店名称单字段做 `XLOOKUP`
- 地址是查出来的结果字段，不是参与匹配的条件

因此本轮设计同步回调为：

- 首期按名称单命中

### 2. 当前 confirm 口径

- 名称单命中：允许 confirm
- 名称多命中：不允许 confirm
- 名称无命中：不允许 confirm

### 3. 地址字段当前角色

首期地址主要用于：

- 原始数据保留
- 前端结果回显
- 后续升级为双命中规则时的预留条件
