# 2026-04-15 Tianshu Import Goods Quantity Requirement

## What Changed

- 更新 `ai-code/二期前端优化设计/2026-04-15_天枢科技物流后台品牌化重构与首页及订单导入重设计方案.md`
- 将“货物数量 / 件数”从隐含字段补充为明确的设计要求

## Why

- 原方案虽然已包含货物明细层，但“这张运单下该货物有多少”没有被强调为强制业务语义
- 物流执行、装车、签收、异常核对通常都需要明确数量口径，不能只记录货物名称、重量、体积

## Scope

- 在字段标准中补充 `货物数量 / 货物件数`
- 在运单客户子表中补充 `客户货物总数量 / 客户货物总件数`
- 在客户货物明细子表中补充 `数量 / 件数`
- 在标准导入模板中补充 `件数`
- 在校验规则与实现前确认项中补充数量口径要求

## Result

- 方案现在明确要求：
  - 货物明细必须能表达当前运单下该货物的数量
  - 在需要物流执行核对时，同时保留 `数量` 与 `件数`
  - 后续实现前需要先确认是否双字段并存
