# 2026-04-18 出库单异常边界一组结论补入讨论稿

## 本次变更

更新文档：
- `仓管模块设计/00_导航与总纲/仓管模块设计启动讨论稿.md`

补充了关于出库单异常边界的一组结论，包括：

- 一期不单独新增 `checked`
- `waiting_ship` 不开放普通回退到 `checking`
- 出库单一期需要轻量“待异常处理”视图
- 出库单详情页需要单独“异常处理信息区”
- 出库单一期异常补充状态也先只启用 `terminated`
- 拣货终止与复核终止在文案上区分、枚举不拆
- 出库单 `done` 后只预留逆向处理概念
- 发货前终止与发货后异常要分成两类处理口径

## 变更目的

把围绕出库单异常表达、异常视图和发货前后边界的讨论一次性收口进讨论稿，并为后续切换到盘点单和移位单状态机建立连续上下文。
