# 专题包跨阶段阅读顺序补充

## 本轮目标

把“核心文件索引”再往包级入口上收一层，为专题包根 `README.md` 补齐跨阶段阅读顺序，让包级入口不只介绍目录，还能直接带阅读路径。

## 本轮变更

1. 在 `专题设计/README.md` 中补充统一的跨阶段阅读顺序，明确包根、主文档清单、总纲、方案/规范/验收、历史目录的默认进入顺序。
2. 在以下专题包根 `README.md` 中补充跨阶段阅读顺序：
   - `专题设计/前端设计/README.md`
   - `专题设计/仓管设计/README.md`
   - `专题设计/企业隔离设计/README.md`
   - `专题设计/高并发优化设计/README.md`
   - `专题设计/六期后端性能优化设计/README.md`
3. 统一把包级入口从“目录说明”提升为“目录说明 + 阅读顺序入口”。

## 结果

- 进入专题包时，读者现在能先知道该包应该按什么阶段顺序阅读。
- 包级 `README` 与阶段级 `README` 的索引关系更顺了，先包级定阅读主线，再阶段级继续下钻。
