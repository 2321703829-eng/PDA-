# 2026-04-22 phase4 database design fix driver vehicle non-binding and full field coverage

## 本次调整

根据进一步确认，对《四期数据库底表设计稿 v1（第二次修正版）》修正了司机/车辆层的两个关键问题：

- 明确司机与车辆不是固定强绑定关系
- 将 `司机列表.xlsx`、`车辆列表.xlsx` 中的业务字段补齐到设计口径

## 关键修正

### 非强绑定关系收口

- 明确司机与车辆只在调度状态层、批次执行层、历史关联层形成“某时点协同关系”
- 删除会误导成固定归属的口径，例如“默认车辆”
- 将“当前绑定车辆 / 当前绑定司机”统一改为“当前协同车辆 / 当前协同司机”
- 明确 `current_vehicle_id` / `current_driver_id` 可空，且不得加固定归属唯一约束

### 字段覆盖补齐

- 补齐司机覆盖清单中的：
  - `军龄`
  - `政治面貌`
  - `婚姻状态`
  - `微信号`
  - `与司机关系`
  - `现居住地行政区`
- 补齐车辆覆盖清单中的：
  - `出厂日期`
  - `购置方式`
  - `备注`

## 设计结论

当前设计稿已经可以表达“司机和车辆按时点关联、非固定配属”的业务前提，同时司机/车辆层对两张 Excel 的业务字段已完成承接。
