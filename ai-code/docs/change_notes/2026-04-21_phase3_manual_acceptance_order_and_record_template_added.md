## 当前内容

### 1. 人工验收执行顺序

文档明确了三类内容：

1. 验收前准备
2. 推荐执行顺序
3. 每页固定动作与问题分级

推荐顺序调整为：

1. `统计图表 -> 物流工作台`
2. `管理看板 -> 司机管理`
3. `导入中心 -> 导入结果页`

这样先锁定共享 Hero、Panel、State 语言，再逐页看页面专项，更适合三期现在“共享层已搭起来、页面正在统一收口”的状态。

### 2. 逐项勾验记录模板

模板固定拆成：

1. 基本信息
2. 页面首屏
3. 筛选区与动作区
4. 摘要层与主体区
5. 状态文案
6. 窄屏与溢出
7. 页面专项项
8. 问题清单与本页结论

这样记录时能直接把“宽度 / 场景 / 优先级 / 是否阻断”一起收口，避免回扫后只留下零散聊天记录。
