# 2026-04-11 search interaction specs

## 本次变更

新增 2 份执行层规范文档：
- `ai-code/搜索与筛选规范.md`
- `ai-code/后台统一交互规范.md`

## 变更原因

前面已经有：
- 页面改造方案
- 页面清单
- 字段清单
- 动作清单
- 多份页面草图

但如果缺少统一规范，后续仍会出现：
- 页面之间的搜索口径不一致
- 同类动作命名漂移
- 列表页、详情页、时间线页、证据页的结构越做越散

因此本次补齐两类基础规范：
- 搜索与筛选规范
- 后台统一交互规范

## 设计结论

### 搜索与筛选规范
- 确立“主搜索 -> 快捷筛选 -> 高级筛选”的统一顺序
- 明确订单页、批次页、异常页、时间线页、证据页、工作台、老板页的筛选建议
- 固定常用筛选命名和默认排序口径
- 强调快捷筛选优先服务业务判断，而不只是字段过滤

### 后台统一交互规范
- 固定列表页、详情页、时间线页、证据页、看板页的结构和阅读顺序
- 统一动作命名、主动作位置、跳转逻辑、状态反馈逻辑
- 明确技术字段折叠、证据和留痕双向跳转、角色视图差异
- 强调“先读懂，再操作”的后台设计原则
