## 2026-05-07 客户种子数据可见性修正

### 背景

- 小程序原始单表导入在当前 v19 测试环境已经可以 `precheck` 通过。
- 但人工在客户列表复核时，看不到刚补入的部分客户，容易误判为“客户数据未导入”。

### 排查结论

- `192.168.0.17 / odoo_logistics_webtest_v19` 中客户数据确实已存在。
- 本次从 `小程序导入模板V1.xlsx` 补入的 3 条新建 `res.partner` 记录初始为 `customer_rank = 0`：
  - `蜜蜂优选超市（广州大学城店)24小时可收货`
  - `时光里便利超市（广州番禺万博店)`
  - `值小团（广州香江店）最晚收货 10点`
- 客户列表按“客户口径”查看时，`customer_rank = 0` 的记录通常不会出现在默认视图中，因此页面看起来像“没导进去”。

### 处理

- 已在 `192.168.0.17` 目标环境中把上述 3 条记录直接修正为 `customer_rank = 1`。
- 修正后它们可以按正常客户条件在客户列表中检索到。

### 当前判断

- 这次人工复核失败的直接原因，不是小程序导入匹配失败，也不是客户数据完全未导入，而是测试种子数据和客户列表默认筛选口径不一致。
- 后续如果继续用脚本或临时数据补客户主数据，应该同步确保：
  - `active = True`
  - `customer_rank >= 1`
  - 需要出现在客户页的记录不要只停留在“联系人但非客户”状态
