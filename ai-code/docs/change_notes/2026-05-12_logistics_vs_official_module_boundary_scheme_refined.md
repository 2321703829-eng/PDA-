# 2026-05-12 物流主线与官方业务域边界方案重构

## 本轮变更

- 重构 `ai-code/专题设计/ODOO原生模块设计/01_模块设计/2026-05-12_物流主线_vs_销售采购库存发票主线_模块边界方案.md`
- 明确“物流主线是一号主线，销售/采购/库存/发票是配套业务域主线”
- 强化 `customer_line` 与 `trace_event` 的边界表述
- 补充统一菜单与工作台原则
- 收紧官方模块与自定义模块的联动边界和风险提示

## 变更原因

- 原稿方向正确，但“并列多主线”的感觉偏强，容易让读者误读成销采存财与物流共同争夺系统主脑
- 原稿对 `customer_line` 的页面节点角色与 `trace_event` 的正式事实角色区分还不够硬
- 原稿对统一菜单、统一体验与模型职责分离的关系还可进一步收口
