## 当前结果

- 当前状态总规范已经形成三套互相分离但可交叉引用的编号口径：
  - 对象编号：`OBJ-*`
  - 主状态 / 执行记录状态编号：`ST-*`
  - 异常补充状态编号：`EST-*`

## 备注

- 当前 `EST-*` 先统一建议：
  - `EST-01 = terminated`
  - `EST-02 = exception`
  - `EST-03 = pending_action`
- 后续如需继续下钻，建议优先补：
  - `EST-*` 到数据库字段映射
  - `EST-*` 到权限矩阵映射
  - `EST-*` 到执行页提示与按钮显隐映射
