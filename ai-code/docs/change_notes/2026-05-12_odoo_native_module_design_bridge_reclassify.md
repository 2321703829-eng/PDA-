## 归类依据

这 3 份文档仍有参考价值，但当前不适合作为本项目正式模块设计主稿，主要原因：

1. 文档主线以通用 ERP 的销售、采购、库存对象为核心，不是当前项目正式主线  
   当前正式主线应以 `wave -> batch -> waybill -> customer_line -> order_line -> goods_line` 为准。

2. 文档将销售订单、采购订单、库存与往来作为第一版业务主体来展开  
   这与仓库当前“物流执行与追溯由 custom addons 承接，`sale / purchase / stock` 主要作为底座或反查对象”的口径不完全一致。

3. 文档适合作为 Odoo 原生能力复用讨论材料  
   但尚未收口到当前项目的 `waybill / customer_line / trace / evidence / exception` 对象体系。

## 准确性检查结论

- 这 3 份文档作为“通用 ERP 承接草案”基本自洽，可保留参考价值
- 但作为“当前 Odoo 19 物流项目正式模块设计”不够准确，应按 `bridge + draft` 理解
- `03_落地与联调/` 现有文件中还存在 `Odoo 18.0` 口径，因此也已在目录说明中降级为桥接参考
