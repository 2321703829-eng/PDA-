## 本次补充的重点

### 1. 权限从三层推进到四层理解

本次明确建议后续把权限整体理解为：

- 菜单权限
- 页面权限
- 动作权限
- 记录规则

其中记录规则重点控制最终“能看到哪些数据”。

### 2. 固定了记录规则的两大主维度

当前统一建议一期数据范围优先按以下两个维度收口：

- `owner_id`
- `warehouse_id`

也就是：

- 货主范围
- 仓库范围

### 3. 固定了五类角色的数据范围建议

本次进一步明确：

- 操作员不应默认看到全仓、全货主
- 主管是扩范围，不是天然全开
- 异常处理角色也仍应受货主 / 仓库边界约束
- 只读角色仍需受数据范围约束
- 管理员可作为更广范围的兜底角色

## 当前意义

这次补充后，这份权限专题已经从：

- 菜单、页面、动作三层矩阵

继续推进到了：

- 数据访问边界
