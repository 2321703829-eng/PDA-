# 2026-04-17 物流风格对齐 skill 与项目规范补充

## 本次变更

新增项目内 skill：

- `.agents/skills/logistics-style-alignment/SKILL.md`

更新项目文档：

- `AGENTS.md`

## 变更内容

新增了一个用于约束仓管与物流页面风格一致性的 skill，核心标准包括：

- 仓管页面默认参照物流模块设计
- 优先复用物流页面的信息架构、布局骨架、按钮位置、状态展示和页面节奏
- 业务差异主要体现在对象和字段层，而不是整体视觉语言层
- 新页面设计前先找最接近的物流参考页

同时把这条标准同步补入了 `ai-code/AGENTS.md`，作为项目级设计一致性规范。

## 变更目的

让后续仓管模块和物流模块在同一 Odoo 后台中保持统一风格，降低学习成本和设计漂移风险，并把“先参考物流，再设计仓管”固化为稳定工作流。
