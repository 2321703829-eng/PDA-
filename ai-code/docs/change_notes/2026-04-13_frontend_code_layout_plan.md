# 2026-04-13 前端代码目录规划

## 背景

当前项目进入前端编码准备阶段，需要明确：

- 前端代码是否应单独集中
- 是否应做完全独立前端工程
- 前端负责人在 GitHub 协作中的主要代码归属区应该在哪里

## 本次新增

- `ai-code/docs/architecture/前端代码目录规划.md`

## 核心结论

- 不建议新建完全独立于 Odoo addon 体系的前端工程
- 建议在 `custom_addons/` 下新增或明确前端承载模块，例如 `logistics_web`
- 业务基础视图保留在业务模块
- 时间线、证据、工作台、老板页等前端增强能力集中到前端承载模块
