## 本次补充的重点

### 1. 主状态与执行记录 / stock 事实的联动口径

明确了以下轻量联动原则：

- 主状态负责表达业务阶段
- 移位执行记录负责表达执行过程
- `stock.picking / stock.move / stock.move.line` 负责表达真实库内移动事实
- 状态推进应依赖真实执行事实，而不是脱离事实手工改状态

### 2. 五个主状态的联动矩阵

补充了：

- `draft`
- `waiting_execute`
- `executing`
- `done`
- `cancel`

分别与：

- 移位执行记录
- `stock.picking`
- `stock.move`
- `stock.move.line`

之间的推荐联动口径。

### 3. 列表页 / 详情页的状态展示分工

明确了：

- 列表页重点解决“识别、筛选、快速判断”
- 详情页重点解决“理解、追溯、继续处理”

并固定了以下展示原则：

- 列表页：主状态占主位，进度信息轻量补充，异常提示弱化展示
- 详情页：主状态清晰展示，执行记录和异常信息共同解释当前处理进度与问题
