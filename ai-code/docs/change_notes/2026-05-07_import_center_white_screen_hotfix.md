## 2026-05-07 导入中心白屏热修

### 现象

- 在网页导入中心打开“小程序原始单表导入”后页面白屏。

### 根因

- 前端修正小程序预校验汇总取值时，在 `import_center_action.js` 中混用了 `??` 和 `&&`，且未加括号。
- 该写法会触发浏览器端 JavaScript 语法错误，导致整个 OWL 页面无法渲染。

### 处理

- 为 `can_confirm_import` 的后备布尔表达式补充括号，避免与 `??` 混用时报语法错。
- 同步代码到 `192.168.0.17 / odoo-lite-test-v19-web`。
- 升级 `logistics_web` 并重启容器。

### 当前状态

- 白屏根因已修复。
- 需要浏览器强刷后重新加载最新前端资产。
