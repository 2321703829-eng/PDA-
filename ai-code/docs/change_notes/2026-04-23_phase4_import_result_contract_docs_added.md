## 关键收口点

- 结果页和结果回读正式改为围绕 `task_no`，不再沿用旧 `import_batch_no`。
- 主数据导入和图片导入统一进入 `import_task` 审计链，首轮主对象类型明确为 `dispatch_main` 和 `image_package`。
- 接口顶层响应码与 `import_error_line.error_code` 字段级错误码明确分层。
- 结果页固定承接任务头、行结果、字段级错误三层信息，并允许补充服务层聚合摘要字段。
