## 本次补充的重点

### 1. 字段字典与状态字段落表方式

明确了移位单一期主单字段的推荐收口：

- 身份字段
- 归属字段
- 主状态字段
- 业务基础字段
- 轻量异常信息字段
- 审计字段

并固定了：

- 主状态继续由单一 `state` 字段承载
- 失败说明先由轻量问题字段承接
- 不把失败细节和部分完成反向堆进主状态字段

### 2. 轻量异常字段口径

明确了移位单一期异常信息建议先用以下轻量字段承接：

- `issue_reason`
- `issue_remark`
- `issue_by`
- `issue_at`

用于支撑详情页的轻量异常信息区，而不急着扩成重型异常状态体系。

### 3. 与 stock 原生对象的字段级关联

固定了以下字段级映射口径：

- 主单 -> `stock.picking`
- 明细 -> `stock.move`
- 执行事实 -> `stock.move.line`

并明确建议：

- 在 `stock.picking` 上通过 `wms_relocation_id` 建立主单关联
- 在 `stock.move` 上通过 `wms_relocation_line_id` 建立明细关联
- `stock.move.line` 继续作为真实执行事实粒度，不重复维护第二套执行真相
