# 第五轮目录索引治理补充

## 本轮目标

把“目录索引版 README”的分类规则进一步制度化，并对超大目录改成“只列核心文件”的精修版，避免索引越补越长。

## 本轮变更

1. 在 `docs/spec/` 新增 `directory_index_readme_template.md`，统一目录索引版 `README.md` 的适用场景、分类规则、长度规则和大目录模板。
2. 在 `design_document_governance_spec.md` 中补充目录索引版 `README` 的正式规则，明确何时应从全量表格切换为核心索引模式。
3. 在 `document_directory_governance.md` 中补充目录索引检查项，要求超大目录优先采用“核心文件索引 + 其余文件处理规则”。
4. 将以下目录改为精修版索引：
   - `专题设计/前端设计/四期前端优化设计/01_专题方案/`
   - `专题设计/前端设计/二期前端优化设计/02_跨模块规范/01_接口与数据/`
   - `专题设计/前端设计/一期前端相关设计/04_来源资料与历史草图/03_页面草图与旧清单/`

## 结果

- 目录索引版 `README` 现在不仅有样例，也有正式模板。
- 超大目录不再要求把所有 `.md` 文件硬塞进表格，入口可读性更稳定。
- 后续继续扩展专题文档时，可以按统一模板控制索引长度。
