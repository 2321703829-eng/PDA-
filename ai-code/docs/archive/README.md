# docs/archive

`docs/archive/` 是设计文件历史归档规则入口。

本目录当前先承接“归档规则与归档口径说明”，不在本轮强制集中搬运全部历史文件。

## 当前归档现实

项目里的历史资料目前主要分散在这些位置：

- `专题设计/*/04_来源资料与历史草图/`
- `专题设计/*/99_待归档/`
- `docs/change_notes/`
- `docs/architecture/` 下的 `bridge` 文档
- `ai-code/.safety_backups/`

## 当前归档原则

1. 历史资料可以暂时保留在原位置
2. 但必须被明确标识为历史参考，不得伪装成当前正式入口
3. 现行主入口必须优先指向正式基线，不把历史稿挂在默认阅读链前面
4. 后续如做物理归并，应优先迁移“已失效但仍高频误读”的文档

## 适合进入归档层的内容

- 旧版草图
- 已废弃方案
- 已执行完的临时迁移计划
- 历史目录退场说明
- 来源材料与旧截图

## 暂不建议立即物理迁移的内容

- 仍被当前主入口大量引用的历史文件
- 尚未补桥接说明的旧方案
- 还需要被频繁追溯的阶段性提交包
