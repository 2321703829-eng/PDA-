# 专题设计旧兼容目录退场方案

> 状态说明：
> - 本方案已执行完成。
> - 4 个旧兼容目录已移除。
> - 当前如需理解迁移前后路径关系，请优先参考 `topic_design_repo_wide_trace_notice.md`。

## 1. 目标

在不破坏历史留痕的前提下，计划并执行移除以下 4 个旧兼容目录：

- `前端设计/`
- `仓管模块设计/`
- `企业分离功能文件夹/`
- `高并发承载能力优化设计/`

这些目录在执行期内曾只保留单个 `README.md` 作为迁移过渡入口，当前已完成删除。

## 2. 执行后状态

当前正式专题根目录已经统一为：

- `专题设计/前端设计/`
- `专题设计/仓管设计/`
- `专题设计/企业隔离设计/`
- `专题设计/高并发优化设计/`

当前正式导航已经完成切换：

- 仓库根入口：`README.md`
- 主文档入口：`docs/README.md`
- 专题统一入口：`专题设计/README.md`
- 仓库级专题总表：`专题包导航总表.md`

## 3. 退场原则

1. 旧兼容目录不再新增任何正文。
2. 现行文档、现行入口、现行专题正文不再把旧兼容目录作为默认路径。
3. 历史 `docs/change_notes/`、已执行方案、历史治理记录允许保留旧目录名与旧路径，作为迁移留痕。
4. 只有在确认旧兼容目录不再承担实际导航职责后，才删除目录本身。

## 4. 允许保留的历史留痕

以下内容允许继续出现旧目录名：

- `docs/change_notes/`
- `docs/dev/topic_design_physical_reorg_execution_plan.md`
- 已执行留档、历史治理记录、迁移映射说明
- 明确标记为 `archive`、`draft` 或历史背景说明的文档

以下内容不应再使用旧兼容目录作为现行入口：

- `README.md`
- `docs/README.md`
- `专题设计/README.md`
- `专题包导航总表.md`
- `docs/context/`
- `docs/architecture/`
- `docs/dev/`
- `专题设计/` 下现行专题正文

## 5. 退场触发条件

满足以下条件后，可以正式删除这 4 个旧兼容目录：

1. 4 个旧目录都只剩 `README.md`，且内容明确标记为兼容跳转。
2. 主入口、`docs/` 入口、专题入口都只指向 `专题设计/`。
3. 全仓回扫后，旧目录路径只剩历史留痕用途，不再出现在现行入口与现行正文中。
4. 已保留一份统一的全仓留痕说明，用于解释迁移前后路径关系。

## 6. 实际执行顺序

1. 先保留旧目录 `README.md` 一段治理过渡期。
2. 在该过渡期内，只允许修现行入口，不再回补旧目录内容。
3. 用 `rg` 做最后一轮回扫，确认旧目录路径只出现在历史留痕与退场说明中。
4. 删除 4 个旧兼容目录。
5. 在 `docs/change_notes/` 中补一条正式“旧兼容目录已移除”留痕。

## 7. 建议验收命令

```powershell
rg -n --fixed-strings "前端设计/" README.md docs 专题设计 专题包导航总表.md --glob '*.md'
rg -n --fixed-strings "仓管模块设计/" README.md docs 专题设计 专题包导航总表.md --glob '*.md'
rg -n --fixed-strings "企业分离功能文件夹/" README.md docs 专题设计 专题包导航总表.md --glob '*.md'
rg -n --fixed-strings "高并发承载能力优化设计/" README.md docs 专题设计 专题包导航总表.md --glob '*.md'
```

验收口径：

- 在现行入口与现行正文里，不应再把这些旧目录作为当前推荐路径。
- 在 `docs/change_notes/`、迁移方案、历史治理记录里保留旧路径，视为正常。

## 8. 删除后的最终状态

删除完成后，仓库的专题设计目录只保留：

```text
专题设计/
  前端设计/
  仓管设计/
  企业隔离设计/
  高并发优化设计/
```

此时旧目录路径只作为历史留痕出现在文档中，不再作为真实目录存在。
