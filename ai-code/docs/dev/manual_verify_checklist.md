# Manual Verify Checklist

## 1. 目的

给后续每次开发提供一份可以直接照着执行的人工检查清单，避免只说“已验证”但没有实际验证路径。

## 2. 通用检查

- 模块能安装或升级
- 菜单能打开
- 列表页正常
- 表单页正常
- 搜索视图正常
- 无明显 `AccessError`
- chatter、附件、活动功能正常

## 3. 订单检查

- 能创建订单
- 订单编号正常生成
- 客户、门店、仓库、责任人可选
- 订单状态能按预期流转
- 列表能按客户、状态、责任人筛选

## 4. 留痕检查

- 可从订单进入留痕
- 可创建多条留痕
- 节点类型可选
- 附件可上传
- 留痕时间和提交人可见
- 签收类留痕录入正常

## 5. 异常检查

- 可从订单创建异常
- 异常类型可选
- 异常状态可流转
- 附件可上传
- 可看到上报人和处理状态

## 6. 主数据检查

### 客户 / 门店

- 客户可正常维护
- 门店可归属到客户
- 地址和联系方式正常展示

### 工作人员

- 岗位类型可区分
- 能关联到订单、留痕、异常

### 仓库

- 订单可选择仓库
- 仓库显示名称和编码正常

## 7. 权限检查

- 管理角色可查看全部
- 执行角色可录留痕与异常
- 非授权角色不会越权访问

## 8. 文档检查

完成代码改动后，检查：

- 是否补写 `change_notes`
- 是否需要同步 `docs/context`
- 是否需要同步 `ARCHITECTURE.md`
- 是否需要同步 `doc_sync.md`
