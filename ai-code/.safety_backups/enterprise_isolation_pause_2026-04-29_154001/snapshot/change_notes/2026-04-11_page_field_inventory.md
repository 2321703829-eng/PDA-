# 2026-04-11 页面字段清单

## 本次新增

新增文件：
- `ai-code/页面字段清单.md`

## 主要内容

- 按页面拆出字段清单
- 将字段分成：
  - 必看字段
  - 摘要字段
  - 可折叠字段
  - 技术字段
- 覆盖 P0 页面：
  - 订单追溯列表页
  - 订单详情页
  - 留痕时间线区
  - 证据查看区
- 覆盖 P1 页面：
  - 批次追溯列表页
  - 批次详情页
  - 当前异常列表页
  - 异常详情页
  - 管理工作台
- 预留 P2 页面字段口径
- 明确哪些字段不建议默认主展示

## 作用

该文档可直接作为：
- 页面草图设计依据
- Odoo 视图字段落位依据
- 页面动作清单的上游输入
