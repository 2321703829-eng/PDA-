# 2026-04-10 管理员后台界面改造方案

## 本次新增

新增文件：
- `ai-code/管理员后台界面改造方案.md`

## 主要内容

- 明确管理员后台的目标不是泛后台改造，而是追溯与判断后台
- 以“当前状态层 / 留痕事实层 / 图片证据层”组织页面结构
- 给出后台信息架构建议
- 明确 P0 / P1 / P2 页面优先级
- 定义订单追溯列表页、订单详情页、时间线区、证据区、异常页的设计要点
- 明确搜索筛选、动作规范、后端依赖和 Odoo 落地方式

## 作用

该方案可作为后续以下工作的直接上游：
- 后台信息架构图
- 后台页面改造清单
- 页面字段清单
- 页面动作清单
- Odoo 后台视图落地设计
