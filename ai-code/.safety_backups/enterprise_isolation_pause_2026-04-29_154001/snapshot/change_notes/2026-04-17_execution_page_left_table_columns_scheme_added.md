# 2026-04-17 执行页左侧表格列结构方案补入讨论稿

## 本次变更

更新文档：
- `仓管模块设计/00_导航与总纲/仓管模块设计启动讨论稿.md`

补充了本轮已确认的内容：

- 左侧待处理表格采用 `统一基础列骨架 + 各页面补充少量业务专属列`
- 不建议四个执行页完全共用一套无差异列结构
- 也不建议四个执行页完全各自独立设计列结构
- 当前统一基础列建议
- `收货 / 上架 / 拣货 / 复核` 四类执行页的专属补充列建议

## 变更目的

把执行页左侧待处理区从“表格组件形态”进一步收紧到“列结构组织方式”，为后续细化常驻列、折叠列和次级信息承载方式建立统一前提。

## 当前说明

本次更新仍属于讨论稿沉淀，后续还会继续细化：

- 哪些列必须常驻展示
- 哪些列更适合折叠或次级信息
- 左侧表格在不同屏宽下的展示优先级
