# 2026-04-13 业务单据前端接入草案完成

## 本次变更

新增文档：

- `前端相关设计/业务单据前端接入设计草案.md`

## 变更目的

根据 `前端设计新工作计划安排.md` 第四阶段安排，补齐 `业务单据` 模块的正式前端接入设计，明确：

- 哪些业务单据页面直接复用 Odoo 原生入口
- 哪些地方需要增加 Smart Button、摘要字段和反查入口
- 销售订单、采购订单、出入库单据如何跳到批次、运单、追溯主链
- 业务单据页承担哪些入口职责，不承担哪些主阅读职责

## 本次收口结论

1. `业务单据` 继续定位为业务来源层和反查入口层
2. `sale.order`、`purchase.order`、`stock.picking` 都不是物流执行主对象
3. 业务单据接入以复用 Odoo 原生单据页为主，不重做整页
4. `sale.order` 优先连接 `运单`，`purchase.order` 优先连接 `批次`
5. 单据页只做轻量摘要和跳转入口，不替代追溯主阅读页
