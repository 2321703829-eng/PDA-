## 本次补充的重点

### 1. 固定了五层校验思路

当前统一建议执行页前端联调前，至少检查：

- asset 层
- client action / registry 层
- 模板与组件层
- 文件与目录层
- 页面入口路径层

### 2. 固定了高风险点

本次明确了当前特别不建议忽略的风险点：

- JS / XML 不成对
- XML ID 与 tag 对不上
- 公共资源与动作页资源顺序错位
- 执行页资源散落多个模块
- 普通详情页和执行页重复维护同一套区块
