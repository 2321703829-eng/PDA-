# 2026-04-24 司机侧 Excel 导出方案新增
## Objective

- 在不改动既有司机侧 PDF 方案的前提下，补一份独立的司机侧 Excel 导出设计文件。

## Added Doc

- 新增 [四期司机侧Excel导出模块设计方案](</d:/Desktop/Odoo/ai-code/前端设计/四期前端优化设计/01_专题方案/2026-04-24_四期司机侧Excel导出模块设计方案.md>)

## Summary

- 方案已按最新讨论收口为“当天所有路线”导出，首轮主入口改成 `delivery_date`。
- Excel 文件结构已收口为“单表司机路线清单”，不再沿用多 Sheet 设计。
- 当前字段范围已收窄为 9 个核心字段：批次号、送货顺序、运单号、客户名称、门店名称、联系人、联系电话、地址、客户/门店备注。
- 文档同步补充了极简单表版 Excel 专属规则，包括冻结窗格、自动筛选、地址与备注换行、工作表命名建议。
- 文档进一步收掉了多余接口，首轮只保留 1 个直接批量导出接口，并把“创建任务 / 查询状态 / 结果下载”降为后续演进项。
- 文档同步补充了缺失 `wave_no` 时按配送日期自动生成默认波次号的过渡方案；连日期也缺失时，再按“业务日期 / 推断日期 / 导入创建日 / unknown”优先级补齐。
- 文档同时把实现拆分、实施顺序和首轮验收点一起更新到当前口径。

## Boundary

- 本次只更新文档，不改动现有 PDF 方案，也不进入编码实现。
