# 2026-04-22 phase4 database design sync customer and store profiles

## 本次调整

对《四期数据库底表设计稿 v1（第二次修正版）》补齐了此前已确认但尚未同步落稿的客户经营画像字段、门店配送画像字段，以及对应的规则层设计。

## 新增/补充对象

- 新增 `logistics_customer_profile`
  - 承接客户等级、客户状态、货到付款、内部往来单位、发票类型、注册电话、注册地址、客户序号
- 扩充 `logistics_store_profile`
  - 承接开始收货时间、截止收货时间、收货时间段、不收货时间段、违停、免费停车时长、停车费、停车位置、停车方式、卸货入口、卸货位置

## 同步补充的规则

- 在总体关系和对象分层中补入 `res.partner -> logistics_customer_profile -> logistics_store_profile` 口径
- 在底表字段覆盖说明中补入客户经营画像层与门店配送画像层覆盖范围
- 补充唯一约束、非空约束、默认值、合法性约束、首轮可执行约束
- 补充 `customer_status` 状态枚举与相关索引建议
- 补充字段来源单一原则，明确注册信息与默认送货信息分层
- 补充导入日志、操作日志、数据修复日志、敏感字段权限边界

## 设计结论

客户经营属性与门店配送规则已经和司机/车辆三层设计一起收口到稳定的主数据/画像层，不再只停留在字段名层面。
