# 2026-04-22 phase4 database design add delivery week flags

## 本次调整

在《四期数据库底表设计稿 v1（第二次修正版）》中补充了“周维度配送周期”字段设计。

## 新增口径

- 导入模板层继续保留 7 个布尔字段铺开：
  - `周一配送`
  - `周二配送`
  - `周三配送`
  - `周四配送`
  - `周五配送`
  - `周六配送`
  - `周日配送`
- 数据库存储层不平铺 7 个 `0/1` 字段，统一汇总到：
  - `logistics_store_profile.delivery_week_flags`

## 首轮编码建议

- `周一配送` -> `mon`
- `周二配送` -> `tue`
- `周三配送` -> `wed`
- `周四配送` -> `thu`
- `周五配送` -> `fri`
- `周六配送` -> `sat`
- `周日配送` -> `sun`

## 定位

- `delivery_week_flags` 表示门店长期稳定的默认配送周期画像
- 首轮用于排线和计划参考
- 首轮不作为强业务约束
- 若后续出现运单级临时覆盖需求，再补 `customer_line` 快照字段
