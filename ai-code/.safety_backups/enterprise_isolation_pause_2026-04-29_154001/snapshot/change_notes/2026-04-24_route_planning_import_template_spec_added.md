## 变更背景

- 当前正式主链导入已收口到四 Sheet：
  - `Waybill`
  - `CustomerLine`
  - `OrderLine`
  - `GoodsLine`
- 但排线作业使用的小程序输入模板本质是单表停靠点录入，不适合强行套用正式四 Sheet。
- 为避免继续混淆“正式主链导入”和“排线输入导入”，本次单独新增排线专用导入方案。

## 核心结论

- 正式主链导入继续使用四 Sheet，不变。
- 排线专用导入单独定义为单表模板。
- 首轮字段范围直接基于 [`副本小程序输入模板0424v1.xlsx`](</d:/Desktop/Odoo/ai-code/副本小程序输入模板0424v1.xlsx>) 表一，固定为 15 个字段。
- 必填口径调整为：
  - `批次号 / 运单号 / 停靠点顺序 / 门店名称 / 经度 / 纬度 / 详细地址 / 配送日期`
- `门店联系电话` 与 `仓库名称` 不再作为条件必填，只保留为选填字段。
- 模板灵活性口径调整为：
  - 字段顺序变化不影响导入
  - 允许同一工作簿存在额外工作表
  - 系统只解析排线导入目标表
- 在原设计稿中补充了 15 个字段的统一清单表：
  - `字段名 / 必填 / 校验规则 / 异常提醒`
- 排线导入首轮只服务：
  - 路线输入
  - 人工复核
  - 司机侧路线导出
- 首轮不承诺直接完成严格版正式主链建档。

## 影响范围
