## 本次补充的重点

### 1. 把执行页按钮继续拆到入口层和过程层

本次继续沿着权限专题里已经明确的：

- 执行页与详情页按钮边界
- XML / Python / JS 对象映射

往前推进，补清了：

- 哪些按钮更像 `client action` 入口控制
- 哪些更像页面容器 / `client view` 层控制
- 哪些应继续留在右侧执行组件内部

### 2. 明确了入口按钮和过程按钮不应落在同一层

本次固定：

- “开始收货 / 上架 / 拣货 / 复核”这类按钮更接近 `client action`
- “完成本次记录”更接近页面容器层
- “确认本次 / 确认并下一条”更接近右侧执行组件层

这样后面做执行页时，不会把所有按钮都硬塞到一个入口对象里。

本次还补了一张更适合直接拿来做前端分层实现的对照表，把：

- 入口按钮
- 过程按钮

分别映射到了不同的前端承载层。
