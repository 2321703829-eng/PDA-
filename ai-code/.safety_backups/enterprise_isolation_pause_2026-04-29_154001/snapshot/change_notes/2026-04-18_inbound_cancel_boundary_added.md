# 2026-04-18 入库单取消边界补入讨论稿

## 本次变更

更新文档：
- `仓管模块设计/00_导航与总纲/仓管模块设计启动讨论稿.md`

补充了入库单一期各状态下的取消边界建议：

- `draft / waiting_receipt` 允许普通取消
- `receipting` 谨慎允许，原则上不建议直接取消
- `received / putawaying / done / cancel` 不建议直接取消

同时补充了当前阶段关于入库单取消规则的统一收口：

- 一期普通取消只开放到 `draft / waiting_receipt`
- 一旦开始真实收货，后续不再走普通取消，而应转异常或特殊处理

## 变更目的

把入库单状态机从“进入/退出条件”进一步推进到“取消边界”，为后续讨论 `receipting` 阶段的终止处理方式建立统一前提。
