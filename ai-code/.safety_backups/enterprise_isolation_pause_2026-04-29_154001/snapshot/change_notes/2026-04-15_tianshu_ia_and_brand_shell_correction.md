# 2026-04-15 天枢品牌化方案信息架构与壳层纠偏

## Objective

根据最新人工验收结果，修正《天枢科技物流后台品牌化重构与首页及订单导入重设计方案》中两处关键偏差：

1. 品牌化要求必须覆盖全局壳层，彻底去除紫色残留
2. 系统全局结构应为“天枢科技首页 -> 企业一级模块”，而不是把物流内部工作区直接做成一级导航

## Current Understanding

上一版方案虽然已经提出蓝色品牌化和首页重构，但仍保留了两处不准确表达：

- 对“去 Odoo 化”的定义还不够严格，没有把 hover、active、弹层、焦点色中的紫色残留列为明确禁止项
- 导航策略仍写成“首页 / 调度中心 / 运单中心 / 留痕中心 / 证据中心 / 异常中心 / 数据看板”的一级结构，容易把物流内部工作区误当作整个系统的信息架构

## Change Notes

本次修订已写回：

- `ai-code/二期前端优化设计/2026-04-15_天枢科技物流后台品牌化重构与首页及订单导入重设计方案.md`

核心调整包括：

1. 新增“本轮新增纠偏结论”
   - 明确全局壳层不得残留淡紫色
   - 明确全局一级导航必须是企业模块，而不是物流工作区

2. 更新 `Outcome`
   - 首页改为“天枢科技首页”
   - 新增“一级导航改为企业模块导航”“首页不是纯物流首页”“全局不得残留紫色主题感”等目标状态

3. 更新 `Brand Direction`
   - 将“主页面蓝色但导航仍紫色”列为明确不允许状态
   - 将紫色 hover / active / 描边 / 弹层高亮纳入禁止项

4. 更新 `页面壳层视觉规则`
   - 顶栏及下拉层统一要求使用蓝色和中性色
   - 主导航由“物流一级导航”改为“企业一级模块 + 模块内二级工作区”

5. 重写 `Navigation Strategy`
   - 一级导航建议调整为：首页、发票、物流、车队、员工、客户与门店、数据看板、设置
   - 物流模块内部再拆：调度、运单、留痕、证据、异常、导入中心

6. 更新 `首页设计`
   - 首页定位提升为“天枢科技系统总入口”
   - 首页顶部优先展示企业模块入口，物流工作区以下沉重点区方式呈现

7. 修正文档尾部确认项与模板入口表述
   - 将“左侧主导航替代顶部应用导航”改为“企业级一级导航 + 模块内二级工作区”
   - 将“运单中心列表页”改为“物流 -> 运单列表页”

## Boundary
