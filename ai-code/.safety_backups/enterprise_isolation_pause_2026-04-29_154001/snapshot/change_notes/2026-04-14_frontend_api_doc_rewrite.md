## 重写原因

原文档存在以下问题：

- 原始内容编码异常，可读性较差
- 接口名称无法直接看出查询方式
- 字段仅列名称，缺少业务含义说明
- 未明确每个接口是通过什么信息查询的

## 本次调整重点

1. 将接口命名统一调整为可读性更强的形式：
   - `getXxxDetailById`
   - `getXxxListByCondition`
   - `getXxxItemsByWaybillId`
   - `getXxxSummaryByDateRange`

2. 为每个核心接口补充：
   - 主要用途
   - 通过什么信息查询
   - 关键请求参数

3. 为每组核心返回字段补充中文含义说明，便于：
   - 前端开发理解字段
   - 后端对齐返回结构
   - 联调和评审沟通

4. 同步补充：
   - 页面到接口映射
   - 当前最小可用接口集
   - 对后端协作的直接建议

## 当前结果

文档现在已经可以作为：

- 前端接口总览版
- 对外共享版的上层阅读入口
- 联调沟通时的快速说明文档
