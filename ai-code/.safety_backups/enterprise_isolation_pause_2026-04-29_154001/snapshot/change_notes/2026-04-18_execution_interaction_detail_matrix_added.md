## 本次补充的重点

### 1. 四类执行页按钮矩阵

明确了：

- 顶部主按钮保持统一
- 右侧主按钮保持统一
- 条件 / 次级动作按页面差异化显示

并固定了：

- 收货页重点是数量 + 批次 / 效期校验
- 上架页重点是来源位 / 目标货位
- 拣货页重点是货位 / 批次 / 数量联动
- 复核页重点是结果确认与问题备注

### 2. 四类执行页右侧常驻字段矩阵

明确了四类执行页在右侧执行区的：

- 当前项摘要常驻字段
- 主录入区常驻字段
- 条件显示 / 次级区字段

### 3. 四类执行页左侧专属列矩阵

明确了统一基础列之外，四类执行页各自最值得补充的专属列：

- 收货：条码、批次
- 上架：来源位、目标位
- 拣货：推荐货位、批次
- 复核：已拣数量参考、复核结果

### 4. 四类执行页底部 tab 关注重点矩阵

明确了：

- 四类执行页都默认打开 `进度摘要`
- 但不同执行页在次级关注重点上存在差异
