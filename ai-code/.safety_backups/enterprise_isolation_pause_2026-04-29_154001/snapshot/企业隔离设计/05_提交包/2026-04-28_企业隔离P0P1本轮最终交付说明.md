# 2026-04-28 企业隔离 `P0 / P1` 本轮最终交付说明

## 1. 文档定位

- 本文用于作为当前企业隔离专题本轮工作的最终交付说明。
- 本文面向内部汇报、阶段收口和下一轮工作承接。
- 本文不替代设计细稿、执行记录和验收清单，而是对它们做统一收口。

## 2. 本轮交付范围

本轮交付覆盖：

- `P0`：多数据库企业隔离底盘的本地最小验证闭环
- `P1`：现有物流模块租户化落地与业务主链跑通

本轮不覆盖：

- 平台库、租户主档、套餐、授权、计费
- 跨租户平台控制面
- 自动开租户、自动绑域名、自动编排
- 图片包平台化运营增强能力

## 3. 本轮统一口径

- 企业之间：数据库级隔离
- 当前先采用方案 A：`子域名 -> dbfilter -> 数据库`
- 当前 `P1` 主阅读入口：`waybill`
- 当前正式追溯主链：`waybill -> trace_event -> evidence -> exception`
- `customer_line` 当前作为结构 / 快照 / 命中辅助层，不承担当前 `P1` 主阅读入口
