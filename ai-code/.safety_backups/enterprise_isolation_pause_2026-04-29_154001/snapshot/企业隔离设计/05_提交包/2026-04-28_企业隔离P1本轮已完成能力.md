# 企业隔离 P1 本轮已完成能力

## 1. `trace / evidence / exception / waybill` 主链已经可用

- 运单页已经具备留痕、证据、异常三条主入口。
- 运单页摘要区已经能同步显示留痕数量、证据数量、进行中异常数量、最新证据时间、异常最高状态等关键信息。
- 留痕、证据、异常三块已经完成首轮联动回归，主流程可以跑通。

## 2. 留痕与证据的正式挂链已经稳定

- 留痕仍以 `trace_event` 作为正式事件对象。
- 证据仍正式挂在 `trace_event_id` 上，不改变原设计锚点。
- 运单页作为当前 `P1` 主阅读入口，已经可以稳定反开留痕、证据、异常。

## 3. 异常处理状态流已经可操作

- 异常单支持：
  - `草稿 -> 打开`
  - `打开 -> 处理中`
  - `打开 / 处理中 -> 已解决`
  - `已解决 / 处理中 -> 已关闭`
  - `草稿 / 打开 / 处理中 / 已解决 -> 已取消`
- 关闭异常前会校验 `close_summary`，避免无结论关闭。
- 异常详情页已经支持反开运单、留痕、批次、证据。

## 4. 图片包导入、命中、补链已经形成首轮可运行闭环

- 已新增图片包导入向导，可上传 ZIP 图片包。
- 已复用现有 `import_task / import_task_line / import_error_line` 审计链承接图片包任务，不另起一套导入底盘。
- 已支持按文件名规则命中运单与辅助节点信息，首轮规则为：
  - `waybill_no__scene.jpg`
  - `waybill_no__store_no__scene.jpg`
  - `waybill_no__customer_line_no__scene.jpg`
- 已支持将命中的图片正式补链到 `trace_event -> evidence`。
- 已支持导入任务列表、失败行重试、已补链证据查看。
- 已支持失败标记、待人工复核标记、错误行记录。

## 5. 首轮权限边界已经收紧到 `P1` 可用版本

- 只读用户：
  - 可看主链数据
  - 不可导入图片包
  - 不可执行图片补链重试
- 图片导入 / 现场人员：
  - 可导入图片包
  - 不可执行图片补链重试
- 调度 / 管理：
  - 可导入图片包
  - 可执行图片补链重试
- 图片审计：
  - 不可导入图片包
  - 可执行图片补链重试
