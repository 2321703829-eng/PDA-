# 2026-04-29 `P0` 发给运维的正式部署执行指令稿

## 1. 文档定位

- 本文用于把当前 `P0` 正式部署动作整理成可直接转给运维执行的简版指令稿。
- 当前默认继续采用 **方案 A：子域名 -> dbfilter -> 数据库**。
- 当前仅针对首个正式测试租户：`kebi / tenant_kebi`。

## 2. 当前固定信息

- 租户编码：`kebi`
- 数据库名：`tenant_kebi`
- 正式测试子域名：`kebi.tianshu.cn`
- 当前方案：`A`
- 目标：让 `kebi.tianshu.cn` 在正式入口下稳定命中 `tenant_kebi`

## 3. 需要运维执行的动作

### 3.1 DNS 解析

请完成：

- 为 `kebi.tianshu.cn` 增加 DNS 解析
- 解析到正式测试环境对应的反向代理入口

执行后需要回填：

- 解析记录类型
- 解析值
- 生效时间
- 验证结果

### 3.2 正式反向代理发布

请完成：

- 在正式测试环境或准生产环境发布 `kebi.tianshu.cn` 的反向代理配置
- 将该域名转发到目标 Odoo 服务
- 透传 `Host`
- 补齐 `X-Forwarded-Host`
- 补齐 `X-Forwarded-For`
- 补齐 `X-Forwarded-Proto`
- 合理设置上传大小与超时参数

最低要求：

- `kebi.tianshu.cn` 访问时只允许进入 `tenant_kebi`
- 不允许回落到其他数据库
- 不允许通过正式入口暴露数据库管理能力

参考说明：

- 详见：
  - `2026-04-29_P0方案A正式反向代理配置说明.md`

### 3.3 正式 Odoo 运行配置

请完成：

- 在正式运行配置中写入 `dbfilter`
- 当前建议值：

```text
^tenant_%d$
```

- 确认配置文件已生效
- 确认正式入口下关闭数据库列表与数据库管理入口

最低要求：

- `Host = kebi.tianshu.cn` 时只能命中 `tenant_kebi`

### 3.4 HTTPS 与证书

如果正式环境要求 HTTPS，请完成：

- 证书申请
- 证书部署
- HTTPS 跳转策略

并验证：

- 登录页可打开
- 跳转无异常
- 图片访问无异常
- 下载无异常

## 4. 运维执行后需要业务 / 实施侧做的验收

运维动作完成后，请按下面顺序执行验收：

1. 正式入口验收
2. 正式最小业务链验收
3. 正式权限验收
4. 正式备份恢复验收
5. 回填正式验收模板

对应模板：

- `2026-04-29_P0正式验收表头与回填模板.md`

## 5. 正式入口验收最低要求

- `https://kebi.tianshu.cn/web/login` 可打开
- 实际命中数据库为 `tenant_kebi`
- `/web/database/selector` 不作为正式选库入口暴露
- `/web/database/manager` 不可用
- `/web/database/list` 不可用

## 6. 正式业务最小链路最低要求

- 运单页可打开
- 留痕主链可用
- 证据主链可用
- 异常主链可用
- 导入中心入口可用

## 7. 正式权限验收最低要求

- 只读账号能看不能写
- 图片导入 / 现场人员能导图、能提留痕、不能关异常
- 调度 / 管理能完成异常处理闭环

## 8. 正式备份恢复最低要求

- 能说明如何备份数据库与 `filestore`
- 能说明如何恢复数据库与 `filestore`
- 如条件允许，恢复后租户链路仍可用
