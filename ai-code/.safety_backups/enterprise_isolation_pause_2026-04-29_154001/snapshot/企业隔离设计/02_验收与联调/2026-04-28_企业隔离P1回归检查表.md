# 2026-04-28 企业隔离 `P1` 回归检查表

## 1. 文档定位

- 本文用于在每轮提交后，快速回扫当前企业隔离 `P1` 的主阅读页、权限和联动入口。
- 本文面向当前单人推进场景，强调“短平快回扫”，不替代完整联调用例包。
- 本文默认每轮改动后至少手动过一遍高风险项。

## 2. 使用方式

建议每轮提交后按下面顺序回扫：

1. 先看 `waybill` 摘要区
2. 再看权限
3. 再看联动入口
4. 最后看异常状态流转

记录方式建议：

- `[ ]` 未检查
- `[x]` 已通过
- `[!]` 有问题待修

## 6. 联动入口回扫

### 6.1 `waybill -> trace`

- [ ] `waybill` 页可进入留痕列表
- [ ] 可进入单条 `trace_event` 详情
- [ ] 从 `trace_event` 可回跳 `waybill`

### 6.2 `waybill -> evidence`

- [ ] `waybill` 页可进入证据列表
- [ ] 可进入证据详情 / 预览页
- [ ] 从证据页可回到 `waybill`
- [ ] 如已挂 `trace_event`，可继续回读留痕上下文

### 6.3 `waybill -> exception`

- [ ] `waybill` 页可进入异常列表
- [ ] 可进入异常详情
- [ ] 从异常详情可回跳 `waybill`
- [ ] 从异常详情可打开相关 `trace_event`
- [ ] 从异常详情可打开相关证据
