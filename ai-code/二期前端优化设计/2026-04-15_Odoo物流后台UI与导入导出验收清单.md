## 一、UI本土化与中文体验验收

### 1. 工作台与管理层总览

- [ ] `运营工作台` 页面标题已显示为 `运营工作台`
- [ ] `运营工作台` 页面不再显示 `Frontend` 或其他旧英文工作台名称
- [ ] `运营工作台` 副标题读起来是业务提示语，而不是技术说明
- [ ] `运营工作台` 卡片标题显示为 `待处理异常 / 待补证据 / 风险批次 / 今日新增`
- [ ] `运营工作台` 空态文案是中文短句，并带业务语气
- [ ] `运营工作台` 错误态文案包含动作建议，例如“请刷新页面或稍后再试”
- [ ] `管理层总览` 页面标题已显示为 `管理层总览`
- [ ] `管理层总览` 页面不再显示 `Boss Trace`
- [ ] `管理层总览` 副标题强调“先看风险和异常”
- [ ] `管理层总览` 对象卡片按钮统一为 `查看异常 / 查看运单 / 查看批次`
- [ ] `管理层总览` 全页统一使用“异常”语义，不混用“争议 / 问题 / 异常”

### 2. 运单详情页

- [ ] 运单详情页页签显示为 `订单明细 / 备注 / 留痕与证据`
- [ ] 运单详情页不再出现 `Trace & Evidence`
- [ ] `留痕与证据` 页内存在三段式阅读引导
- [ ] 阅读引导顺序明确为“先看留痕 -> 再看证据 -> 最后核对异常”
- [ ] 留痕区标题显示为 `留痕时间线`
- [ ] 证据区标题显示为 `证据查看`
- [ ] 页面不再出现 `Trace Timeline` 或 `Evidence Viewer`
- [ ] 调试区标题显示为 `原始关联数据（调试）`
- [ ] 调试区仍保留，但明显弱于主阅读区

### 3. 留痕与证据体验

- [ ] 留痕筛选后会显示“共 X 条，当前筛选出 Y 条”
- [ ] 留痕无数据时显示中文业务空态文案
- [ ] 留痕筛选无结果时提示“可取消筛选继续查看”
- [ ] 证据查看区会显示当前第几张、关联哪条留痕、上传时间等摘要
- [ ] 异常相关证据会有对应提示
- [ ] 只能预览时会出现“当前仅支持预览”之类提示

### 4. 订单明细与英文残留

- [ ] 运单 `订单明细` 列头显示为 `外部单号 / 销售订单 / 出库单 / 门店 / 货物摘要 / 数量 / 明细状态`
- [ ] 页面主路径中不再出现 `External Order No / Sale Order / Stock Picking / Goods Summary / Line Status`
- [ ] 页面主路径中不再出现 `Trace & Evidence / Trace Timeline / Evidence Viewer / Frontend / Boss Trace`
- [ ] 页面整体视觉已呈现灰蓝系卡片层级，而不是 Odoo 原始淡紫默认感

- [ ] 留痕筛选反馈：通过
- [ ] 证据摘要与提示：通过

- [ ] 英文残留清理：通过
