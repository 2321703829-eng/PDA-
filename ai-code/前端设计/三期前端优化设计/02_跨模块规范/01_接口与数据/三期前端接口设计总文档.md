# 三期前端接口设计总文档

适用范围：
- 用于收口三期相较前两期新增或升级的接口设计
- 当前覆盖后台 `admin` 场景下的司机管理和统计图表两条主线

当前状态：
- 本文档是三期接口资料的总入口
- 同目录下更细的司机管理接口清单、统计图表接口清单和指标字典继续保留
- 与二期可承接收尾项相关的接口统一和导入结果页补充，继续看 `三期接口口径统一与结果页补充说明.md`

---

## 1. 文档定位

这份总文档只回答 4 个问题：

1. 三期相较一期、二期，接口层主要新增了什么
2. 哪些接口域继续复用前两期
3. 三期新增接口分别服务哪些页面和能力
4. 后端应按什么接口域拆任务和联调

---

## 2. 三期相较前两期的升级结论

### 2.1 一句话结论

三期接口升级不是重新搭一整套接口体系，而是在前两期基础上重点补齐 2 组能力：

1. 司机管理
2. 全局统计图表

同时补一小组不改变三期主线的接口收尾项：

3. 二期导入结果页页面化与接口口径统一

### 2.2 三期总体判断

| 类别 | 结论 |
| --- | --- |
| 一期、二期稳定的运单、异常、批次、导入列表与详情接口 | 继续复用 |
| 司机列表、司机画像、司机指标与趋势 | 三期新增接口 |
| 三期全局统计图表页聚合接口 | 三期新增接口 |
| 二期导入结果页页面化与接口口径统一 | 三期补充细化，不重开整套导入体系 |
| 界面系统化美化 | 当前不默认误判为必须新开接口 |

---

## 3. 复用、升级与新增总表

### 3.1 继续复用

| 接口/能力 | 三期处理方式 | 说明 |
| --- | --- | --- |
| 运单列表与详情 | 继续复用 | 统计下钻后继续进入原业务页 |
| 异常列表与详情 | 继续复用 | 异常趋势与异常类型分布图继续回到原异常域 |
| 批次列表与详情 | 继续复用 | 高风险批次排行下钻继续回原批次域 |
| 二期导入链路接口 | 继续复用 | 当前不属于三期主升级范围 |

### 3.2 三期新增接口域

| 接口域 | 三期动作 | 推荐路线 |
| --- | --- | --- |
| 司机管理 | 新增 | RPC + JSON controller |
| 全局统计图表 | 新增 | JSON controller |
| 导入结果补充与接口统一 | 补充细化 | 继续复用现有 JSON controller，必要时最小扩字段 |

## 4. 三期核心接口总表

### 4.1 司机管理域

| 接口 | 用途 | 建议路径/路线 |
| --- | --- | --- |
| `getDriverList` | 司机列表页主查询 | RPC |
| `getDriverFilterOptions` | 司机筛选项初始化 | RPC |
| `getDriverProfileOverview` | 司机画像页顶部对象头与执行概览 | `GET /api/admin/logistics/drivers/{driver_id}/profile` |
| `getDriverKpiCards` | 司机画像页 KPI 卡片 | `GET /api/admin/logistics/drivers/{driver_id}/kpis` |
| `getDriverRiskSummary` | 司机画像页风险与异常区 | `GET /api/admin/logistics/drivers/{driver_id}/risk-summary` |
| `getDriverTrendMetrics` | 司机画像页个人趋势图 | `GET /api/admin/logistics/drivers/{driver_id}/trends` |

### 4.2 全局统计图表域

| 接口 | 用途 | 建议路径/路线 |
| --- | --- | --- |
| `getStatsPageOverview` | 统计页首屏总览 | `GET /api/admin/logistics/stats/overview` |
| `getStatsTrendMetrics` | 趋势图与双指标趋势图 | `GET /api/admin/logistics/stats/trends` |
| `getStatsDistributionMetrics` | 分布图 | `GET /api/admin/logistics/stats/distributions` |
| `getStatsRankingMetrics` | 排行图与对比图 | `GET /api/admin/logistics/stats/rankings` |
| `getStatsDrilldownContext` | 下钻筛选上下文，可选 | `POST /api/admin/logistics/stats/drilldown-context` |

### 4.3 导入结果补充域

| 接口 | 用途 | 建议路径/路线 |
| --- | --- | --- |
| `getWaybillImportResult` | 导入结果查询与结果页页面化主读取 | `GET /api/admin/logistics/imports/waybill-standard/result` |
| `downloadWaybillImportErrorReport` | 结果页错误报告下载 | `GET /api/admin/logistics/imports/waybill-standard/error-report` |

说明：

- 当前优先扩现有结果查询接口，不建议为结果页页面化重开第二套导入结果接口
- 具体扩字段、命名映射和文件落位继续看 `三期接口口径统一与结果页补充说明.md`

## 5. 统一路线结论

| 场景 | 推荐路线 |
| --- | --- |
| 标准对象列表、详情读取 | RPC |
| 聚合型司机画像卡片与趋势图 | JSON controller |
| 聚合型统计图表页 | JSON controller |

统一前缀建议继续保持：

- `/api/admin/logistics/...`

## 6. 关键口径提醒

### 6.1 司机管理

- 司机按执行归属统计
- 当前不拆自有司机 / 外协司机
- 当前保留 `是否自己有车` 字段

### 6.2 统计图表

- 地区主口径统一挂在 `门店地区`
- 客户与地区统计按 `customer_line`
- 缺证据统一包含 `missing + partial`
- 全局统计页只保留 `司机月均异常率排行图`
- 司机个人趋势图继续留在司机画像页
