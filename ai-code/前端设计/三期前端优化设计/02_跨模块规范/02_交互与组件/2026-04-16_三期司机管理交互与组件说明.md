## Current Understanding

当前三期司机管理方向已经冻结了下面这些前提：

1. 司机管理是执行资源对象入口，不是普通员工详情页
2. 司机详情页第一页统一命名为 `概览`
3. 全局统计页只保留 `司机月均异常率排行图`
4. 司机个人趋势图统一转入司机画像详情页
5. 司机详情页第一版关联记录区先放 `最近运单 + 最近异常`
6. 司机页第一版不区分 `自有司机 / 外协司机`

因此本文件的核心任务，不是重新讨论对象边界，而是把这些结论变成可以直接指导页面设计和开发实现的交互规则。

## 1. 司机列表页交互规则

### 1.1 页面定位

司机列表页统一定位为：

- 查找入口
- 风险初筛入口
- 进入司机画像详情页的入口

它不承担完整分析页职责，也不承担复杂车队管理职责。

### 1.2 顶部交互区

列表页顶部固定放 3 组控件：

- 搜索框
- 筛选栏
- 刷新按钮

### 1.3 搜索规则

搜索框第一版固定支持：

- 司机姓名
- 联系方式
- 车牌号

说明：

- 搜索作为单独控件存在，不并入筛选项数量统计
- 第一版不补更复杂的高级搜索面板

### 1.4 筛选项最终清单

第一版固定保留下面 3 个筛选项：

1. `当前状态`
   - 选项建议：`全部 / 在用 / 停用`

2. `是否自己有车`
   - 选项建议：`全部 / 是 / 否`

3. `所属车辆`
   - 选项建议：按车辆下拉选择

当前暂不放入第一版的筛选项：

- 月均异常率区间
- 最近执行时间区间
- 服务地区
- 服务门店
- 异常类型

### 1.5 排序项最终清单

第一版固定支持下面 3 个排序项：

1. `最近执行时间`
2. `月均异常率`
3. `关联运单数`

默认排序冻结为：

- `最近执行时间 desc`

说明：

- 默认先看活跃司机，更符合日常管理入口心智
- 当用户切到 `月均异常率 desc` 时，列表承担风险筛查入口职责

### 1.6 列表字段

第一版固定显示下面这些字段：

- 司机姓名
- 联系方式
- 所属车辆
- 当前状态
- 最近执行时间
- 关联运单数
- 月均异常率

显示规则：

- `所属车辆` 显示为单行摘要文本，例如 `沪A12345 / 4.2米厢车`
- `月均异常率` 显示为“数值 + 风险标签”
- `最近执行时间` 超过一定时长时可做轻提醒，例如 `近 7 天无执行`

### 1.7 行内交互

列表页统一采用下面交互：

- 点击整行 -> 进入司机画像详情页
- 点击司机姓名 -> 进入司机画像详情页
- 第一版不鼓励放过多行内按钮

如需保留快捷动作，只建议保留：

- `查看画像`

### 1.8 列表页状态反馈

加载态：

- 使用表格骨架屏

空态：

- `当前没有符合条件的司机`

错误态：

- `司机列表加载失败，请刷新后重试。`

无权限态：

- `当前账号暂无查看司机管理的权限。`

## 2. 司机画像页区块与组件

司机画像详情页第一页统一命名为 `概览`，第一版固定由下面 6 个区块组成：

1. 顶部对象头
2. 核心指标带
3. 个人趋势图区
4. 执行概览区
5. 风险与异常区
6. 关联记录区

---

## 3. 顶部对象头

### 3.1 组件组成

顶部对象头建议包含下面 4 类组件：

- 页面标题组件
- 基础信息组
- 车辆摘要块
- 轻操作按钮组

### 3.2 展示内容

固定展示：

- 司机姓名
- 联系方式
- 当前状态
- 所属车辆
- 是否自己有车
- 最近执行时间
- 备注信息

### 3.3 按钮组

第一版固定建议放：

- 查看关联运单
- 查看关联异常
- 返回司机列表

### 3.4 下钻目标

- `查看关联运单` -> 当前司机的运单列表
- `查看关联异常` -> 当前司机的异常列表
- `返回司机列表` -> 返回上次筛选和排序状态下的司机列表页

### 3.5 空态 / 错误态

顶部对象头理论上不单独做区块空态。

对象不存在时：

- `当前司机不存在或已不可用。`

加载失败时：

- `当前司机信息加载失败，请返回列表后重试。`

## 4. 核心指标带

### 4.1 组件组成

核心指标带统一由 `6 张 KPI 卡片` 组成。

### 4.2 指标卡清单

1. 本月运单量
2. 月均异常率
3. 当前月签收率
4. 当前月超时率
5. 缺证据率
6. 关联异常数

### 4.3 交互规则

- 每张 KPI 卡片都支持点击下钻
- hover 和点击态必须明显
- KPI 卡片承担“信息 + 入口”双重职责

### 4.4 下钻目标

1. `本月运单量`
   - 跳到：当前司机本月运单列表

2. `月均异常率`
   - 跳到：当前司机异常运单列表

3. `当前月签收率`
   - 跳到：当前司机本月签收相关运单列表

4. `当前月超时率`
   - 跳到：当前司机本月超时运单列表

5. `缺证据率`
   - 跳到：当前司机缺证据运单列表

6. `关联异常数`
   - 跳到：当前司机异常列表

### 4.5 空态 / 错误态

空态：

- `当前暂无可展示的司机指标。`

错误态：

- `司机指标加载失败，请稍后重试。`

---

## 5. 个人趋势图区

### 5.1 组件组成

个人趋势图区由下面组件组成：

- 趋势图卡片
- 图例
- tooltip
- 图表空态占位

### 5.2 固定图表清单

1. `司机月度运单量趋势图`
2. `司机异常率趋势图`
3. `司机签收率 + 超时率双指标趋势图`

### 5.3 排布规则

- 第一行：运单量趋势图 + 异常率趋势图
- 第二行：签收率 + 超时率双指标宽图

### 5.4 交互规则

- 点趋势图时间点 -> 进入对应时间范围的下钻列表
- 双指标图支持图例开关
- 每张图顶部都应有一句小说明，告诉用户“这张图看什么”

### 5.5 下钻目标

1. `司机月度运单量趋势图`
   - 点某个月 -> 当前司机该月运单列表

2. `司机异常率趋势图`
   - 点某个月 -> 当前司机该月异常运单列表

3. `司机签收率 + 超时率双指标趋势图`
   - 点签收率点位 -> 当前司机该月签收相关运单列表
   - 点超时率点位 -> 当前司机该月超时运单列表

建议：

- 下钻页标题应保留“司机 + 时间范围”的来源感知

### 5.6 空态 / 错误态

空态：

- `当前时间范围内暂无执行数据。`

错误态：

- `趋势图加载失败，请稍后重试。`

## 6. 执行概览区

### 6.1 组件组成

执行概览区建议包含：

- 摘要统计卡组
- Top 3 标签组或简表组件

### 6.2 展示内容

固定展示：

- 关联批次数
- 关联运单总数
- 最近 30 天运单数
- 最近 30 天批次数
- 最近服务门店数
- 最近服务地区数

补充展示：

- 主要服务地区 Top 3
- 主要服务门店 Top 3
- 最近使用车辆信息

### 6.3 交互规则

- 本区以轻阅读为主，不额外堆复杂图表
- 可点击项优先跳运单列表，不优先跳新的中间分析页

### 6.4 下钻目标

- `关联运单总数` -> 当前司机运单列表
- `最近 30 天运单数` -> 当前司机近 30 天运单列表
- `主要服务地区 Top 3` -> 当前司机该地区运单列表
- `主要服务门店 Top 3` -> 当前司机该门店运单列表

当前不建议第一版强制下钻：

- 关联批次数
- 最近 30 天批次数

### 6.5 空态 / 错误态

空态：

- `当前司机还没有可统计的执行记录。`

错误态：

- `执行概览加载失败，请稍后重试。`

## 7. 风险与异常区

### 7.1 组件组成

风险与异常区建议固定由 3 部分组成：

- 风险摘要卡组
- 高频异常类型列表
- 最近异常表格

### 7.2 风险摘要卡

固定指标：

- 异常运单数
- 严重异常数
- 超时运单数
- 缺证据运单数

### 7.3 异常类型摘要

第一版建议用轻量列表，不强制上复杂饼图。

每项建议展示：

- 异常类型
- 数量
- 占比

### 7.4 最近异常表格

建议字段：

- 异常编号
- 运单号
- 异常类型
- 状态
- 上报时间
- 跳转入口

### 7.5 下钻目标

风险摘要卡下钻：

- `异常运单数` -> 当前司机异常运单列表
- `严重异常数` -> 当前司机严重异常列表
- `超时运单数` -> 当前司机超时运单列表
- `缺证据运单数` -> 当前司机缺证据运单列表

异常类型摘要下钻：

- 点某异常类型 -> 当前司机该异常类型异常列表

最近异常表格下钻：

- 点异常编号 -> 异常详情页
- 点运单号 -> 运单详情页

### 7.6 空态 / 错误态

风险摘要空态：

- `当前暂无风险相关数据。`

异常类型摘要空态：

- `当前暂无异常类型分布。`

最近异常空态：

- `当前没有关联异常。`

错误态：

- `风险与异常信息加载失败，请稍后重试。`

## 8. 关联记录区

### 8.1 组件组成

第一版确认固定由 2 个轻量表格组成：

- 最近运单表格
- 最近异常表格

### 8.2 最近运单表格

- 状态
- 配送日期
- 是否超时

### 8.3 最近异常表格

- 运单号
- 类型
- 状态
- 上报时间

### 8.4 交互规则

- 运单号 / 异常编号使用主链接样式

### 8.5 下钻目标

- 点运单号 -> 运单详情页

### 8.6 空态 / 错误态

## 9. 司机画像页统一下钻规则

统一规则如下：

1. 点顶部按钮 -> 进入关联列表
2. 点 KPI 卡片 -> 进入筛选后的运单或异常列表
3. 点趋势图时间点 -> 进入对应时间范围列表
4. 点异常类型 -> 进入对应异常列表
5. 点运单号 / 异常编号 -> 进入对象详情页

设计原则：

- 优先跳“可继续行动的列表页或详情页”
- 不优先跳抽象中间页
- 返回上一页时，应尽量保留原筛选和原阅读位置

## 10. 统一组件样式规则

### 10.1 页面层级

视觉层级统一为：

1. 页面标题
2. 区块标题
3. KPI 主数值
4. 表格正文
5. 辅助说明

### 10.2 顶部对象头样式

- 姓名作为主标题
- 联系方式、状态、车辆作为辅助信息
- 头部使用轻卡片或轻边框承载
- 按钮组控制在 2 到 3 个

### 10.3 KPI 卡片样式

- 同宽同高
- 主数值突出
- 指标名称简短
- hover 有明显可点击反馈
- 风险型指标可用轻橙 / 轻红强调，但不做整排重告警

### 10.4 趋势图卡片样式

- 使用统一图表卡容器
- 标题、副标题、图例位置统一
- 图表内边距统一
- 双指标图两条线颜色对比明显

### 10.5 表格组件样式

- 表头字重统一
- 行高统一
- 主链接列样式统一
- 状态标签尺寸统一
- 风险字段用小标签，不用大面积染色

### 10.6 风险标签样式

风险统一分 3 档：

- 低风险
- 中风险
- 高风险

颜色建议：

- 低风险：中性或浅绿色
- 中风险：橙色
- 高风险：红色

### 10.7 空态 / 错误态样式

- 空态图形轻量，不喧宾夺主
- 空态文案一句话即可
- 错误态优先区块级展示，不让整页一起失败
- 错误态需给出“重试或稍后重试”的动作提示

### 10.8 按钮样式

统一只保留 3 类：

- 主按钮
- 次按钮
- 文本按钮 / 链接按钮

司机页推荐使用：

- `查看关联运单`、`查看关联异常` -> 次按钮
- `返回司机列表`、`查看全部` -> 文本按钮 / 链接按钮

### 10.9 间距与留白

- 区块之间统一大间距
- 区块内部组件统一中间距
- KPI 卡、趋势图卡、表格容器使用统一卡片边距
