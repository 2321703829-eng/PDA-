# 三期前端落地与联调说明

适用范围：
- 三期前端优化设计从方案进入实现、联调、验收的执行说明
- 当前重点覆盖：司机管理、统计图表、界面系统化美化，以及可承接的二期收尾项

- `../00_导航与总纲/2026-04-17_Odoo物流后台三期前端优化设计总纲.md`
- `../02_跨模块规范/01_接口与数据/三期前端接口设计总文档.md`
- `三期司机管理联调与验收清单.md`
- `三期统计图表联调与验收清单.md`
- `三期导入结果页联调与验收清单.md`

---

## 1. 文档定位

这份文档用于把三期设计从“文档结论”转成“落地执行口径”。

它主要回答：

1. 三期应该先落哪些页面和接口
2. 页面和接口如何配对联调
3. 界面系统化美化应该在什么阶段介入
4. 可纳入三期的二期遗留应如何收口，而不是重新扩成独立大项目

---

## 2. 三期落地拆分原则

当前建议按 `3 条主线 + 1 组配套收尾` 推进：

1. 司机管理任务
2. 统计图表任务
3. 界面系统化美化任务
4. 二期可承接收尾任务

---

## 3. 推荐落地任务包

### 3.1 Task A. 司机管理

交付内容：

- 司机管理入口
- 司机列表页
- 司机画像详情页
- 司机相关下钻闭环

联调依赖：

- `getDriverList`
- `getDriverProfileOverview`
- `getDriverKpiCards`
- `getDriverRiskSummary`
- `getDriverTrendMetrics`

### 3.2 Task B. 全局统计图表

交付内容：

- 全局统计图表页
- 4 大分组
- `P0 8 张图`
- `P1 2 张图`
- 下钻到业务列表与对象详情

联调依赖：

- `getStatsPageOverview`
- `getStatsTrendMetrics`
- `getStatsDistributionMetrics`
- `getStatsRankingMetrics`

### 3.3 Task C. 界面系统化美化

交付内容：

- 首页顶部栏可读性修正
- 首页右上角按钮区重组
- 司机页与统计页的列表、详情和图表卡统一收口

联调依赖：

- 前端壳层和样式为主
- 当前不默认依赖新增业务接口

### 3.4 Task D. 二期可承接收尾

交付内容：

- 导入结果详情 / 回看页页面化补齐
- 二期存量接口与三期新增接口的命名/口径统一
- 与当前前端主路径直接相关的少量技术债清理

当前明确纳入范围：

- 二期导入结果页进一步页面化
- 三期接口与二期存量接口的统一收口
- `logistics_web` 中与当前主路径直接相关的 deprecated 路由和旧兼容资源清理

当前明确不纳入范围：

- 非运单对象导入中心化扩建
- 独立客户明细 / 货物明细标准模板
- 固定需求 + 临时需求体系

联调依赖：

- 继续复用二期导入中心与结果查询能力
- 如结果页页面化需要最小补口，再按最小接口补充
- 不默认新开一整套导入中心接口体系

---

## 4. 推荐实现顺序

1. 先做司机管理
2. 再做全局统计图表
3. 再做二期可承接收尾
4. 最后做界面系统化美化

说明：

- 司机管理先把新对象和画像页立住
- 统计图表再把全局分析能力立住
- 二期收尾放在主功能线之后，避免抢占三期主线节奏
- 界面美化最后统一收口，减少前面功能线返工

---

## 5. 推荐联调顺序

| 联调阶段 | 联调对象 | 重点 |
| --- | --- | --- |
| L1 | 司机管理 | 列表、画像页、趋势图区和下钻闭环 |
| L2 | 统计图表 | 4 大分组、10 张图和下钻闭环 |
| L3 | 二期可承接收尾 | 导入结果回看、接口口径统一和技术债回归 |
| L4 | 界面系统化美化 | 顶部栏、按钮区、列表密度、图表卡统一规则 |

---

## 6. P0 验收建议

当前建议优先验收下面 6 项：

1. `司机管理` 成为独立入口
2. 司机画像详情页成为三期阅读中枢
3. 全局统计图表页完成 `4` 大分组
4. 全局统计图表页完成 `P0 8 张图`
5. 首页顶部栏文字可读性问题得到修正
6. 首页右上角按钮区完成重组或明确收口方案

说明：

- 二期可承接收尾默认不强行挤入三期 `P0`
- 若其中某项直接阻断三期主路径联调，可提升为并行修复项

---

## 7. 联调前检查清单

- 页面结构与 `三期系统页面关系总览.md` 一致
- 菜单命名与 `三期前端模块结构与菜单总表.md` 一致
- 接口口径与 `三期前端接口设计总文档.md` 一致
- 司机页边界与司机管理专题一致
- 统计页图表范围与统计专题一致
- 导入结果页页面化如进入本轮实现，应与二期导入中心和结果读取口径保持一致

---

## 8. 典型联调样例建议

至少准备下面 5 类样例：

1. 活跃正常司机样例
2. 高风险司机样例
3. 高风险批次样例
4. 多地区分布样例
5. 缺证据问题集中样例
6. 导入成功 / 失败结果回看样例（如本轮同步承接二期结果页页面化）
