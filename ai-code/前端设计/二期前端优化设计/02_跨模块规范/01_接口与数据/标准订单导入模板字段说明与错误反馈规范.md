# 标准订单导入模板字段说明与错误反馈规范
适用范围：
- 二期标准导入主路径
- 当前正式模板：`TSL-IMPORT-WAYBILL-V2.xlsx`
- 当前正式入口：`物流 -> 导入中心`

当前结论：
- `V1` 单表 `CSV` 已退出二期正式样例和正式验收口径
- 当前标准模板统一为一份 `V2 XLSX`，内含 `运单 / 客户明细 / 货物明细` 三个 Sheet
- 当前预校验、正式导入、结果查询、错误报告导出均按 `V2` 口径执行

关联文档：
- `../../00_导航与总纲/2026-04-16_TSL-IMPORT-WAYBILL-V2三Sheet标准模板正式规格.md`
- `前端接口设计总文档.md`
- `controller 示例响应.md`

## 1. 模板身份

- `template_code`: `TSL-IMPORT-WAYBILL-V2`
- `template_version`: `v2`
- 标准文件名：
  - 英文列头：`TSL-IMPORT-WAYBILL-V2.xlsx`
  - 中文列头：`TSL-IMPORT-WAYBILL-V2.zh_CN.xlsx`

说明：
- 中英双版本只是列头语言不同，业务语义和字段结构一致
- 上传文件必须是 `.xlsx`
- 当前不再使用单表 `CSV` 作为正式导入模板

---

## 2. Sheet 结构

模板固定包含 3 个业务 Sheet：

1. `运单`
2. `客户明细`
3. `货物明细`

校验规则：
- 三个 Sheet 必须全部存在
- Sheet 名必须完全匹配
- 不允许缺失核心 Sheet

---

## 3. 字段清单

### 3.1 `运单` Sheet

| 字段编码 | 必填 | 说明 |
| --- | --- | --- |
| `waybill_no` | 是 | 运单号，运单层主键 |
| `batch_no` | 否 | 批次号，存在则校验主数据 |
| `wave_no` | 否 | 波次号，存在则校验主数据 |
| `delivery_date` | 否 | 配送日期，格式 `YYYY-MM-DD` |
| `warehouse_code` | 否 | 仓库编码 |
| `vehicle_no` | 否 | 车辆号 |
| `driver_name` | 否 | 司机姓名 |
| `driver_phone` | 否 | 司机电话 |
| `remark` | 否 | 运单层备注 |

### 3.2 `客户明细` Sheet

| 字段编码 | 必填 | 说明 |
| --- | --- | --- |
| `waybill_no` | 是 | 关联 `运单` Sheet |
| `customer_no` | 是 | 客户编号 |
| `customer_name` | 否 | 有值则与主数据一致校验 |
| `store_no` | 否 | 门店编号 |
| `store_name` | 否 | 有值则与主数据一致校验 |
| `delivery_remark` | 否 | 客户层配送备注 |
| `signoff_requirement` | 否 | 签收要求 |
| `customer_ref` | 否 | 客户外部参考号 |

### 3.3 `货物明细` Sheet

| 字段编码 | 必填 | 说明 |
| --- | --- | --- |
| `waybill_no` | 是 | 关联 `运单` Sheet |
| `customer_no` | 是 | 关联 `客户明细` Sheet |
| `store_no` | 否 | 建议填写，便于精确挂接 |
| `goods_code` | 否 | 货物编码 |
| `goods_name` | 是 | 货物名称 |
| `spec` | 否 | 规格 |
| `qty` | 是 | 数量，必须大于 `0` |
| `package_count` | 否 | 件数，非负整数 |
| `uom_name` | 否 | 单位 |
| `weight` | 否 | 重量，非负数 |
| `volume` | 否 | 体积，非负数 |
| `temperature_zone` | 否 | 温层，枚举值 |
| `package_type` | 否 | 包装类型 |
| `remark` | 否 | 货物层备注 |

## 4. 跨 Sheet 关联规则

### 4.1 客户明细关联运单

- `客户明细.waybill_no` 必须能在 `运单.waybill_no` 中找到
- 否则返回：
  - `WAYBILL_NOT_FOUND_IN_WAYBILL_SHEET`

### 4.2 货物明细关联客户明细

- 优先按 `waybill_no + customer_no + store_no` 关联
- 若 `store_no` 为空，则退化为 `waybill_no + customer_no`
- 否则返回：
  - `CUSTOMER_LINE_NOT_FOUND_IN_CUSTOMER_SHEET`

### 4.3 唯一性与一致性

- `运单` Sheet 中同一个 `waybill_no` 只能出现一次
- `客户明细` Sheet 中同一个 `waybill_no + customer_no + store_no` 只能出现一次
- `货物明细` Sheet 中不允许无意义重复行

## 5. 预校验规则

### 5.1 模板结构级

- `TEMPLATE_FILE_TYPE_INVALID`
- `TEMPLATE_SHEET_MISSING`
- `TEMPLATE_SHEET_EMPTY`
- `TEMPLATE_HEADER_MISMATCH`
- `TEMPLATE_CODE_INVALID`
- `TEMPLATE_VERSION_INVALID`

### 5.2 字段级

- `FIELD_REQUIRED`
- `FIELD_FORMAT_INVALID`
- `FIELD_VALUE_INVALID`
- `FIELD_ENUM_INVALID`

### 5.3 主数据匹配级

- `BATCH_NO_NOT_FOUND`
- `WAVE_NO_NOT_FOUND`
- `WAREHOUSE_CODE_NOT_FOUND`
- `CUSTOMER_NO_NOT_FOUND`
- `STORE_NO_NOT_FOUND`
- `WAYBILL_NO_ALREADY_EXISTS`

### 5.4 分层一致性级

- `WAYBILL_GROUP_CONFLICT`
- `CUSTOMER_GROUP_CONFLICT`
- `CUSTOMER_STORE_MISMATCH`
- `WAYBILL_NOT_FOUND_IN_WAYBILL_SHEET`
- `CUSTOMER_LINE_NOT_FOUND_IN_CUSTOMER_SHEET`

## 6. 错误反馈结构

预校验失败时，错误明细至少返回：

```json
{
  "sheet_name": "客户明细",
  "row_no": 2,
  "field_code": "customer_no",
  "field_label": "客户编号",
  "error_code": "CUSTOMER_NO_NOT_FOUND",
  "error_message": "客户编号不存在，请先维护客户主数据。"
}
```

错误反馈原则：
- 必须带 `sheet_name`
- 必须带 `row_no`
- 必须优先定位业务字段，而不是数据库字段
- 必须给出可执行的修正方向

---

## 7. 错误报告导出

当前错误报告下载接口：

- `GET /api/admin/logistics/imports/waybill-standard/error-report`

当前错误报告文件格式：
- `CSV`

当前列头固定为：
- `Sheet`
- `行号`
- `字段编码`
- `字段名称`
- `错误编码`
- `错误说明`

说明：
- 主模板已升级为 `XLSX`
- 错误报告当前仍使用 `CSV`，用于快速下载和复核预校验错误

---

## 8. 结果页统计字段

正式导入完成后，结果页至少返回：

- `import_batch_no`
- `status`
- `status_label`
- `created_waybill_count`
- `created_customer_line_count`
- `created_goods_line_count`
- `updated_record_count`
- `skipped_record_count`
- `failed_record_count`
- `error_report_url`
- `failure_reason`

## 9. 当前边界

- 当前正式主路径是“整单三 Sheet 导入”
- 当前客户明细页、货物明细页虽然也可进入导入中心，但下载的仍是同一份 `V2` 标准模板
- 独立的“客户明细标准模板”“货物明细标准模板”不在本期范围内
