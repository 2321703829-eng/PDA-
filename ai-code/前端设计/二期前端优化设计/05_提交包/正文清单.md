## 2. 正文阅读原则

建议阅读时遵循：

1. 先看总纲，理解二期到底改什么
2. 再看模块结构和页面关系，理解系统级组织方式
3. 再看两份专题方案，理解 UI 与导入两条专项线
4. 最后看接口、交互、权限和落地说明，确认实施口径

## 3. 当前说明

本轮正文的组织方式，与一期相比有两个区别：

1. 二期不再按“大量模块草案”作为正文主体，而是以“总纲 + 结构说明 + 专题方案 + 跨模块规范”作为正文主体
2. 二期接口资料虽然底稿很多，但正式提交时优先只引用 `二期接口设计总稿（领导阅读版）.md` 作为正文入口，避免阅读过于分散
