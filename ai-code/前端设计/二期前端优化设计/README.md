# 二期前端优化设计

本目录用于整理二期前端优化相关的正式设计资料。

整理原则参考 `前端相关设计/` 的分层方式，但按当前资料规模收口为“总纲、专题、跨模块规范、验收、样例、待归档”几层并行组织。

补充说明：

- 为对齐一期接口资料夹标准，二期新增了平行目录 `02_跨模块规范/`
- 当前已存在的 `02_验收与联调/` 为此前已归位目录，本轮不做历史重编号
- 本轮补充了部分一期中已有、二期此前缺失的说明型文件，并新增 `05_提交包/` 作为评审阅读入口

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_专题方案/`
3. `02_跨模块规范/`
4. `02_验收与联调/`
5. `03_模板与样例/`
6. `05_提交包/`
7. `99_待归档/`

## 目录说明

- `00_导航与总纲/`：二期总纲入口，用于统一品牌化、首页、导航和订单导入重设计口径
- `01_专题方案/`：按主题拆开的当前专项方案，便于独立评审和后续拆分实施
- `02_跨模块规范/`：二期相较一期的接口、字段、交互、权限等跨模块规则补充
- `02_验收与联调/`：基于专题方案整理出的人工验收单、落地说明和联调核验材料
- `03_模板与样例/`：用于验证当前导入链路的模板文件和使用说明
- `05_提交包/`：面向领导和评审的摘要与阅读顺序入口
- `99_待归档/`：暂存尚未明确归属的二期资料

## 文件关系

- `00_导航与总纲/2026-04-15_天枢科技物流后台品牌化重构与首页及订单导入重设计方案.md` 是二期目录总纲
- `00_导航与总纲/二期前端模块结构与菜单总表.md` 与 `二期系统页面关系总览.md` 用于补齐系统结构说明层
- `01_专题方案/` 下两份文档是当前已收口的专项方案，分别承接 UI 中文化与导入导出体验
- `02_跨模块规范/01_接口与数据/` 对齐一期标准建立，用于承接二期接口升级补充
- `02_跨模块规范/02_交互与组件/` 与 `03_权限与状态/` 用于补齐二期此前较薄的说明层
- `02_验收与联调/2026-04-15_Odoo物流后台UI与导入导出验收清单.md` 由两份专题方案拆解而来，`二期前端落地与联调说明.md` 则补充了执行说明
- `03_模板与样例/` 下的 V2 XLSX 样例和说明文档用于验证当前三 Sheet 标准导入链路，不代表后续更深层的业务规则扩展已全部定稿
- `05_提交包/二期评审摘要与阅读顺序.md` 适合用于汇报、评审和快速理解整包资料

## 适用边界

- 本目录当前只补结构整理、阅读入口和说明性内容
- 二期正式方案正文的业务结论、指标口径和实现策略仍以各自原文为准
- 如后续出现草稿、截图、会议纪要等临时材料，应先进入 `99_待归档/`，确认归属后再并入正式目录
