## 2. 二期落地拆分原则

当前建议按 4 类任务推进：

1. 入口与壳层任务
2. 对象阅读任务
3. 统计分析任务
4. 导入链路任务

---

## 3. 推荐落地任务包

### 3.1 Task A. 首页与企业壳层

交付内容：

- 首页主入口
- 一级导航调整
- 首页系统模块入口区
- 首页物流重点摘要区
- 最近动态区
- 角色化引导区

联调依赖：

- `getHomeOverviewSummary`
- `getHomeRecentActivities`
- `getHomeGuideByRole`

### 3.2 Task B. 运单详情三层阅读

交付内容：

- 运单详情概览区
- 客户明细页签
- 货物明细页签
- 留痕与异常区挂接

联调依赖：

- `getWaybillDetailV2`
- `getWaybillCustomerLinesByWaybill`
- `getWaybillCustomerGoodsLinesByWaybill`

### 3.3 Task C. 所有统计图表

交付内容：

- 统计总览
- 趋势图
- 排行区
- 从首页和统计页继续下钻到业务列表

联调依赖：

- `getStatsOverviewByDateRange`
- `getStatsTrendByMetric`
- `getStatsRankingByDimension`

### 3.4 Task D. 导入中心与结果页

交付内容：

- 标准模板下载入口
- 预校验页
- 正式导入
- 导入结果页
- 从结果页跳转运单详情验证

联调依赖：

- `downloadWaybillStandardTemplate`
- `precheckWaybillStandardImport`
- `confirmWaybillStandardImport`
- `getWaybillImportResult`

当前状态补充：

- `本期已落地第一轮前端闭环`
- 当前已在后台新增自定义 `导入中心` 页面，不再只依赖 Odoo 原生 `tag=import`
- 当前导入中心已支持：
  - 标准模板下载
  - 文件上传
  - 预校验结果展示
  - 正式导入确认
  - 导入结果统计展示
  - 错误报告下载
- 当前首页快捷入口、物流菜单导入入口、运单导入按钮已切到新的导入中心页面
- 当前波次 / 批次 / 留痕 / 证据 / 异常等非运单对象，仍沿用原生导入路径，不在本轮改造范围内

---

## 4. 推荐实现顺序

1. 先做运单详情三层阅读
2. 再做首页与企业壳层
3. 再做所有统计图表
4. 再做导入中心与结果页

说明：

- 运单详情三层阅读是二期数据结构升级基础
- 首页是领导和业务最先感知到的入口
- 导入链路依赖接口和错误反馈口径更完整，适合稍后推进

---

## 5. 推荐联调顺序

| 联调阶段 | 联调对象 | 重点 |
| --- | --- | --- |
| L1 | 运单详情三层阅读 | 页签结构和字段是否匹配 |
| L2 | 首页 | 摘要卡、趋势卡、动态和引导区是否稳定 |
| L3 | 所有统计图表 | 时间范围、趋势点、排行结构是否稳定 |
| L4 | 导入链路 | 模板、预校验、结果页闭环是否成立 |

---

## 6. P0 验收建议

当前建议优先验收下面 6 项：

1. 首页成为系统默认主入口
2. 一级导航改为企业模块结构
3. `所有统计图表` 独立成一级入口
4. 运单详情可直接查看客户明细和货物明细
5. 导入中心具备标准模板下载和预校验能力
6. 导入结果页能回跳运单详情验证
