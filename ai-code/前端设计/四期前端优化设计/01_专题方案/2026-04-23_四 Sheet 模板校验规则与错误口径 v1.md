# 2026-04-23 四 Sheet 模板校验规则与错误口径 v1

## 文档定位

- 本文用于冻结四期正式标准模板的预校验规则和错误口径。
- 本文基于 [四 Sheet 正式模板字段清单 v1](</d:/Desktop/Odoo/ai-code/前端设计/四期前端优化设计/01_专题方案/2026-04-23_四 Sheet 正式模板字段清单 v1.md:1>)。
- 本文只覆盖四 Sheet 正式模板：
  - `Waybill`
  - `CustomerLine`
  - `OrderLine`
  - `GoodsLine`

## Objective

- 冻结四 Sheet 模板的文件级、Sheet 级、行级、跨 Sheet 级校验规则。
- 冻结错误明细如何落到 `sheet_name / row_no / field_name / error_code / error_message`。
- 为后续预校验实现、错误报告导出、结果页展示提供统一口径。

## Benchmark

本次冻结统一以以下基线为准：

1. 正式模板结构以四 Sheet 为准。
2. 数据字段只校验“业务表头与数据库底表交集字段”。
3. 模板结构关系键例外保留：
  - `waybill_no`
  - `customer_line_no`
  - `order_line_no`
4. 错误码优先复用现有导入错误码清单；确需新增时再补充。

## OBB

### Outcome

- 预校验可以稳定判断：
  - 模板文件是否合法
  - Sheet 结构是否合法
  - 关联关系是否完整
  - 关键字段是否缺失或格式错误
  - 是否存在重复键和跨行冲突
- 错误结果可以稳定定位到：
  - 哪个 Sheet
  - 哪一行
  - 哪个字段
  - 什么错误码

### Behavior

- 文件先做模板级校验，再做 Sheet 级校验，再做跨 Sheet 关系校验。
- 所有失败统一落到错误明细，不允许只返回模糊文本。
- 同一行允许返回多条字段级错误。

### Boundary

- 本文不定义前端展示样式。
- 本文不定义每个枚举字段的最终业务字典值全集。
- 本文不处理旧三 Sheet 和单表快捷模板的规则。

## 一、错误明细结构冻结

每条错误统一输出为：

| 字段 | 说明 |
| --- | --- |
| `sheet_name` | 所在 Sheet 名 |
| `row_no` | Excel 里的实际数据行号 |
| `field_name` | 系统字段名 |
| `field_label` | 模板列头 |
| `error_code` | 错误码 |
| `error_message` | 面向业务可读的错误说明 |
| `raw_value` | 原始值，可空 |
| `mapped_value` | 映射值，可空 |

说明：

- 表头错误、模板错误这类没有实际数据行时，`row_no = 0`。
- 跨 Sheet 命中失败时，错误挂在子 Sheet 当前行，不回写父 Sheet。

## 二、模板级校验

### 2.1 文件校验

| 校验项 | 规则 | 错误码 |
| --- | --- | --- |
| 模板编码 | 必须命中当前正式模板编码 | `TEMPLATE_CODE_INVALID` |
| 模板版本 | 必须命中当前正式模板版本 | `TEMPLATE_VERSION_INVALID` |
| 文件类型 | 仅允许 `.xlsx` | `TEMPLATE_FILE_TYPE_INVALID` |
| 文件内容 | 必须可正常解析为 Excel | `PRECHECK_PARSE_FAILED` |

### 2.2 Sheet 存在性校验

必须同时存在下面 4 个 Sheet：

1. `Waybill`
2. `CustomerLine`
3. `OrderLine`
4. `GoodsLine`

缺任意一个，报：

- `TEMPLATE_SHEET_MISSING`

### 2.3 表头校验

- 每个 Sheet 都必须包含被冻结字段清单中的必填列。
- 非必填列允许缺失。
- 未识别的附加列允许保留，但首轮不参与正式映射。

错误码：

- `TEMPLATE_HEADER_MISMATCH`

### 2.4 空 Sheet 校验

- `Waybill`、`CustomerLine`、`OrderLine`、`GoodsLine` 任一 Sheet 无数据行，都视为预校验失败。

错误码：

- `TEMPLATE_SHEET_EMPTY`

## 三、通用字段校验

### 3.1 必填校验

- 冻结为必填的字段为空，报：
  - `FIELD_REQUIRED`

### 3.2 数值校验

适用字段：

- `doc_qty`
- `base_qty`
- `unit_price`
- `amount`
- `settled_amount`
- `unsettled_amount`
- `tax_amount`
- `cost_amount`
- `gross_profit`
- `gross_profit_rate`
- `unit_weight`
- `unit_volume`
- `total_weight`
- `total_volume`
- `free_parking_minutes`
- `parking_fee_per_hour`
- `upstairs_floor_count`

规则：

- 不能解析为数值：`FIELD_FORMAT_INVALID`
- 业务上不允许小于 `0` 的字段，小于 `0`：`FIELD_VALUE_INVALID`
- `doc_qty` 必须大于 `0`

### 3.3 日期校验

适用字段：

- `delivery_date`
- `doc_date`
- `audited_at`

规则：

- 首轮统一接受 `YYYY-MM-DD`
- 无法解析时，报：
  - `FIELD_FORMAT_INVALID`

### 3.4 电话字段校验

适用字段：

- `contact_phone`
- `driver_phone`
- `registered_phone`

规则：

- 首轮只做基础格式校验，不做运营商归属校验。
- 明显非法字符组合报：
  - `FIELD_FORMAT_INVALID`

### 3.5 布尔字段校验

适用字段：

- `allow_cash_on_delivery`
- `illegal_parking_flag`
- `access_alley`
- `access_handcart`
- `access_pallet_exchange`
- `access_cooler_box_exchange`
- `delivery_week_mon` 到 `delivery_week_sun`

首轮允许输入值：

- `是 / 否`
- `Y / N`
- `TRUE / FALSE`
- `1 / 0`

无法识别时，报：

- `FIELD_FORMAT_INVALID`

## 四、Sheet 级校验规则

### 4.1 `Waybill`

#### 主键规则

- `waybill_no` 文件内唯一

错误码：

- `WAYBILL_NO_DUPLICATED_IN_SHEET`

#### 行级必填

- `warehouse_code`
- `delivery_date`
- `wave_no`
- `batch_no`
- `waybill_no`

错误码：

- `FIELD_REQUIRED`

#### 主数据命中

- `warehouse_code` 必须命中仓库主数据

错误码：

- `WAREHOUSE_CODE_NOT_FOUND`

#### 跨行一致性

同一文件内：

- 相同 `batch_no` 的 `warehouse_code` 必须一致
- 相同 `batch_no` 的 `wave_no` 必须一致
- 相同 `wave_no` 的 `warehouse_code` 必须一致
- 相同 `wave_no` 的 `delivery_date` 必须一致

错误码：

- `BATCH_WAREHOUSE_CONFLICT`
- `BATCH_WAVE_CONFLICT`
- `WAVE_WAREHOUSE_CONFLICT`
- `WAVE_DATE_CONFLICT`
- `BATCH_SNAPSHOT_CONFLICT`
- `WAVE_SNAPSHOT_CONFLICT`

#### 与系统现有数据冲突

- 若当前模式为“新建主链导入”，系统已存在相同 `waybill_no`，报：
  - `WAYBILL_NO_ALREADY_EXISTS`

### 4.2 `CustomerLine`

#### 主键规则

- 同一 `waybill_no` 下，`customer_line_no` 不允许重复

错误码：

- `CUSTOMER_LINE_DUPLICATED_IN_WAYBILL`

#### 父级命中

- 每一行 `waybill_no` 都必须命中 `Waybill` Sheet

错误码：

- `WAYBILL_REFERENCE_NOT_FOUND`

#### 行级必填

- `waybill_no`
- `customer_line_no`
- `customer_name`
- `address_full`

错误码：

- `FIELD_REQUIRED`

### 4.3 `OrderLine`

#### 主键规则

- `order_line_no` 文件内唯一

错误码：

- `ORDER_LINE_NO_DUPLICATED_IN_FILE`

#### 父级命中

- `waybill_no + customer_line_no` 必须命中 `CustomerLine` Sheet

错误码：

- `CUSTOMER_LINE_REFERENCE_NOT_FOUND`

#### 订单键规则

- `source_doc_no / sales_order_no` 二选一
- 同一父节点下：
  - 若 `source_doc_no` 重复
  - 或 `sales_order_no` 重复
  且对应订单级其他字段不一致，视为冲突

错误码：

- `IMPORT_ORDER_KEY_REQUIRED`
- `ORDER_LINE_KEY_DUPLICATED_IN_PARENT`

#### 行级必填

- `order_line_no`
- `waybill_no`
- `customer_line_no`

错误码：

- `FIELD_REQUIRED`

### 4.4 `GoodsLine`

#### 父级命中

- `order_line_no` 必须命中 `OrderLine` Sheet

错误码：

- `ORDER_LINE_REFERENCE_NOT_FOUND`

#### 行级必填

- `order_line_no`
- `product_name`
- `doc_qty`

错误码：

- `FIELD_REQUIRED`
- `IMPORT_PRODUCT_NAME_REQUIRED`

#### 数值规则

- `doc_qty` 必须大于 `0`
- 其余数量、金额、重量、体积字段不得小于 `0`

错误码：

- `FIELD_FORMAT_INVALID`
- `FIELD_VALUE_INVALID`

说明：

- `GoodsLine` 首轮不做“完全相同货物行重复拦截”。
- 同一订单下允许多条商品明细，哪怕商品名称相同。

## 五、跨 Sheet 校验顺序冻结

推荐预校验顺序：

1. 文件与模板校验
2. `Waybill` 结构与主键校验
3. `CustomerLine` 结构、主键、父级校验
4. `OrderLine` 结构、主键、父级、订单键校验
5. `GoodsLine` 结构、父级、数量字段校验

说明：

- 后续步骤不覆盖前一步错误。
- 同一行可以同时存在“父级未命中”和“字段缺失”两类错误。

## 六、错误码冻结表

### 6.1 模板级错误码

| `error_code` | 场景 |
| --- | --- |
| `TEMPLATE_CODE_INVALID` | 模板编码错误 |
| `TEMPLATE_VERSION_INVALID` | 模板版本错误 |
| `TEMPLATE_FILE_TYPE_INVALID` | 文件格式错误 |
| `PRECHECK_PARSE_FAILED` | 文件无法解析 |
| `TEMPLATE_SHEET_MISSING` | 缺少必需 Sheet |
| `TEMPLATE_HEADER_MISMATCH` | 表头不匹配 |
| `TEMPLATE_SHEET_EMPTY` | Sheet 无数据 |

### 6.2 结构与关系错误码

| `error_code` | 场景 |
| --- | --- |
| `WAYBILL_NO_DUPLICATED_IN_SHEET` | `Waybill` 主键重复 |
| `CUSTOMER_LINE_DUPLICATED_IN_WAYBILL` | 同一运单下门店节点编号重复 |
| `ORDER_LINE_NO_DUPLICATED_IN_FILE` | `OrderLine` 主键重复 |
| `WAYBILL_REFERENCE_NOT_FOUND` | 子表引用的运单不存在 |
| `CUSTOMER_LINE_REFERENCE_NOT_FOUND` | `OrderLine` 引用的门店节点不存在 |
| `ORDER_LINE_REFERENCE_NOT_FOUND` | `GoodsLine` 引用的订单不存在 |
| `ORDER_LINE_KEY_DUPLICATED_IN_PARENT` | 同一父节点下订单键重复或冲突 |

### 6.3 值校验错误码

| `error_code` | 场景 |
| --- | --- |
| `FIELD_REQUIRED` | 必填值缺失 |
| `FIELD_FORMAT_INVALID` | 字段格式错误 |
| `FIELD_VALUE_INVALID` | 字段值非法 |
| `IMPORT_ORDER_KEY_REQUIRED` | 订单键缺失 |
| `IMPORT_PRODUCT_NAME_REQUIRED` | 商品名称缺失 |
| `WAREHOUSE_CODE_NOT_FOUND` | 仓库编码未命中 |
| `WAYBILL_NO_ALREADY_EXISTS` | 现有系统已存在同号运单 |
| `BATCH_WAREHOUSE_CONFLICT` | 同批次仓库冲突 |
| `BATCH_WAVE_CONFLICT` | 同批次波次冲突 |
| `WAVE_WAREHOUSE_CONFLICT` | 同波次仓库冲突 |
| `WAVE_DATE_CONFLICT` | 同波次日期冲突 |
| `BATCH_SNAPSHOT_CONFLICT` | 批次级共享字段冲突 |
| `WAVE_SNAPSHOT_CONFLICT` | 波次级共享字段冲突 |

## 七、错误文案规则

- 错误文案必须指向业务可见列头，不只写系统字段名。
- 错误文案优先说明：
  - 哪一列
  - 当前值是什么
  - 应如何修正

推荐文案模板：

1. 必填类：
   - `OrderLine 第 5 行，列“销售订单号”不能为空。`
2. 命中类：
   - `GoodsLine 第 8 行，列“订单行编号”未命中 OrderLine Sheet。`
3. 冲突类：
   - `Waybill 第 4 行，批次号“BT001”对应的仓库不一致，请统一。`

## 八、与结果页的关系

- 预校验失败时，任务头仍可创建，但 `can_confirm_import = false`
- 每条错误都应可在结果页和错误报告中回读
- 结果页统计建议支持：
  - `sheet_error_count`
  - `top_error_codes`
  - `top_error_fields`

## 九、v1 结论

- 四 Sheet 模板的预校验规则已经可以进入实现前冻结阶段。
- 后续实现不应再临时增加“拍脑袋规则”。
- 若后续要改字段、改关系键或改错误码，应先回写本文和字段清单 v1。
