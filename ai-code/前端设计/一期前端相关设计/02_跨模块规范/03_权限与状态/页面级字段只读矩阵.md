# 页面级字段只读矩阵

适用范围：
- 当前前端一期核心页面
- 主要服务页面开发时的字段渲染与编辑判断

优先基准：
- `前端权限显示与角色映射草案.md`
- `P0页面Odoo落地实现清单.md`
- `前后端接口字段级契约清单.md`

关联文档：
- `异常中心前端设计草案.md`
- `后台按波次批次运单追溯页面设计.md`
- `设置与规则模块前端设计草案.md`

---

## 1. 文档定位

这份文档是页面层的“字段是否可编辑”速查表。

它解决的是：

- 某个字段前端默认应该只读还是可编辑
- 不同角色进入同一页时，哪些区块应该锁住
- 开发时哪些表单控件可以直接做成 display-only

说明：
- 这里是前端显示矩阵
- 最终权限仍以后端权限为准

---

## 2. 角色简称

为方便阅读，以下简称统一为：

- `SA`：系统管理员
- `OM`：物流运营管理员
- `EP`：异常处理人员
- `RV`：追溯查看人员
- `BM`：老板/管理层

矩阵值说明：

- `R`：只读
- `RW`：可读可写
- `-`：默认不显示或不进入该页

## 10. 前端开发使用建议

建议按下面方式使用这份矩阵：

1. 页面初版先按矩阵控制显示态
2. 表单字段默认取最保守策略
3. 如果某字段一期其实不需要编辑，宁可先只读
4. 遇到不确定字段，不在页面层自行放开可编辑态

---

## 11. 当前最需要优先锁定的只读口径

一期建议先彻底锁死这些字段为只读：

- 所有编号类字段
- 所有事实时间字段
- 所有上传人、提交人字段
- 所有聚合摘要字段
- 所有证据元数据字段

真正允许前端编辑的先只保留：

- 运单内部备注
- 异常状态
- 异常负责人
- 处理备注
- 设置模块中的配置项
