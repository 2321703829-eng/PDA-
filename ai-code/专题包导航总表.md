# 专题包导航总表

本页用于统一列出 `docs/` 之外、当前已经归并到 `专题设计/` 下的设计专题包，作为仓库级总导航。

## 适用范围

本总表当前覆盖以下专题设计包：

- [专题设计/README.md](./专题设计/README.md)
- [前端设计](./专题设计/前端设计/README.md)
- [仓管设计](./专题设计/仓管设计/README.md)
- [企业隔离设计](./专题设计/企业隔离设计/README.md)
- [高并发优化设计](./专题设计/高并发优化设计/README.md)

不在本总表覆盖范围内的目录：

- `docs/`
- `scripts/`
- `templates/`
- `.agents/`
- `odoo-reconstruct/`
- 其他临时或工具型目录

## 与主文档体系的关系

- 项目总基线、业务边界和模块架构，仍以 [docs/README.md](./docs/README.md) 为主入口。
- 本页只负责把 `docs/` 外的专题设计包统一挂出来。
- 进入某个专题包后，再按该专题包自己的 `README.md` 继续下钻。

- 历史根目录 `前端设计/`、`仓管模块设计/`、`企业分离功能文件夹/`、`高并发承载能力优化设计/` 已完成移除。
- 这些旧根目录名只保留在迁移说明与历史留痕中，不再作为真实目录或默认阅读路径。
- 退场规则见 [docs/dev/topic_design_legacy_root_retirement_plan.md](./docs/dev/topic_design_legacy_root_retirement_plan.md)。
- 全仓历史路径口径见 [docs/dev/topic_design_repo_wide_trace_notice.md](./docs/dev/topic_design_repo_wide_trace_notice.md)。

## 统一入口模板

所有专题包根 `README.md` 统一使用以下章节结构：

1. `统一命名`
2. `专题定位`
3. `建议阅读顺序`
4. `目录/层级说明`
5. `当前推荐入口`
6. `适用边界`

## 按需求进入

- 如果要看系统正式基线，先看 [docs/README.md](./docs/README.md)。
- 如果要看分阶段页面与交互方案，先看 [前端设计](./专题设计/前端设计/README.md)。
- 如果要看仓储与库内作业专题，先看 [仓管设计](./专题设计/仓管设计/README.md)。
- 如果要看企业隔离或多租户方向，先看 [企业隔离设计](./专题设计/企业隔离设计/README.md)。
- 如果要看查询承载和热点 SQL 优化，先看 [高并发优化设计](./专题设计/高并发优化设计/README.md)。
