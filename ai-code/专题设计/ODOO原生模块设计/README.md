# ODOO原生模块设计

本目录用于承接 `Odoo` 原生模块能力调研、复用判断和第一版业务承接方案，是与 `docs/` 主文档体系并行的专题设计包入口。

## 统一命名

- 统一专题名：`ODOO原生模块设计`
- 当前物理目录：`专题设计/ODOO原生模块设计/`

## 专题定位

- 主题：围绕 Odoo 原生模块做功能覆盖盘点、现状核查、第一版业务承接和落地参考
- 当前阶段：以 ERP/WMS/TMS/BI 功能范围收口、模块边界澄清、原生模块复用与实施路径整理为主，并补充后续 `B2B` 订货商城的正式模块设计
- 与主文档体系关系：
  - 项目级业务基线仍以 `docs/context/` 与 `docs/architecture/` 为准
  - 本目录负责承接原生模块专题的专项调研、专题方案和落地参考材料

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_模块设计/`
3. `02_桥接参考/`
4. `03_落地与联调/`
5. `04_来源资料与历史草图/`

## 跨阶段阅读顺序

1. 先看 [主文档清单.md](./主文档清单.md)，确认当前主入口和文档角色。
2. 再读 `00_导航与总纲/2026-05-12_本期工作总纲.md`，先锁定本期目标、范围、模块重心和验收口径。
3. 再读 `00_导航与总纲/2026-05-12_Odoo原生功能_vs_福科目标功能差异一览表.md`，先看原生已有、需要改动和需要新增的能力总表。
4. 再读 `00_导航与总纲/` 其余文档，补足功能范围、现状对照和长期蓝图。
5. `01_模块设计/` 当前主要承接本期 ERP/WMS/TMS/BI 建设边界、原生模块启用和实施策略。
6. 销售、采购、库存与往来三个第一版业务草案当前按桥接参考理解，进入 `02_桥接参考/` 阅读。
7. 需要看部署、架构或交付参考时，再进入 `03_落地与联调/`。
8. 只有在追溯原始需求或补充来源时，再回看 `04_来源资料与历史草图/`。

- `03_落地与联调/`：系统架构和部署类落地参考材料，当前文件基于旧版 Odoo 18 环境，应按桥接参考理解
- `04_来源资料与历史草图/`：原始需求文件和补充来源材料
