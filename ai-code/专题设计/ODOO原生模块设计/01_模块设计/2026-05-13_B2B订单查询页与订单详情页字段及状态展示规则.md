## 1. Objective

细化 `B2B` 订单查询页和订单详情页的字段、状态展示、筛选规则、摘要展示和售后入口规则，作为客户查单链路的直接开发依据。

## 2. Boundary

本文件覆盖：

- `B2B` 我的订单列表页
- 订单详情页
- 订单状态展示
- 仓配摘要展示
- 收款摘要展示
- 售后入口展示规则

本文件不覆盖：

- 完整售后工单页
- 在线支付页
- 后台 ERP 审核页
- WMS / TMS 内部工作台页面

## 3. 页面目标

### 3.1 订单查询页

让客户快速完成：

- 查看自己提交过的订单
- 按状态、时间、门店搜索订单
- 识别哪些订单待审核、待发货、配送中、已签收或异常

### 3.2 订单详情页

让客户完成：

- 查看一张订单的完整商品明细
- 查看订单金额和门店信息
- 查看履约摘要
- 查看收款摘要
- 在允许场景下发起售后

## 4. 状态设计原则

### 4.1 状态来源原则

`B2B` 前台不单独维护正式订单状态机。

前台展示状态来自：

- `sale.order` 业务状态摘要
- `WMS` 作业摘要
- `TMS` 配送摘要
- `account` 收款摘要

### 4.2 B2B 前台展示状态

建议只展示客户可理解的轻量状态：

- `to_review`
  - 待审核
- `confirmed`
  - 已确认
- `to_ship`
  - 待出库
- `shipping`
  - 配送中
- `signed`
  - 已签收
- `delivery_exception`
  - 配送异常
- `cancelled`
  - 已取消

### 4.3 状态映射建议

| B2B展示状态 | 来源对象 | 判定口径 |
|---|---|---|
| 待审核 | `sale.order` | 销售单处于草稿或待审核 |
| 已确认 | `sale.order` | 已确认但尚未进入出库执行 |
| 待出库 | `sale.order + WMS` | 已确认，WMS 尚未完成出库 |
| 配送中 | `TMS` | 已交接并进入派车 / 在途 |
| 已签收 | `TMS` | 签收完成 |
| 配送异常 | `TMS / exception` | 存在未关闭配送异常 |
| 已取消 | `sale.order` | 销售单取消 |

## 5. 订单查询页设计

### 5.1 页面结构

建议分成 4 个区块：

1. 顶部筛选区
2. 订单状态快捷筛选条
3. 订单列表区
4. 分页或加载更多区

### 5.2 筛选区字段

| 字段 | 字段键 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 订单号 | `order_no_keyword` | 文本输入 | 否 | 支持模糊搜索 |
| 收货门店 | `store_partner_id` | 下拉 | 否 | 当前客户可用门店 |
| 下单开始日期 | `date_from` | 日期 | 否 | |
| 下单结束日期 | `date_to` | 日期 | 否 | |
| 状态 | `display_status` | 下拉 / 标签 | 否 | |
| 是否仅看异常 | `only_exception` | 开关 | 否 | |

### 5.3 状态快捷筛选

建议快捷标签：

- 全部
- 待审核
- 待出库
- 配送中
- 已签收
- 异常

### 5.4 列表字段

| 字段 | 字段键 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 订单号 | `order_name` | 文本 | 是 | 对应 `sale.order.name` |
| 下单时间 | `order_date` | 日期时间 | 是 | |
| 收货门店 | `store_name` | 文本 | 是 | |
| 商品摘要 | `line_summary` | 文本 | 是 | 如“3种商品 / 12件” |
| 订单金额 | `amount_total` | 金额 | 是 | |
| 付款方式 | `b2b_payment_method` | 文本 | 否 | |
| 收款摘要 | `payment_status_summary` | 文本 | 否 | 如未收款 / 部分收款 / 已收款 |
| 履约状态 | `display_status` | 标签 | 是 | 客户友好状态 |
| 异常标记 | `has_exception` | 标签 | 否 | 有异常时突出显示 |
| 详情按钮 | `open_detail` | 按钮 | 是 | 进入详情页 |

### 5.5 列表交互规则

- 默认按下单时间倒序
- 只能看到当前客户自己的订单
- 切换门店后，只显示该门店相关订单
- 有异常的订单允许高亮
- 列表项点击后进入订单详情页

## 7. 订单详情页状态展示规则

### 7.1 只展示客户可理解的摘要

前台不直接暴露：

- `wave`
- `batch`
- `handover`
- `driver_task`
- `waybill`

除非后续要开放更深物流追踪页。

当前只展示：

- 是否已确认
- 是否已出库
- 是否配送中
- 是否已签收
- 是否有异常

### 7.2 异常展示规则

当订单存在未关闭异常时：

- 订单列表页显示异常标记
- 订单详情页显示异常摘要
- 若允许售后，则展示“发起售后”入口

### 7.3 收款摘要规则

当前阶段收款摘要仅做客户友好展示：

- 未收款
- 待确认
- 部分收款
- 已收款

正式财务口径仍以 `account` 为准。

## 8. 售后入口展示规则

### 8.1 允许展示售后入口的场景

建议至少满足其一：

- 订单已签收
- 订单存在配送异常
- 订单部分签收 / 拒收

### 8.2 不展示售后入口的场景

- 订单仍处于待审核
- 订单尚未出库
- 订单已取消

## 9. 查询与详情页后端校验

### 9.1 权限校验

- 当前登录用户只能查看所属客户订单
- 不允许跨客户查看订单
- 不允许通过手工篡改 `order_id` 查看他人订单

### 9.2 数据校验

- 订单必须来源于 `source_channel = b2b` 或允许被 B2B 查询
- 门店必须属于当前客户
- 履约摘要只能读取与当前订单相关的 ERP/WMS/TMS 数据

## 10. 空态与异常态

### 10.1 订单查询页空态

建议提示：

- `当前还没有订单，先去选购商品吧。`
- `没有找到符合条件的订单，请调整筛选条件。`

### 10.2 订单详情异常态

建议提示：

- `订单信息暂时无法加载，请稍后重试。`
- `当前无权查看该订单。`
- `订单不存在或已不可访问。`

## 11. 本期不做

本期订单查询页 / 详情页不做：

- 实时地图轨迹
- 司机电话直拨
- 逐张回单图片大规模证据中心
- 在线退款
- 在线改单
- 客户侧取消后自动回写复杂库存逻辑

## 12. 验收口径

通过最小标准：

- 客户能查到自己的订单
- 客户能按状态、门店、时间筛选订单
- 订单详情能展示商品、金额、门店、履约摘要、收款摘要
- 状态展示与 ERP/WMS/TMS 摘要一致
- 无权查看他人订单
- 满足条件时能显示售后入口
