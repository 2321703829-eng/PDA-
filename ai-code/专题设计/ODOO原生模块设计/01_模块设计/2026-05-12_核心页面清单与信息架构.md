## 1. Objective

这份文档用于回答本期开工前最后一个页面问题：

1. 用户从哪里进入系统
2. 每个域至少需要哪些页面
3. 哪些页面复用 Odoo 原生，哪些需要新建
4. 页面之间怎么跳，避免用户在系统里迷路

---

## 2. 信息架构总原则

- 本期按 `ERP / WMS / TMS / BI / 系统底座 / 既有物流域` 六个域组织菜单
- 菜单统一，但对象职责不混用
- 详情页优先支持“反查上游、跳转下游、查看摘要”
- 工作台页负责动作处理，单据详情页负责信息确认
- 优先复用原生列表页、表单页、搜索视图；工作台和跨域聚合页再自建

---

## 3. 一级菜单结构

建议一级菜单如下：

1. `ERP经营`
2. `WMS仓内`
3. `TMS配送`
4. `财务结算`
5. `BI看板`
6. `系统底座`
7. `既有物流联动`

说明：

- 如果前端希望更简洁，可将 `财务结算` 并入 `ERP经营`
- `既有物流联动` 本期可以只对少数角色显示
- `系统底座` 只给管理员和实施角色开放

---

## 4. ERP 页面清单

### 4.1 主数据页

- 客户档案列表/详情页
- 供应商档案列表/详情页
- 商品档案列表/详情页
- 门店档案列表/详情页
- 价格规则列表/详情页

页面类型：

- 优先复用原生模型详情页并做轻改

关键动作：

- 新建
- 批量导入
- 启停用
- 查看历史价格
- 跳转关联销售/采购/配送摘要

### 4.2 销售页

- 销售订单列表页
- 销售订单详情页
- 销售订单导入页
- 客户往来查询页

页面类型：

- 列表/详情优先复用 `sale.order`
- 导入页和往来查询页建议自建轻工作台

关键动作：

- 新建订单
- 审核确认
- 查看待出库摘要
- 查看待配送摘要
- 查看应收与对账摘要

### 4.3 采购页

- 采购订单列表页
- 采购订单详情页
- 采购到货计划页
- 供应商往来查询页

页面类型：

- 列表/详情优先复用 `purchase.order`
- 到货计划页可轻工作台化

关键动作：

- 新建采购单
- 审核确认
- 生成待收货需求
- 查看收货进度
- 查看应付与对账摘要

---

## 5. WMS 页面清单

### 5.1 仓库作业工作台

- 收货工作台
- 上架工作台
- 分拣工作台
- 复核工作台
- 装车交接工作台
- 盘点工作台

页面类型：

- 这组页面建议自建

关键动作：

- 扫描/选择任务
- 录入数量
- 提交作业结果
- 查看异常提示
- 跳转来源销售/采购单

### 5.2 仓库管理页

- 仓库列表/详情页
- 库位列表/详情页
- 库存台账查询页
- 实物库存查询页
- 出入库任务列表页

页面类型：

- 仓库、库位、基础 picking 可复用原生
- 台账和作业聚合查询页建议自建

关键动作：

- 查询库存
- 查看库位
- 查看任务状态
- 查看收货/出库来源
- 查看盘点调整结果

---

## 6. TMS 页面清单

### 6.1 配送调度工作台

- 排线工作台
- 派车工作台
- 司机任务列表页
- 签收回单工作台
- 配送异常处理页

页面类型：

- 建议自建

关键动作：

- 生成路线
- 指派司机和车辆
- 查看待配送任务
- 录入签收结果
- 提交异常
- 查看运费明细

### 6.2 配送基础页

- 门店配送档案页
- 车辆档案页
- 司机档案页
- 运费明细查询页

- 司机/车辆可优先复用 `hr` / `fleet` 基础页并轻改

关键动作：

- 配置配送频次和配送窗

- 查询运费
- 查看签收与异常摘要

## 7. 财务结算页面清单

- 应收查询页
- 应付查询页
- 收款登记页
- 付款登记页

## 10. 既有物流联动页面清单

- 物流联动摘要页
- 既有 waybill 反查页
- 既有 customer_line 反查页

本期定位：

- 只做摘要、跳转、反查
- 不重做既有物流主工作台

关键动作：

- 从 ERP / WMS / TMS 查看关联 waybill 摘要
- 从既有物流页反查销售、库存、配送、财务结果

---

## 11. 核心页面跳转关系

建议至少保证下面这些跳转成立：

1. 销售订单 -> 待出库摘要 -> 分拣/复核工作台
2. 采购订单 -> 待收货摘要 -> 收货/上架工作台
3. 装车交接 -> 派车工作台 -> 司机任务 -> 签收回单
4. 销售订单 -> 应收摘要 -> 对账页
5. 采购订单 -> 应付摘要 -> 对账页
6. 订单/仓库/配送看板 -> 来源列表页
7. ERP / WMS / TMS 详情页 -> 既有物流摘要
8. 既有物流摘要 -> ERP / WMS / TMS 来源详情

---

## 13. 进入编码前的页面锁定口径

进入编码前，至少要锁定下面 5 件事：

1. 一级菜单结构
2. 每个域的主入口页面
3. 哪些页面复用原生，哪些页面自建
4. 关键工作台的动作按钮和状态展示
5. 关键跳转链路

锁定到这一步，就可以开始做 menu、action、view、security 和工作台模型了。
