## 使用说明

- 当前目录内现有文件基于旧版 `Odoo 18.0` 落地环境，应按 `bridge` 理解。
- `2026-05-13_kebi正式站接入实施清单.md` 为当前正式站接入执行文档，优先用于 `kebi.tianshuchain.cn/odoo` 接入前准备。
- `2026-05-13_kebi界面重构与入口接线清单.md` 为当前正式站 UI 和壳层接线执行文档，优先用于首页、工作台和统计中心入口收口。
- `2026-05-13_kebi页面线框清单.md` 为当前正式站页面线框文档，优先用于前端页面骨架、信息分区和跳转链开发。
- 本目录文件提供落地参考，不单独定义项目主架构边界。
- 若与 `docs/architecture/` 或 `docs/dev/` 冲突，以主文档体系为准。
