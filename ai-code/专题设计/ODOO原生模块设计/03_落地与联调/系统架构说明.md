## 五、业务数据流

### 5.1 客户下单 → 发货 完整链路

```
客户访问 /shop
    │
    ▼
浏览商品（website_sale + website_sale_stock 显示实时库存）
    │
    ▼
加入购物车 → 结算 → 支付
    │
    ▼
生成销售订单 SO (sale)
    │
    ▼
SO 确认 → 自动生成发货单 Delivery Order (sale_stock → stock.picking)
    │
    ▼
仓库拣货 (stock_picking_batch 批次合并拣货)
    │
    ▼
发货出库 → 库存扣减 (stock.quant)
    │
    ▼
生成发票 (account.move)
    │
    ▼
毛利计算 (sale_margin / sale_stock_margin)
```

### 5.2 采购入库链路

```
创建采购订单 PO (purchase)
    │
    ▼
PO 确认 → 自动生成入库单 Receipt (purchase_stock → stock.picking)
    │
    ▼
收货入库 → 库存增加 (stock.quant)
    │
    ▼
供应商发票匹配 (account)
    │
    ▼
落地成本分摊 (stock_landed_costs)
    │
    ▼
商品成本价更新 → 影响后续销售毛利
```

### 5.3 物流调度链路（自定义模块）

```
运单创建 (logistics_dispatch.waybill)
    │
    ▼
波次分组 (logistics_dispatch.wave)
    │
    ▼
批次分配 (logistics_dispatch.batch)
    │
    ▼
执行过程留痕 (logistics_trace_core → trace_event)
    │
    ├── 拍照/签名证据 (logistics_trace_evidence)
    │
    └── 异常上报处理 (logistics_trace_exception)
```
