# Odoo原生功能 vs 福科目标功能差异一览表

文档类型：
- 专题方案





## 1. 一眼结论

整体判断：

- ERP 基础能力：Odoo 原生覆盖较高
- WMS 标准底座：Odoo 原生覆盖中高
- TMS 调度与签收：Odoo 原生覆盖较低，主要依赖既有物流模块和新定制
- BI 看板：Odoo 原生覆盖低，需要新建聚合页
- 系统底座：Odoo 原生覆盖中高，但仍需补数据权限、日志、模板等管理能力

一句话收口：

**这期最值得复用的是 ERP 和库存底座，最需要补的是 WMS 作业工作台、TMS 调度执行页、BI 看板，以及福科特有的价格、结账、对账和经营口径。**

## 6. 本期需要改动或新增的重点功能

如果只看“本期一定会动代码”的部分，优先级最高的是下面这些：

### 6.1 必改原生

- `res.partner`
  - 客户等级
  - 账期
  - 结算方式
  - 门店类型与门店业务属性
- `product.template` / `product.product`
  - 箱规
  - 参考进价
  - 基础销售价补充
  - 业务展示字段
- `sale.order`
  - 业务来源字段
  - 价格校验辅助字段
  - 待出库 / 待配送摘要字段
- `purchase.order`
  - 到货计划字段
  - 收货摘要字段
- `stock.warehouse` / `stock.location`
  - 业务库区
  - 拣货区
  - 路线/作业辅助字段
- `account.move` / `account.payment`
  - 业务对账摘要
  - 来源单据摘要

### 6.2 必新增

- 价格规则
- 调价记录
- 订单导入批次与导入明细
- 对账单与对账单明细
- 结账记录
- WMS 收货 / 上架 / 出库 / 分拣 / 复核 / 装车交接工作台对象
- TMS 派车 / 司机任务 / 运费明细对象
- BI 快照与看板聚合页

### 6.3 重点复用既有自定义

- `waybill`
- `customer_line`
- `trace_event`
- `evidence`
- `exception`

本期原则：

- 保留
- 联动
- 反查

而不是重做或回退到官方销售/库存/发票对象。
