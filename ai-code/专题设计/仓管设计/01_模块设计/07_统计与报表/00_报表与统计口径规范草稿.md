## 1. 文档定位

本文件用于把仓管模块中与统计、报表、查询视图相关的内容从总讨论稿中进一步抽出，形成一个可独立继续演进的统计专题稿。

当前重点不是一步设计完整 BI 平台，而是先固定：

- 一期哪些查询与统计能力值得先做
- 查询与统计的边界
- 与库存事实、执行事实、页面展示、权限范围的关系

## 2. 范围与边界

### 2.1 当前纳入范围

- 库存查询
- 发货汇总
- 接单统计
- 客户维度查询
- 异常或超时统计

### 2.2 当前不纳入范围

- 全量 BI 平台
- 高度自由图表中心
- 跨系统统一经营分析平台
- 很重的自定义报表设计器

## 3. 当前推荐的总体原则

当前更推荐统一理解为：

`报表建立在事实层之上，查询优先服务业务定位，统计优先服务管理判断。`

也就是：

- 查询不应篡改事实层
- 统计不应取代业务主单和执行页
- 报表优先做稳定聚合，不优先做复杂分析中心

## 4. 一期纳入范围

当前一期更推荐先覆盖这些能力：

- 库存查询
- 发货汇总
- 接单统计
- 客户维度查询
- 异常 / 超时统计

一句话收口：

`一期报表目标不是做大屏，而是先把高频查询和关键管理聚合做稳。`

## 5. 查询与统计的分层口径

当前更推荐分成两层：

### 5.1 查询层

更偏业务人员使用，回答：

- 现在有什么
- 这张单到哪了
- 这个客户 / 货主当前情况如何

### 5.2 统计层

更偏管理与汇总使用，回答：

- 今天发了多少
- 当前异常有多少
- 哪些客户、仓库、流程节点更集中

一句话收口：

`查询更贴近定位对象，统计更贴近聚合判断。`

## 6. 当前推荐的查询类能力

当前一期更推荐优先纳入：

- 库存查询
- 客户维度查询
- 按主单或状态的业务查询

当前查询页更推荐至少支持：

- 关键字搜索
- 状态筛选
- 仓库 / 货主筛选
- 时间范围

## 7. 当前推荐的统计类能力

当前一期更推荐优先纳入：

- 发货汇总
- 接单统计
- 异常 / 超时统计

当前统计结果更推荐优先按以下维度聚合：

- 仓库
- 货主 / 客户
- 主状态
- 时间

## 8. 报表对象字段字典基线

### 8.1 库存查询对象

当前更推荐最小字段先围绕：

- 商品
- 货主
- 仓库
- 货位
- 批次
- 当前数量
- 可用数量
- 冻结数量
- 最近更新时间

### 8.2 发货汇总对象

当前更推荐最小字段先围绕：

- 发货日期
- 仓库
- 货主 / 客户
- 发货单量
- 发货件数 / 行数
- 已发货数量摘要

### 8.3 接单统计对象

当前更推荐最小字段先围绕：

- 日期
- 仓库
- 货主 / 客户
- 接单量
- 状态分布

### 8.4 异常 / 超时统计对象

当前更推荐最小字段先围绕：

- 异常类型
- 主状态
- 仓库
- 货主 / 客户
- 超时标识
- 时间
- 数量摘要

### 8.5 当前推荐的一句话口径

`报表对象字段先围绕“归属、状态、时间、数量摘要”收口，不在一期把所有经营分析指标一次做满。`

## 9. 查询页 / 统计页页面结构基线

### 9.1 查询页结构基线

当前更推荐查询页统一采用：

- 顶部搜索与筛选区
- 中部标准表格
- 右上轻量导出或查看入口
- 分页区

### 9.2 统计页结构基线

当前更推荐统计页统一采用：

- 顶部筛选区
- 中部聚合结果表格
- 上方或侧边轻量摘要卡片
- 必要时保留导出入口

### 9.3 当前推荐的一句话口径

`查询页优先服务定位对象，统计页优先服务看汇总，不把两者混成同一种页面。`

## 10. 与事实层、页面层、权限层的关系

当前更推荐：

- 库存统计建立在 `stock.quant`、`stock.move`、`stock.move.line` 等事实层之上
- 管理汇总建立在主单与执行记录稳定后的聚合层之上
- 查询页、统计页都不突破页面权限与记录规则边界

一句话收口：

`报表先复用事实层，不另造统计真相。`

## 11. 报表对象与权限 / 记录规则联动口径

当前更推荐：

- 查询页和统计页都不突破页面权限与记录规则边界
- 报表中的货主 / 仓库维度应跟随业务对象范围收口
- 聚合结果只在“用户本来就可见的数据范围内”做汇总

当前推荐的联动理解：

- 权限先决定“能不能看”
- 记录规则再决定“能看哪些数据”
- 报表页面最后决定“在可见范围内怎么展示和聚合”

一句话收口：

`报表只在可见范围内做聚合，不借报表突破数据边界。`

## 12. 当前不建议的一期做法

当前不建议：

- 一期就做高度自由的图表中心
- 一期就把所有查询、统计、看板混成一个页面
- 用统计口径字段替代业务事实字段
- 为了做报表再维护一套并行库存真相

- 查询与统计的分层口径
- 一期优先查询类能力
- 一期优先统计类能力
- 报表对象字段字典基线
- 查询页 / 统计页页面结构基线
