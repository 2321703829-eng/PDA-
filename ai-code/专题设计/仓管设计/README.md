# 仓管设计

本目录用于承接仓管专题的正式设计资料，是与 `docs/` 主文档体系并行的专题设计包入口。

## 统一命名

- 统一专题名：`仓管设计`
- 当前物理目录：`专题设计/仓管设计/`

## 专题定位

- 主题：仓储与库内作业能力设计
- 当前阶段：以启动讨论、边界澄清、对象拆分和规范草稿为主
- 与主文档体系关系：
  - 业务总基线仍以 `docs/context/` 和 `docs/architecture/` 为准
  - 本目录负责承接仓管专题的专项设计、细化规范和落地清单

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_模块设计/`
3. `02_跨模块规范/`
4. `03_落地与联调/`
5. `04_来源资料与历史草图/`
6. `05_提交包/`
7. `99_待归档/`

## 目录说明

- `00_导航与总纲/`：仓管专题启动说明、当前进度和模块关系
- `01_模块设计/`：主数据、入库、库存、出库、盘点、接口、报表等模块稿
- `02_跨模块规范/`：编码、状态、权限、接口和查询规则
- `03_落地与联调/`：P0 范围、调研清单、验证清单和联调安排
- `04_来源资料与历史草图/`：来源资料、截图和补充记录
- `05_提交包/`：评审、汇报和交付入口
- `99_待归档/`：待收口材料
