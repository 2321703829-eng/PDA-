# 仓管设计

本目录用于承接仓管专题的正式设计资料，是与 `docs/` 主文档体系并行的专题设计包入口。

## 统一命名

- 统一专题名：`仓管设计`
- 当前物理目录：`专题设计/仓管设计/`

## 专题定位

- 主题：仓储与库内作业能力设计
- 当前阶段：以启动讨论、边界澄清、对象拆分和规范草稿为主
- 与主文档体系关系：
  - 业务总基线仍以 `docs/context/` 和 `docs/architecture/` 为准
  - 本目录负责承接仓管专题的专项设计、细化规范和落地清单

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_模块设计/`
3. `02_跨模块规范/`
4. `03_落地与联调/`
5. `04_来源资料与历史草图/`
6. `05_提交包/`
7. `99_待归档/`

## 跨阶段阅读顺序

仓管专题目前还处在“启动 -> 边界澄清 -> 模块拆分 -> 规范收口 -> 落地验证”的推进序列里，建议按下面顺序读：

1. 先看 [主文档清单.md](./主文档清单.md)，确认仓管专题当前主入口。
2. 再读 `00_导航与总纲/`，先收口 OBB、阶段判断和模块范围。
3. 之后进入 `01_模块设计/`，优先理解主数据、入库、库存、出库、盘点这些核心能力对象。
4. 再看 `02_跨模块规范/`，把编码、状态、权限、接口和查询规则统一起来。
5. 最后再读 `03_落地与联调/`、`05_提交包/`，只在需要追溯来源时回看 `04_来源资料与历史草图/` 和 `99_待归档/`。

- `05_提交包/`：评审、汇报和交付入口
