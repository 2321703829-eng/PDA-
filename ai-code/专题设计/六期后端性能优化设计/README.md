1. 先看 [主文档清单.md](./主文档清单.md)，确认本专题当前主文档集合。
2. 再读 `00_导航与总纲/`，先把六期边界、优化主轴和阶段口径收口。
3. 然后进入 `01_专题方案/`，优先阅读方向取舍、Outcome 和 `P0 / P1 / P2` 清单。
4. 接着读 `02_跨模块规范/` 与 `02_验收与联调/`，把执行约束、验收条件和落地闭环连起来。
