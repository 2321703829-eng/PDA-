## 二、当前剩余待修项

### P1. 顶部菜单仍有个别英文残留

当前问题：

- 顶部菜单中的 `Frontend` 仍是英文

影响：

- 中文一致性不足
- 客户可见文案不完整

建议：

- 补齐菜单、action、client action 标题的中文翻译

### P1. Trace & Evidence 增强 widget 仍需继续美化

当前问题：

- widget 已能渲染
- 但视觉层仍偏“可用态”，距离最终展示质量还有差距

具体表现：

- 时间线卡片仍较朴素
- `Evidence Viewer` 仍偏窄、偏保守
- fallback 区和增强区同时存在时，页面层次还不够精致

影响：

- 不影响功能验证
- 会影响客户演示观感

建议：

- 在主链稳定后，继续做布局和视觉优化

### P1. 工作台与老板页目前仍是占位数据

当前问题：

- 工作台和老板页虽然可打开
- 但页面文案明确提示仍在使用 placeholder 数据

影响：

- 不能作为真实业务看板使用
- 卡片数字和对象列表暂不能作为最终验收依据

建议：

- 接真实异常、高风险批次、证据缺失、今日新增争议等聚合

### P2. 列表列宽与部分文案细节仍需优化

当前问题：

- 部分列表列宽偏窄
- 编号、摘要、状态字段在紧凑宽度下不够舒展
- 个别字段标题和中文文案仍有进一步润色空间

影响：

- 不影响功能
- 影响可读性与专业感

建议：

- 在页面结构稳定后统一做列表层视觉收口

### P2. 中文翻译仍需继续查漏补缺

当前问题：

- 虽然翻译主链已恢复
- 但从当前截图看，仍可能存在少量漏翻译项

影响：

- 页面语言不够一致

建议：

- 按截图继续补漏翻译
- 尤其关注：
  - 菜单名
  - client action 标题
  - 工作台说明文案
  - 老板页说明文案

## 三、当前结论

当前系统已经通过了“能否进入真实联调”的关键门槛。

更准确地说：

- 主数据页可以打开
- 主对象可以创建与保存
- 运单、批次、留痕、证据、异常之间的主关系已打通
- 运单详情页的核心聚合字段能联动更新
- 追溯链路和异常链路都已经具备继续联调和继续验收的条件

当前主要剩余问题已经不再是“功能是否存在”，而是：

- 中文是否完全一致
- widget 是否足够美观
- 看板是否切到真实聚合数据
- 列表与文案是否进一步收口
