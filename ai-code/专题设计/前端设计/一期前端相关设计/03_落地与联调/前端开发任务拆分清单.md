# 前端开发任务拆分清单

适用范围：
- 当前一期 Odoo 物流后台前端开发
- 面向页面实现、组件实现、联调准备、权限收口

优先基准：
- `前端总体设计总览.md`
- `P0页面Odoo落地实现清单.md`
- `前后端接口字段级契约清单.md`
- `页面级字段只读矩阵.md`

关联文档：
- `controller 示例响应.md`
- `时间线与证据区widget结构草案.md`
- `前端权限显示与角色映射草案.md`
- `Smart Button设计清单.md`

---

## 1. 文档定位

这份文档用于把现有设计直接拆成可执行开发任务。

目标不是再讨论方案，而是回答：

- 先做什么
- 每块任务的交付物是什么
- 哪些任务能并行
- 哪些任务必须依赖前置完成

---

## 2. 开发拆分原则

当前建议按 5 类任务拆：

1. 页面骨架任务
2. 数据接入任务
3. 增强组件任务
4. 权限与显示控制任务
5. 联调与收口任务

---

## 3. P0 主链任务拆分

## 3.1 运单追溯列表页

任务编号：
- `FE-P0-001`

任务名称：
- 运单追溯列表页骨架实现

主要内容：
- 建 `search view`
- 建 `tree view`
- 完成主搜索
- 完成状态/批次/证据筛选
- 完成列表列展示

依赖：
- 运单主模型字段确定
- `getWaybillList` 契约稳定

交付物：
- 列表页可打开
- 列表字段与设计一致
- 支持基础筛选与分页

---

## 3.2 运单详情页基础表单

## 7. 推荐执行顺序

建议按下面顺序推进：

1. `FE-P0-001` 运单追溯列表页
2. `FE-P0-003` 当前异常列表页
3. `FE-P0-002` 运单详情页基础表单
4. `FE-P0-004` 异常详情页基础表单
5. `FE-P0-006` 时间线 widget
6. `FE-P0-007` 证据区 widget
7. `FE-P0-005` 管理工作台
8. `FE-P0-008` 菜单可见性控制
9. `FE-P0-009` 按钮与字段只读控制
10. `FE-P0-010` mock 数据接入
11. `FE-P0-011` 跳转链路校验
12. `FE-P0-012` 联调收口

## 8. 可并行项建议

以下任务可以并行：

- 列表页骨架 与 异常列表页骨架
- 运单详情基础表单 与 异常详情基础表单
- 时间线 widget 与 证据区 widget
- 菜单可见性控制 与 字段只读控制

## 9. 当前任务完成判断标准

每项任务建议按这 3 条判断是否完成：

1. 页面结构已落位
2. 数据字段已对齐文档
3. 跳转或权限行为已可验证
