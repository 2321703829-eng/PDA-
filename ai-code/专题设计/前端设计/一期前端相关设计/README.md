# 一期前端相关设计

本目录承载一期前端设计资料，是 `专题设计/前端设计/` 的第一阶段正式入口。

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_模块设计/`
3. `02_跨模块规范/`
4. `03_落地与联调/`
5. `05_提交包/`

## 目录说明

- `00_导航与总纲/`：前端总览、页面关系和取材说明
- `01_模块设计/`：工作台、追溯、异常、运输、仓储等模块设计
- `02_跨模块规范/`：接口、交互、组件和实施规范
- `03_落地与联调/`：P0 落地清单与实施桥接
- `04_来源资料与历史草图/`：来源资料和历史草图
- `05_提交包/`：阶段提交与交付入口
- `99_待归档/`：待收口材料
