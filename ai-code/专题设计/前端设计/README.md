# 前端设计

`专题设计/前端设计/` 是当前前端专题设计包的总入口。

## 统一命名

- 统一专题名：`前端设计`
- 当前物理目录：`专题设计/前端设计/`

## 专题定位

- 主题：前端阶段化设计与页面交互方案
- 当前阶段：按一期到六期组织的阶段化设计总入口
- 与主文档体系关系：
  - 业务总基线仍以 `docs/context/` 和 `docs/architecture/` 为准
  - 本目录负责承接前端页面、交互、接口衔接和阶段化设计资料

## 跨阶段阅读顺序

第一次进入前端专题包时，建议按下面顺序读：

1. 先看 [主文档清单.md](./主文档清单.md)，确认前端包当前有哪些主入口。
2. 再看 [一期前端相关设计/README.md](./一期前端相关设计/README.md)，理解初始页面结构、基础阅读链和历史主入口。
3. 再按 [二期前端优化设计/README.md](./二期前端优化设计/README.md) -> [三期前端优化设计/README.md](./三期前端优化设计/README.md) -> [四期前端优化设计/README.md](./四期前端优化设计/README.md) 的顺序看演进，重点关注接口、阅读链、导入导出和联调收口。
4. 五期、六期目录优先按补充阶段理解；如果该阶段还未形成同等强度主线，不应跳过前四期直接阅读。
5. 具体进入某一期后，再按该期目录内的“总纲 -> 方案 -> 规范 -> 验收/联调 -> 历史资料”顺序继续下钻。

## 状态口径

- 各阶段根 `README.md` 与总纲、模块设计、跨模块规范默认按 `现行` 理解。
- 文件名或正文明确带 `draft`、`草稿`、`讨论稿` 的材料按 `draft` 理解。
- `04_来源资料与历史草图/` 默认按 `archive` 理解。
- `99_待归档/` 默认按 `archive` 理解，除非正文显式标注仍在回收处理中。
