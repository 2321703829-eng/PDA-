# 2026-04-21 四期订单阅读区结构草案

## 页面定位

- 订单阅读区是门店节点下的主业务阅读区。
- 它承接 `order_line` 快照和订单对应货物的主展示信息。

## 当前结论

1. 订单页仍是首轮主阅读层之一。
2. 但它回到 `customer_line` 下面阅读，而不是直接挂在运单下作为唯一子层。
3. `goods_line` 仍是事实源和扩展层。

## 页面结构

### 1. 订单对象头

- 单据号 / 单据编号
- 订单号
- 销售订单号
- 单据日期
- 单据来源
- 单据状态

### 2. 订单快照区

- 业务类型
- 部门
- 渠道
- 业务员
- 支付状态
- 审核状态
- 结算状态
- 特殊要求
- 订单备注

### 3. 货物主展示区

- 商品编码
- 商品名称
- 规格
- 条码
- 单位
- 数量
- 重量
- 体积
- 货物备注

### 4. 经营字段区

- 单价
- 金额
- 税额
- 成本
- 毛利
- 毛利率

## 页面职责边界

- 订单页不替代运单总览
- 订单页不替代门店节点页
- 订单页是门店节点下的业务阅读页
