# 2026-04-21 四期导入模板字段级映射与校验规则清单

## 文档定位

- 本文用于收口四期单表字段如何落到 `waybill / customer_line / order_line / goods_line`。
- 自 2026-04-23 起，本文统一以《四期数据库底表设计稿 v1（第二次修正版）》为当前有效数据库基线。
- 本文只定义字段落层、导入校验和正式落库口径，不再保留与底表稿冲突的旧规则。

## 必填级别定义

| 级别 | 含义 |
| --- | --- |
| `硬必填` | 缺失即失败，无法进入正式落库 |
| `推荐硬必填` | 强烈建议提供；不提供时只能依赖系统生成或导入侧兜底 |
| `动态必填` | 主数据命不中或不完整时必须提供 |
| `可选` | 首轮允许为空 |
| `二阶段` | 首轮不进入最小单表 |

## 1. 系统控制字段

| 字段 | 落层 | 级别 | 规则 | 说明 |
| --- | --- | --- | --- | --- |
| `运单号` | `waybill` | 硬必填 | 正式落库必须有有效 `waybill_no` | 正式运单业务键 |
| `运单分组号` | `waybill` | 可选 | 仅作导入控制字段，不替代 `waybill_no` | 预分组、查重提示、辅助映射 |
| `customer_line_no` | `customer_line` | 推荐硬必填 | 优先用于门店节点命中；最终必须满足 `(waybill_id, customer_line_no)` 唯一 | 运单内稳定业务键 |

## 6. 当前统一口径

1. `waybill_no` 是正式运单键，`waybill_group_no` 只是导入控制字段。
2. `customer_line_no` 是运单内稳定业务键，不是数据库主键。
3. `customer_line_id` 是订单正式归属 FK，文本业务键只服务导入聚合与快照。
4. `goods_line` 是订单下的事实明细层，首轮即允许一单多货。
