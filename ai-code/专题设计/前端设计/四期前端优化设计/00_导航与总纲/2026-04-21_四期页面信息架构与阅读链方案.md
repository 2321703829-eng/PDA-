# 2026-04-21 四期页面信息架构与阅读链方案

## 文档定位

- 本文定义四期页面层级、主入口和阅读链。
- 当前统一前提恢复为：运单可挂多个门店节点。

## 核心结论

1. 运单详情页仍然是四期主阅读页之一，但不再吞并门店节点层。
2. 门店节点阅读区重新恢复为四期核心阅读中枢。
3. 首轮主阅读链恢复为：`waybill -> customer_line -> order_line`。
4. 图片阅读链恢复为：`waybill -> customer_line -> 图片预览 / 留痕 / 证据`。

## 页面分层总览

| 层级 | 角色 | 页面 |
| --- | --- | --- |
| L1 | 总入口 | 首页、导入中心 |
| L2 | 工作区 | 单表导入、图片导入、运单列表 |
| L3 | 对象列表 | 运单列表、门店节点列表、订单列表 |
| L4 | 主阅读层 | 运单详情、门店节点阅读区、订单阅读区 |
| L5 | 证据层 | 门店节点图片预览、门店节点留痕、门店节点导出 |

## 四期主路径

### 1. 单表导入路径

`首页 -> 导入中心 -> 单表快捷导入 -> 导入结果页 -> 运单详情 -> 门店节点阅读区 -> 订单阅读区`

### 2. 图片导入路径

`首页 -> 导入中心 -> 图片批量导入 -> 图片导入结果页 -> 运单详情 -> 门店节点阅读区 -> 图片预览`

### 3. 运单阅读路径

`运单列表 -> 运单详情 -> 门店节点阅读区 -> 订单阅读区`

### 4. 图片阅读路径

`运单详情 -> 门店节点阅读区 -> 图片预览 / 证据区 / 导出`

## 页面角色说明

### 运单详情页

- 运单总容器页
- 展示执行信息、批次上下文、门店节点汇总、图片汇总
- 向门店节点页分发

### 门店节点阅读区

- 四期现场事实阅读中枢
- 展示门店联系人、地址、经纬度、停靠顺序、图片、留痕、下属订单

### 订单阅读区

- 首轮主业务阅读层
- 展示订单快照和该订单对应货物的主展示字段

### 货物层

- 不单独强化首轮页面
- 作为事实层和未来扩展层保留

## 当前明确退出的口径

以下口径不再作为四期主口径：

- `运单 -> order_line` 直接成为全部主阅读链
- 图片直接挂 `waybill` 成为唯一业务挂点
- 门店节点页降级为兼容说明稿
