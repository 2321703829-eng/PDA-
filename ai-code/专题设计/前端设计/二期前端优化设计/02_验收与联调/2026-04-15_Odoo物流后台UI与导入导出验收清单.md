## 一、UI本土化与中文体验验收

### 1. 工作台与管理层总览

- [ ] `运营工作台` 页面标题已显示为 `运营工作台`
- [ ] `运营工作台` 页面不再显示 `Frontend` 或其他旧英文工作台名称
- [ ] `运营工作台` 副标题读起来是业务提示语，而不是技术说明
- [ ] `运营工作台` 卡片标题显示为 `待处理异常 / 待补证据 / 风险批次 / 今日新增`
- [ ] `运营工作台` 空态文案是中文短句，并带业务语气
- [ ] `运营工作台` 错误态文案包含动作建议，例如“请刷新页面或稍后再试”
- [ ] `管理层总览` 页面标题已显示为 `管理层总览`
- [ ] `管理层总览` 页面不再显示 `Boss Trace`
- [ ] `管理层总览` 副标题强调“先看风险和异常”
- [ ] `管理层总览` 对象卡片按钮统一为 `查看异常 / 查看运单 / 查看批次`
- [ ] `管理层总览` 全页统一使用“异常”语义，不混用“争议 / 问题 / 异常”

### 2. 运单详情页

- [ ] 运单详情页页签显示为 `订单明细 / 备注 / 留痕与证据`
- [ ] 运单详情页不再出现 `Trace & Evidence`
- [ ] `留痕与证据` 页内存在三段式阅读引导
- [ ] 阅读引导顺序明确为“先看留痕 -> 再看证据 -> 最后核对异常”
- [ ] 留痕区标题显示为 `留痕时间线`
- [ ] 证据区标题显示为 `证据查看`
- [ ] 页面不再出现 `Trace Timeline` 或 `Evidence Viewer`
- [ ] 调试区标题显示为 `原始关联数据（调试）`
- [ ] 调试区仍保留，但明显弱于主阅读区

### 3. 留痕与证据体验

- [ ] 留痕筛选后会显示“共 X 条，当前筛选出 Y 条”
- [ ] 留痕无数据时显示中文业务空态文案
- [ ] 留痕筛选无结果时提示“可取消筛选继续查看”
- [ ] 证据查看区会显示当前第几张、关联哪条留痕、上传时间等摘要
- [ ] 异常相关证据会有对应提示
- [ ] 只能预览时会出现“当前仅支持预览”之类提示

### 4. 订单明细与英文残留

- [ ] 运单 `订单明细` 列头显示为 `外部单号 / 销售订单 / 出库单 / 门店 / 货物摘要 / 数量 / 明细状态`
- [ ] 页面主路径中不再出现 `External Order No / Sale Order / Stock Picking / Goods Summary / Line Status`
- [ ] 页面主路径中不再出现 `Trace & Evidence / Trace Timeline / Evidence Viewer / Frontend / Boss Trace`
- [ ] 页面整体视觉已呈现灰蓝系卡片层级，而不是 Odoo 原始淡紫默认感

### 5. UI验收记录

- [ ] 运单页签与标题：通过
- [ ] 留痕筛选反馈：通过
- [ ] 证据摘要与提示：通过
- [ ] 订单明细列头中文化：通过
- [ ] 英文残留清理：通过

## 二、导入导出体验验收

### 1. 导入入口

- [ ] 波次列表页顶部出现独立 `导入` 按钮
- [ ] 批次列表页顶部出现独立 `导入` 按钮
- [ ] 运单列表页顶部出现独立 `导入` 按钮
- [ ] 留痕列表页顶部出现独立 `导入` 按钮
- [ ] 证据列表页顶部出现独立 `导入` 按钮
- [ ] 异常列表页顶部出现独立 `导入` 按钮
- [ ] 齿轮菜单中的 `导入记录` 仍保留
- [ ] 点击运单列表页独立 `导入` 按钮后，会进入自定义 `导入中心` 页面，而不是 Odoo 原生导入页
- [ ] 首页 `物流导入` 快捷入口会进入自定义 `导入中心` 页面
- [ ] `物流 -> 导入中心` 菜单会进入自定义 `导入中心` 页面
- [ ] 菜单层当前只保留单一 `导入中心` 主入口，不再把 `运单导入 / 客户明细导入 / 货物明细导入` 作为可见的二级菜单入口

### 2. 导入中心页面与 V2 模板

- [ ] 导入中心页面标题显示为 `导入中心`
- [ ] 页面副标题明确表达“先下载模板，再预校验，再正式导入”
- [ ] 页面内存在 `标准模板下载 / 上传与预校验 / 预校验结果 / 导入结果` 四个主要区块
- [ ] 页面可下载 `TSL-IMPORT-WAYBILL-V2.xlsx`
- [ ] 页面可下载 `TSL-IMPORT-WAYBILL-V2.zh_CN.xlsx`
- [ ] 下载后的模板固定包含 `运单 / 客户明细 / 货物明细` 三个 Sheet
- [ ] 不再以旧的单表 `CSV` 作为当前主样例口径

### 3. 预校验与错误反馈

- [ ] 选择 `.xlsx` 文件后，页面会正确显示当前文件名
- [ ] 点击 `开始预校验` 后，会返回导入批次号
- [ ] 预校验结果会显示 `总行数 / 失败行数 / 是否可正式导入`
- [ ] 当预校验失败时，页面会展示错误明细表
- [ ] 错误明细表至少包含：
  - `Sheet`
  - `行号`
  - `字段`
  - `错误编码`
  - `错误说明`
- [ ] 预校验失败时可下载错误报告
- [ ] 错误报告文件列头为：
  - `Sheet`
  - `行号`
  - `字段编码`
  - `字段名称`
  - `错误编码`
  - `错误说明`

### 4. 正式导入与结果展示

- [ ] 只有当预校验通过后，`确认正式导入` 按钮才可执行
- [ ] 正式导入完成后，结果区会显示：
  - `导入批次号`
  - `状态`
  - `新增运单`
  - `新增客户明细`
  - `新增货物明细`
- [ ] 结果区可执行 `刷新结果`
- [ ] 结果区可回到运单列表继续核验
- [ ] 当导入失败或存在失败原因时，页面会显示明确失败说明

### 5. V2 三 Sheet 成功样例验收

- [ ] 使用 `V2` 三 Sheet 成功样例时，预校验结果为可正式导入
- [ ] 正式导入后能成功创建：
  - 运单
  - 客户明细
  - 货物明细
- [ ] 导入完成后，在运单列表中可按导入样例中的运单号查到对应记录
- [ ] 打开对应运单后，能看到客户明细与货物明细真实落库

### 6. V2 三 Sheet 失败样例验收

- [ ] 当 `客户明细` Sheet 为空时，预校验会失败
- [ ] 当 `货物明细` 指向不存在的客户层关系时，预校验会失败
- [ ] 当模板结构错误时，错误会明确指出是文件级、Sheet 级还是字段级问题
- [ ] 当前不会把结构级错误误判成“可以正式导入”
