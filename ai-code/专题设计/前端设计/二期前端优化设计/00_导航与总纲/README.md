# 导航与总纲

本目录存放二期前端优化设计的总纲入口文档。

当前使用方式：

1. 先读本目录主方案，确认二期品牌化、首页、导航和订单导入重设计的总方向
2. 再读 `二期前端模块结构与菜单总表.md`，确认二期一级导航和物流模块二级工作区
3. 再读 `二期系统页面关系总览.md`，确认首页、统计图表、运单详情和导入中心之间的页面关系
4. 再读 `2026-04-16_TSL-IMPORT-WAYBILL-V2三Sheet标准模板正式规格.md`，确认本期已落地的多 Sheet 标准模板方案
5. 再读 `2026-04-16_客户与货品固定需求及临时需求拆分方向记录.md`，确认后续开发方向
6. 再进入 `../01_专题方案/` 阅读 UI 与导入导出两份专项方案
7. 需要人工核验时，再看 `../02_验收与联调/`

适用边界：

- 本目录负责统一二期口径，不直接替代专题验收单
- 当前实现验证和样例导入，不应只看总纲，需同时结合配套专题和样例说明
