# 二期提交包

本目录用于承接二期前端优化设计中面向领导汇报、方案评审和正式提交的阅读入口文件。

建议阅读顺序：

1. `领导汇报版摘要.md`
2. `二期评审摘要与阅读顺序.md`
3. `正文清单.md`
4. `附件清单.md`

目录说明：

- `领导汇报版摘要.md`：面向领导快速汇报的高层摘要
- `二期评审摘要与阅读顺序.md`：面向评审与项目推进的总入口
- `正文清单.md`：本轮建议作为正式正文提交的文档清单
- `附件清单.md`：本轮建议作为支撑依据和补充说明的附件清单

当前原则：

- 提交包不替代原正文目录
- 正式设计内容仍以 `../00_导航与总纲/`、`../01_专题方案/`、`../02_跨模块规范/` 为准
- 本目录负责“让别人快速看懂该看什么”
