# 跨模块规范

本目录用于存放二期前端优化设计中的跨模块规范资料。

当前重点新增：

- `01_接口与数据/`：二期相较一期的接口升级补充
- `02_交互与组件/`：二期首页、统计、运单详情、导入中心的交互与组件变更说明
- `03_权限与状态/`：二期角色、入口、按钮和页签的前端显示口径

使用建议：

1. 先读 `../00_导航与总纲/`
2. 再读 `../01_专题方案/`
3. 进入本目录确认二期新增能力对应的接口、字段和路线
4. 再看交互与权限说明，确认页面层和显示层口径
5. 需要做回归核验时，再读 `../02_验收与联调/`

适用边界：

- 本目录不重写一期已经稳定的接口设计
- 一期已稳定的基础列表、详情、留痕、证据、异常接口继续复用一期口径
- 本目录重点说明二期新增首页、统计图表、运单详情重构、标准导入链路的升级补充
- 当前二期跨模块规范已不只覆盖接口，还补充了交互和权限两层说明
