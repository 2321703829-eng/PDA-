## 1. 文档定位

这份文档用于把二期接口设计转成可排期、可分工、可联调的后端任务包。

建议拆成 5 个任务包，按依赖顺序推进。

---

## 2. 任务包拆分

## Task 1. 首页聚合接口包

接口范围：

- `getHomeOverviewSummary`
- `getHomeRecentActivities`
- `getHomeGuideByRole`

交付目标：

- 首页可独立加载今日工作区、最近动态、角色化引导

实现重点：

- 角色化聚合
- 轻量筛选
- 统一 controller 返回结构

联调基准：

- `前端接口设计总文档.md`
- `二期接口入参校验与错误码清单.md`

## Task 2. 统计图表接口包

接口范围：

- `getStatsOverviewByDateRange`
- `getStatsTrendByMetric`
- `getStatsRankingByDimension`

交付目标：

- 所有统计图表入口可展示摘要、趋势和排行

实现重点：

- 指标白名单
- 时间范围校验
- 统计粒度与排行维度限制

联调基准：

- `聚合字段实现策略文档.md`
- `二期接口入参校验与错误码清单.md`

## Task 3. 运单详情三层读取包

接口范围：

- `getWaybillDetailV2`
- `getWaybillCustomerLinesByWaybill`
- `getWaybillCustomerGoodsLinesByWaybill`

交付目标：

- 运单详情可切到“概览 / 客户明细 / 货物明细”三层阅读

实现重点：

- `getWaybillDetail` 扩字段兼容
- 子表读取性能
- 客户子表与货物子表关联校验

联调基准：

- `二期接口差异清单.md`
- `前后端接口字段级契约清单.md`

## Task 4. 模板下载与预校验包

接口范围：

- `downloadWaybillStandardTemplate`
- `precheckWaybillStandardImport`

交付目标：

- 用户可以下载标准模板并完成预校验

实现重点：

- 模板版本管理
- 文件类型/大小限制
- 字段级错误反馈
- 分层一致性校验

联调基准：

- `标准订单导入模板字段说明与错误反馈规范.md`
- `二期接口入参校验与错误码清单.md`

## Task 5. 正式导入与结果页包

接口范围：

- `confirmWaybillStandardImport`
- `getWaybillImportResult`

交付目标：

- 预校验通过后可正式导入，并可查看结果页

实现重点：

- `precheck_token` 生命周期
- 导入批次号唯一性
- 结果汇总统计
- 错误报告导出

联调基准：

- `标准订单导入模板字段说明与错误反馈规范.md`
- `前端接口设计总文档.md`

---

## 3. 推荐排期顺序

1. Task 3 运单详情三层读取包
2. Task 1 首页聚合接口包
3. Task 2 统计图表接口包
4. Task 4 模板下载与预校验包
5. Task 5 正式导入与结果页包

说明：

- 运单详情三层读取是二期数据结构升级的基础
- 首页和统计依赖聚合，但与导入链路耦合较低，可并行推进
- 导入链路建议按“模板下载/预校验”先行，再推进正式导入

---

## 4. 当前验收口径

每个任务包至少要产出：

1. 接口路径与方法
2. 入参校验
3. 错误码实现
4. 响应 DTO
5. 一组联调 mock 示例
