## 1. 文档定位

这份文档用于回答二期接口实现前必须收口的 3 个问题：

1. 每个接口的入参要校验什么
2. 校验失败时返回什么错误码
3. 前后端联调时哪些错误属于可预期业务错误，哪些属于系统错误

---

## 2. 通用规则

## 2.1 通用错误返回结构

```json
{
  "code": "INVALID_PARAM",
  "message": "date_from 不能为空",
  "data": null,
  "request_id": "req_demo_001",
  "details": {
    "field": "date_from"
  }
}
```

说明：

- `code`：稳定错误码，供程序判断
- `message`：给页面或日志直接展示
- `details`：可选，用于字段级错误定位

## 2.2 通用错误码清单

| 错误码 | 含义 | 典型场景 |
|---|---|---|
| `INVALID_PARAM` | 通用入参非法 | 缺参、类型错误、非法枚举 |
| `UNAUTHORIZED` | 未登录或身份失效 | 会话失效 |
| `FORBIDDEN` | 无权访问 | 角色权限不足 |
| `OBJECT_NOT_FOUND` | 主对象不存在 | 记录 ID 不存在 |
| `DATE_RANGE_INVALID` | 时间范围非法 | `date_from > date_to` |
| `PAGE_SIZE_TOO_LARGE` | 分页过大 | 超出最大分页限制 |
| `INTERNAL_ERROR` | 系统内部错误 | 未捕获异常 |

## 2.3 通用入参规则

- `page` 默认 `1`，最小 `1`
- `page_size` 默认 `20`
- 列表类接口最大 `page_size` 建议 `100`
- 排行类接口 `top_n` 最大建议 `50`
- `date` 使用 `YYYY-MM-DD`
- `date_from / date_to` 使用 `YYYY-MM-DD`
- `metric_code`、`dimension_code`、`role_code` 必须走白名单枚举

## 3. 接口级校验与错误码

## 3.1 `getHomeOverviewSummary`

### 入参校验规则

- `date` 可空，空时默认当天
- `date` 如传入，必须符合 `YYYY-MM-DD`
- `role_code` 可空，空时取当前登录用户主角色
- `warehouse_id` 可空，如传入必须存在且当前用户可见

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `INVALID_PARAM` | `date` 格式错误 | 非法日期 |
| `WAREHOUSE_NOT_FOUND` | `warehouse_id` 不存在 | 仓库不存在 |
| `FORBIDDEN` | 用户无权查看该仓库 | 权限不足 |

## 3.2 `getHomeRecentActivities`

### 入参校验规则

- `date` 可空，格式同上
- `role_code` 可空
- `limit` 可空，默认 `10`
- `limit` 最大建议 `50`

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `INVALID_PARAM` | `date` 或 `limit` 非法 | 格式或类型错误 |
| `LIMIT_TOO_LARGE` | `limit > 50` | 防止一次取数过大 |

## 3.3 `getHomeGuideByRole`

### 入参校验规则

- `role_code` 可空，空时取当前角色
- `role_code` 如传入必须在允许角色集合中

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `ROLE_CODE_INVALID` | `role_code` 不在白名单 | 非法角色编码 |
| `FORBIDDEN` | 当前用户无权切换查看该角色引导 | 权限不足 |

## 3.4 `getStatsOverviewByDateRange`

### 入参校验规则

- `date_from` 必填
- `date_to` 必填
- `date_from <= date_to`
- 时间跨度建议不超过 `366` 天
- `warehouse_id / customer_id / driver_id` 可空，如传入必须存在且当前用户可见

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `INVALID_PARAM` | `date_from` / `date_to` 缺失或格式错误 | 基础校验失败 |
| `DATE_RANGE_INVALID` | 起止时间反转 | 非法时间范围 |
| `DATE_RANGE_TOO_LARGE` | 超出允许跨度 | 控制统计成本 |
| `WAREHOUSE_NOT_FOUND` | 仓库不存在 | 主数据不存在 |
| `CUSTOMER_NOT_FOUND` | 客户不存在 | 主数据不存在 |
| `DRIVER_NOT_FOUND` | 司机不存在 | 主数据不存在 |
| `FORBIDDEN` | 当前用户无权查看筛选对象 | 权限不足 |

## 3.5 `getStatsTrendByMetric`

### 入参校验规则

- `metric_code` 必填，必须在允许指标集合中
- `granularity` 必填，枚举：`day / week / month`
- `date_from`、`date_to` 必填
- `date_from <= date_to`
- `warehouse_id` 可空

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `METRIC_CODE_INVALID` | 指标编码非法 | 不允许的统计指标 |
| `GRANULARITY_INVALID` | 粒度非法 | 不在允许枚举中 |
| `DATE_RANGE_INVALID` | 时间范围非法 | 起止错误 |
| `DATE_RANGE_TOO_LARGE` | 跨度过大 | 限制趋势计算成本 |
| `FORBIDDEN` | 无权查看当前统计范围 | 权限不足 |

## 3.6 `getStatsRankingByDimension`

### 入参校验规则

- `metric_code` 必填
- `dimension_code` 必填，枚举建议：`customer / store / driver / batch`
- `date_from`、`date_to` 必填
- `top_n` 默认 `10`，最大 `50`

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `METRIC_CODE_INVALID` | 指标非法 | 不允许的指标 |
| `DIMENSION_CODE_INVALID` | 维度非法 | 不允许的维度 |
| `TOP_N_INVALID` | `top_n < 1` 或非整数 | 排名数量非法 |
| `TOP_N_TOO_LARGE` | `top_n > 50` | 防止查询过重 |
| `DATE_RANGE_INVALID` | 时间范围非法 | 起止错误 |

## 3.7 `getWaybillDetailV2`

### 入参校验规则

- `waybill_id` 必填
- `waybill_id` 必须为正整数
- 目标运单必须存在且当前用户可见

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `INVALID_PARAM` | `waybill_id` 缺失或类型错误 | 基础校验失败 |
| `WAYBILL_NOT_FOUND` | 运单不存在 | 主对象不存在 |
| `FORBIDDEN` | 用户无权查看该运单 | 权限不足 |

## 3.8 `getWaybillCustomerLinesByWaybill`

### 入参校验规则

- `waybill_id` 必填
- `page`、`page_size` 按通用分页规则
- 目标运单必须存在且当前用户可见

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `WAYBILL_NOT_FOUND` | 运单不存在 | 主对象不存在 |
| `PAGE_SIZE_TOO_LARGE` | 单页过大 | 分页保护 |
| `FORBIDDEN` | 用户无权查看该运单 | 权限不足 |

## 3.9 `getWaybillCustomerGoodsLinesByWaybill`

### 入参校验规则

- `waybill_id` 必填
- `customer_line_id` 可空
- 如传 `customer_line_id`，必须属于当前 `waybill_id`
- `page`、`page_size` 按通用规则

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `WAYBILL_NOT_FOUND` | 运单不存在 | 主对象不存在 |
| `CUSTOMER_LINE_NOT_FOUND` | 客户子表不存在 | 子对象不存在 |
| `CUSTOMER_LINE_WAYBILL_MISMATCH` | 客户子表不属于当前运单 | 分层关联错误 |
| `PAGE_SIZE_TOO_LARGE` | 单页过大 | 分页保护 |
| `FORBIDDEN` | 用户无权查看该运单 | 权限不足 |

## 3.10 `downloadWaybillStandardTemplate`

### 入参校验规则

- `template_code` 必填
- `template_version` 必填
- 模板编码和版本必须已发布

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `TEMPLATE_CODE_INVALID` | 模板编码不存在 | 非法模板 |
| `TEMPLATE_VERSION_INVALID` | 模板版本不存在 | 非法版本 |
| `TEMPLATE_NOT_PUBLISHED` | 模板未发布 | 当前不可下载 |
| `FORBIDDEN` | 用户无权下载该模板 | 权限不足 |

## 3.11 `precheckWaybillStandardImport`

### 入参校验规则

- 必须上传文件或传入可解析文件令牌
- `template_code`、`template_version` 必填
- 文件类型仅允许 `csv / xlsx`
- 文件大小建议限制在实现侧配置
- 模板编码和版本必须有效

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `UPLOAD_FILE_MISSING` | 未上传文件 | 缺少输入文件 |
| `FILE_TYPE_NOT_SUPPORTED` | 文件类型非法 | 非 `csv/xlsx` |
| `FILE_TOO_LARGE` | 超出大小限制 | 保护服务 |
| `TEMPLATE_CODE_INVALID` | 模板编码非法 | 模板不存在 |
| `TEMPLATE_VERSION_INVALID` | 模板版本非法 | 版本不存在 |
| `TEMPLATE_AND_FILE_MISMATCH` | 文件结构与模板版本不匹配 | 模板校验失败 |
| `PRECHECK_PARSE_FAILED` | 文件解析失败 | 编码或表结构错误 |

## 3.12 `confirmWaybillStandardImport`

### 入参校验规则

- `precheck_token` 必填
- `import_batch_no` 必填
- 预校验结果必须存在且未过期
- 预校验结果必须允许正式导入
- `import_batch_no` 在系统中必须唯一

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `PRECHECK_TOKEN_MISSING` | 缺少预校验令牌 | 必填缺失 |
| `PRECHECK_NOT_FOUND` | 预校验结果不存在 | 令牌非法 |
| `PRECHECK_EXPIRED` | 预校验结果已过期 | 需重新预校验 |
| `PRECHECK_NOT_CONFIRMABLE` | 预校验未通过 | 仍有阻断错误 |
| `IMPORT_BATCH_NO_DUPLICATED` | 导入批次号重复 | 唯一性冲突 |
| `IMPORT_EXECUTION_FAILED` | 正式导入失败 | 执行阶段失败 |

## 3.13 `getWaybillImportResult`

### 入参校验规则

- `import_batch_no` 必填
- 目标导入批次必须存在
- 当前用户必须可见该批次结果

### 业务错误码

| 错误码 | 触发条件 | 说明 |
|---|---|---|
| `IMPORT_BATCH_NO_MISSING` | 缺少导入批次号 | 必填缺失 |
| `IMPORT_RESULT_NOT_FOUND` | 导入结果不存在 | 批次号非法 |
| `FORBIDDEN` | 用户无权查看该导入批次 | 权限不足 |
