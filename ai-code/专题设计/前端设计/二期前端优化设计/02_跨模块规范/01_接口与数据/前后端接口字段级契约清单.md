# 二期前后端接口字段级契约清单

> 状态说明：
> - 本文档只补二期升级接口的字段级契约。
> - 一期未改动的字段契约，继续以一期 `前后端接口字段级契约清单.md` 为准。
> - 当前文档重点覆盖：首页、统计图表、运单详情三层阅读、标准导入模板主路径。

适用范围：
- 二期已明确要新增或升级的数据接口
- 二期后台首页、统计图表、导入结果页和运单详情重构页

关联文档：
- `最终接口总表.md`
- `接口路线决策文档.md`
- `聚合字段实现策略文档.md`

---

## 1. 文档定位

这份文档回答二期接口层最细的一层问题：

1. 新接口最少必须返回哪些字段
2. 哪些字段必须稳定存在
3. 哪些字段允许为空
4. 哪些是二期新增字段，哪些只是一期字段复用

---

## 2. 当前契约原则

### 2.1 一期字段不重写

- 一期已稳定接口字段，除非二期明确升级，否则不在本文件重复展开

### 2.2 二期新增字段优先显式命名

- 首页聚合字段统一用 `*_count`、`*_rate`
- 趋势点字段统一使用 `point_date`、`metric_value`
- 导入结果字段统一使用 `*_row_count`、`*_record_count`

### 2.3 编码和文案分离

- 编码类：`status`、`metric_code`、`dimension_code`
- 文案类：`status_label`、`metric_label`、`dimension_label`

---

## 3. 通用 controller 返回规范

```json
{
  "code": "OK",
  "message": "success",
  "data": {},
  "request_id": "req_demo_001"
}
```

## 4. 二期核心接口字段契约

## 4.1 `getHomeOverviewSummary`

用途：
- 首页今日工作区
- 首页物流核心指标区

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `date` | string | 否 | 默认当天 |
| `role_code` | string | 否 | 当前用户角色 |
| `warehouse_id` | integer | 否 | 仓库过滤 |

返回字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `date` | string | 是 | 统计日期 |
| `role_code` | string | 否 | 当前角色编码 |
| `todo_exception_count` | integer | 是 | 待处理异常数 |
| `todo_evidence_count` | integer | 是 | 待补证据对象数 |
| `todo_waybill_count` | integer | 是 | 待执行运单数 |
| `timeout_risk_waybill_count` | integer | 是 | 超时风险运单数 |
| `signed_rate` | number | 是 | 已签收率，`0~1` |
| `evidence_completion_rate` | number | 是 | 证据补齐率，`0~1` |
| `exception_waybill_rate` | number | 是 | 异常运单率，`0~1` |
| `store_signoff_rate` | number | 否 | 门店签收完成率 |
