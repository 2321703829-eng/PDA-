# 六期前端优化设计

本目录承载六期前端优化资料，是 `专题设计/前端设计/` 的第六阶段正式入口。

## 当前重点

- 以“页面结构轻量化”和“物流模块边界减重”为当前主方向。
- 让用户在高频操作中可以更直接进入物流工作区，同时不给后续仓管等相邻模块造成入口和结构挤压。
- 六期目录先按统一阶段结构搭好，后续页面方案、导航方案、联调清单按标准位置继续沉淀。

## 建议阅读顺序

1. `00_导航与总纲/`
2. `01_专题方案/`
3. `02_跨模块规范/`
4. `02_验收与联调/`
5. `03_模板与样例/`
6. `05_提交包/`

## 层级口径

- 物理目录保留 `02_验收与联调/` 历史编号。
- 阅读时统一按逻辑层级 `03_联调验收层` 理解。

## 目录说明

- `00_导航与总纲/`：放六期总目标、范围、阅读顺序、结论摘要。
- `01_专题方案/`：放页面结构、导航重构、工作区拆分等专题设计稿。
- `02_跨模块规范/01_接口与数据/`：放模块入口 DTO、菜单路由、统计聚合取数等接口约束。
- `02_跨模块规范/02_交互与组件/`：放页面框架、导航交互、模块切换与组件复用规范。
- `02_验收与联调/`：放开发任务拆分、联调清单、验收口径与问题回收记录。
- `03_模板与样例/`：放线框草图、导航样图、模块结构对照样例。
- `04_来源资料与历史草图/`：放外部来源资料、旧版草图、过程记录。
- `05_提交包/`：放阶段总结、评审摘要、汇报材料。
- `99_待归档/`：放临时文件与待归档材料。
