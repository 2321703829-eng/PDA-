# 三期司机管理联调与验收清单

## 文档定位

- 本文件用于将三期司机管理专题拆成可直接联调、自测和人工勾验的验收清单
- 它服务于司机管理专题从设计进入实现后的页面联调、接口联调和回归核验

## 阅读关系

1. 先读 `../01_专题方案/2026-04-16_Odoo物流后台员工模块分层与司机管理专题方案.md`
2. 再读 `../02_跨模块规范/01_接口与数据/2026-04-16_三期司机管理接口补充清单.md`
3. 再读 `../02_跨模块规范/02_交互与组件/2026-04-16_三期司机管理交互与组件说明.md`
4. 再读 `../02_跨模块规范/03_权限与状态/三期司机管理权限与状态说明.md`
5. 然后按本清单逐项核验当前实现

## 适用边界说明

- 本清单只核验三期司机管理专题当前约定范围是否实现
- 本清单不扩展车队管理完整台账，不扩展后台工作人员管理完整专题
- 本清单不替代后续更细的后端测试用例、权限自动化测试和企业分离方案验收

---

## Objective

将三期司机管理专题拆成一份可直接勾选的联调与人工验收清单，重点核验下面 5 类内容：

1. 司机管理入口与页面结构
2. 司机列表页显示与交互
3. 司机画像详情页 6 大区块
4. 司机相关接口与下钻闭环
5. 司机管理页的权限显示与状态口径

---

## Boundary

本验收单只覆盖：

- 司机管理入口
- 司机列表页
- 司机画像详情页
- 司机关联运单 / 异常下钻页
- 司机专题相关接口、交互、权限、状态

本验收单不覆盖：

- 企业分离功能中的套餐能力层
- 数据范围层的完整记录规则验收
- 多公司 `multi-company`
- 车队管理历史车辆关系完整页

---

## 核验前准备

1. 确认本轮已实现司机管理相关页面与接口
2. 确认前端已按三期司机管理专题文档完成基本接线
3. 确认浏览器已强刷缓存，例如：
   `Ctrl + F5`
4. 建议准备至少 3 类司机样例数据：
   - 正常活跃司机
   - 高风险司机
   - 停用司机
5. 建议准备至少 2 类边界样例数据：
   - 无关联异常司机
   - 无执行记录或近 7 天无执行司机

## 四、下钻与联调闭环验收

### 1. 顶部按钮下钻

- [ ] 点击 `查看关联运单` 可进入当前司机运单列表
- [ ] 点击 `查看关联异常` 可进入当前司机异常列表
- [ ] 点击 `返回司机列表` 后可保留原筛选和排序状态

### 2. KPI 卡片下钻

- [ ] 点击 `本月运单量` 可进入当前司机本月运单列表
- [ ] 点击 `月均异常率` 可进入当前司机异常运单列表
- [ ] 点击 `当前月签收率` 可进入当前司机签收相关运单列表
- [ ] 点击 `当前月超时率` 可进入当前司机超时运单列表
- [ ] 点击 `缺证据率` 可进入当前司机缺证据运单列表
- [ ] 点击 `关联异常数` 可进入当前司机异常列表

### 3. 趋势图下钻

- [ ] 点击月度运单量趋势点位，可进入对应月份运单列表
- [ ] 点击异常率趋势点位，可进入对应月份异常运单列表
- [ ] 点击签收率趋势点位，可进入对应月份签收相关运单列表
- [ ] 点击超时率趋势点位，可进入对应月份超时运单列表
- [ ] 下钻后的页面标题或筛选条件中可感知“司机 + 时间范围”来源

### 4. 表格下钻

- [ ] 点击最近运单中的运单号，可进入运单详情页
- [ ] 点击最近异常中的异常编号，可进入异常详情页
- [ ] 点击最近异常中的运单号，可进入运单详情页
- [ ] `查看全部` 能跳到当前司机的完整运单或异常列表

## 八、建议联调顺序

建议按下面 4 个阶段推进：

1. `L1` 司机列表页  
   先把搜索、筛选、排序和列表展示跑通

2. `L2` 司机画像页首屏  
   先联顶部对象头、指标带和执行概览区

3. `L3` 司机画像页趋势与风险区  
   再联趋势图、风险摘要、异常类型摘要和最近异常

4. `L4` 下钻与权限回归  
   最后联下钻列表、查看全部、权限显示和状态边界
