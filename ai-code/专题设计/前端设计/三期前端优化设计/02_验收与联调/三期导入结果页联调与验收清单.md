# 三期导入结果页联调与验收清单

## 文档定位

- 本文件用于将三期承接的“导入结果页页面化”拆成可直接联调、自测和人工勾验的验收清单
- 它服务于二期导入结果能力并入三期后的页面联调、接口联调和回归核验

## 阅读关系

1. 先读 `三期前端落地与联调说明.md`
2. 再读 `../02_跨模块规范/01_接口与数据/三期接口口径统一与结果页补充说明.md`
3. 再读 `../02_跨模块规范/02_交互与组件/三期导入结果页交互与组件说明.md`
4. 再读 `../../二期前端优化设计/01_专题方案/2026-04-15_Odoo物流后台导入导出体验优化方案.md`
5. 然后按本清单逐项核验当前实现

## 适用边界说明

- 本清单只核验三期承接的运单标准导入结果页页面化范围
- 本清单不扩展导入历史中心、导入审计中心和非运单对象导入结果页
- 本清单不替代更细的后端测试用例、错误报告文件内容校验和性能压测报告

---

## Objective

将三期承接的导入结果页页面化任务拆成一份可直接勾选的联调与人工验收清单，重点核验下面 6 类内容：

1. 结果页进入路径与页面结构
2. 结果页 5 个固定区块
3. 结果页 4 个核心动作与跳转闭环
4. 成功、失败、空态、批次不存在、接口报错等状态反馈
5. 结果接口复用与最小扩字段联调
6. 与现有导入中心和运单列表的回归兼容性

---

## Boundary

本验收单只覆盖：

- 运单标准导入结果页
- 结果页的顶部结果头、摘要卡、批次信息区、动作区、失败说明区
- `GET /api/admin/logistics/imports/waybill-standard/result`
- 错误报告下载入口
- 从结果页进入运单列表和返回导入中心的闭环

本验收单不覆盖：

- 运单标准导入模板下载页
- 导入预校验与正式导入提交流程本身
- 导入历史列表页
- 非运单对象导入能力扩建

---

## 核验前准备

1. 确认本轮已实现导入结果页相关页面与接口接线
2. 确认前端已按三期导入结果页接口稿和交互稿完成基本接线
3. 确认浏览器已强刷缓存，例如：
   `Ctrl + F5`
4. 建议准备至少 3 类样例数据：
   - 导入成功批次
   - 导入部分失败批次
   - 导入整体失败批次
5. 建议准备至少 2 类边界样例数据：
   - 批次不存在或结果不可读
   - 当前批次无错误报告

## 一、进入路径与页面结构联调

### 1. 进入路径

- [ ] 导入中心完成导入后，可进入结果页
- [ ] 从导入中心已有结果区或结果链接，可进入结果页
- [ ] 当前未新增全局菜单直达结果页入口
- [ ] 当前未误扩成导入历史中心入口

### 2. 页面结构

- [ ] 结果页第一页固定为 5 个区块
- [ ] 5 个区块顺序为：
  - 顶部结果头
  - 结果摘要卡区
  - 文件与批次信息区
  - 后续动作区
  - 失败说明 / 错误报告区
- [ ] 页面不是简单复刻导入中心内嵌结果区
- [ ] 页面没有扩成逐条错误明细工作台

---

## 二、顶部结果头验收

### 1. 展示字段

- [ ] 展示 `import_batch_no`
- [ ] 展示 `status_label`
- [ ] 展示 `template_code`
- [ ] 展示 `template_version`
- [ ] 页面存在一句结果摘要文案

### 2. 状态标签

- [ ] `finished` 显示为成功态
- [ ] `processing` 显示为进行态
- [ ] `failed` 显示为失败态
- [ ] 如当前实现支持 `partially_finished`，其样式与 `failed` 明显区分

### 3. 顶部动作

- [ ] 存在 `刷新结果`
- [ ] 存在 `下载错误报告`
- [ ] 存在 `进入运单列表`
- [ ] 存在 `按导入批次继续核验`

---

## 三、结果摘要卡与批次信息区验收

### 1. 摘要卡区

- [ ] 第一版摘要区固定为 6 张卡或等价 6 格统计位
- [ ] 存在 `总行数`
- [ ] 存在 `通过行数`
- [ ] 存在 `失败行数`
- [ ] 存在 `新建运单数`
- [ ] 存在 `新建客户明细数`
- [ ] 存在 `新建货物明细数`
- [ ] 缺失值显示为 `--`
- [ ] 0 值正常显示为 `0`

### 2. 文件与批次信息区

- [ ] 展示 `file_name`
- [ ] 展示 `template_code`
- [ ] 展示 `template_version`
- [ ] 展示 `import_batch_no`
- [ ] 展示 `confirmed_at`
- [ ] 展示 `finished_at`
- [ ] 信息区为阅读型信息卡，而不是伪装成表单

---

## 四、动作与跳转闭环验收

### 1. 刷新结果

- [ ] 点击 `刷新结果` 会重新请求结果接口
- [ ] 刷新期间优先为区块级加载，而不是整页白屏
- [ ] 刷新失败时有明确错误提示

### 2. 下载错误报告

- [ ] `error_report_url` 存在时，`下载错误报告` 可点
- [ ] 当前批次无错误报告时，按钮为禁用态而不是直接消失
- [ ] 禁用态文案或提示为：`当前批次无错误报告`
- [ ] 点击后可正常下载错误报告文件

### 3. 进入运单列表

- [ ] 存在成功写入记录时，`进入运单列表` 可点
- [ ] 点击后进入运单列表页
- [ ] 点击后优先带上当前 `import_batch_no` 相关筛选

### 4. 按导入批次继续核验

- [ ] 点击后进入带当前批次条件的运单列表
- [ ] 当前未新开专门“核验工作台”
- [ ] 下钻后的列表页中可感知当前导入批次来源

### 5. 返回行为

- [ ] 从结果页返回上一页时，优先回到导入中心原有上下文
- [ ] 从外部直接进入结果页时，不强制做复杂返回记忆

---

## 五、失败说明与状态反馈验收

### 1. 失败说明区

- [ ] `failure_reason` 有值时，失败说明区会展示
- [ ] `failed_record_count > 0` 时，失败说明区会展示
- [ ] `error_report_url` 存在时，失败说明区中存在错误报告入口
- [ ] 当前未在页内展开逐条错误表格

### 2. 成功态

- [ ] 成功态文案能明确提示可继续前往运单列表核验结果
- [ ] 成功态下失败说明区可折叠为轻量提示

### 3. 失败态

- [ ] 失败态文案能明确提示先查看失败原因和错误报告
- [ ] 失败态下失败说明区默认展开

### 4. 空态

- [ ] 结果为空时，空态文案为 `当前批次暂无可展示的导入结果。`
- [ ] 空态下仍保留 `刷新结果`
- [ ] 空态下仍保留 `返回导入中心` 或等价返回动作

### 5. 批次不存在与接口报错

- [ ] 批次不存在时，文案为 `当前导入批次不存在，或结果已不可查看。`
- [ ] 接口失败时，文案为 `导入结果加载失败，请刷新后重试。`
- [ ] 错误态不会吞掉当前批次号上下文

### 6. 无权限态

- [ ] 无权限态文案为 `当前账号暂无查看导入结果的权限。`

---

## 六、接口联调清单

### 1. 路由复用

- [ ] 结果页继续复用 `GET /api/admin/logistics/imports/waybill-standard/result`
- [ ] 当前未为结果页新开 `detail` 或 `review` 类路由
- [ ] 当前未改写既有导入主路径前缀

### 2. 返回结构

- [ ] 返回包继续沿用导入域当前 `code: 0/1` 口径
- [ ] `data.import_batch_no` 可正常返回
- [ ] `data.status` 可正常返回
- [ ] `data.status_label` 可正常返回
- [ ] `data.error_report_url` 可正常返回
- [ ] `data.failure_reason` 可正常返回

### 3. 最小扩字段

- [ ] `template_code` 已返回或前端已有稳定兜底
- [ ] `template_version` 已返回或前端已有稳定兜底
- [ ] `file_name` 已返回或前端已有稳定兜底
- [ ] `total_row_count` 已返回或前端已有稳定兜底
- [ ] `passed_row_count` 已返回或前端已有稳定兜底
- [ ] `failed_row_count` 已返回或前端已有稳定兜底
- [ ] `confirmed_at` 已返回或前端已有稳定兜底
- [ ] `finished_at` 已返回或前端已有稳定兜底

---

## 七、回归兼容性验收

### 1. 导入中心回归

- [ ] 导入中心原有模板下载能力未受影响
- [ ] 导入中心原有预校验能力未受影响
- [ ] 导入中心原有正式导入提交流程未受影响
- [ ] 导入中心原有结果查询能力未受影响

### 2. 结果链路回归

- [ ] 错误报告下载链路未受影响
- [ ] 结果页不会要求重新建立第二套导入 service
- [ ] 结果页与导入中心之间不存在双份结果状态字典冲突

### 3. 运单列表回归

- [ ] 从结果页进入运单列表不会破坏原有运单列表筛选能力
- [ ] 批次筛选或批次来源提示不会破坏原有运单列表阅读体验

---

## 八、当前结论建议

当下面 5 条同时满足时，可认为“导入结果页页面化”已经达到三期可联调状态：

- [ ] 结果页继续复用现有结果接口
- [ ] 页面 5 个区块已全部落地
- [ ] 4 个核心动作都已可用且跳转闭环成立
- [ ] 成功、失败、空态、批次不存在、接口报错 5 类状态均有清晰反馈
- [ ] 导入中心与运单列表未出现明显回归问题
