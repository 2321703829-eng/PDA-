# 三期统计图表联调与验收清单

## 文档定位

- 本文件用于将三期统计图表专题拆成可直接联调、自测和人工勾验的验收清单
- 它服务于三期统计图表专题从设计进入实现后的页面联调、接口联调和回归核验

## 阅读关系

1. 先读 `../01_专题方案/2026-04-16_Odoo物流后台统计图表专题方案.md`
2. 再读 `../01_专题方案/2026-04-16_三期统计图表第一版保留清单.md`
3. 再读 `../02_跨模块规范/01_接口与数据/2026-04-16_三期统计指标字典讨论版.md`
4. 再读 `../02_跨模块规范/01_接口与数据/2026-04-16_三期统计图表接口补充清单.md`
5. 再读 `../02_跨模块规范/02_交互与组件/2026-04-16_三期统计图表交互与组件说明.md`
6. 然后按本清单逐项核验当前实现

## 适用边界说明

- 本清单只核验三期全局统计图表页当前约定范围是否实现
- 本清单不扩展司机画像详情页中的个人趋势图区
- 本清单不替代后续更细的后端测试用例、权限自动化测试和性能压测报告
- 本清单不展开企业分离方案下的套餐能力层与跨租户统计权限验收

---

## Objective

将三期统计图表专题拆成一份可直接勾选的联调与人工验收清单，重点核验下面 6 类内容：

1. 统计入口与页面结构
2. 全局统计页 4 大分组与 10 张正式图表
3. 图表交互、下钻和页面状态反馈
4. 统计接口与图表映射闭环
5. 指标口径与页面边界是否一致
6. `P0 / P1` 分期落地是否清晰

---

## Boundary

本验收单只覆盖：

- 全局统计图表入口
- 全局统计图表第一页
- `执行概览 / 风险概览 / 司机与资源 / 区域与质量` 4 组
- 三期第一版正式保留的 10 张图
- 统计页相关接口、交互、下钻和口径

本验收单不覆盖：

- 司机画像页中的个人趋势图
- 自定义报表编辑能力
- 多租户跨企业汇总统计
- 更复杂的经营报表和计费型报表体系

---

## 核验前准备

1. 确认本轮已实现三期统计图表页相关页面与接口
2. 确认前端已按三期统计专题文档完成基本接线
3. 确认浏览器已强刷缓存，例如：
   `Ctrl + F5`
4. 建议准备至少 5 类样例数据：
   - 正常业务波动样例
   - 异常高发时段样例
   - 高风险批次样例
   - 高风险司机样例
   - 不同门店地区分布样例
5. 建议准备至少 2 类边界样例数据：
   - 当前时间范围内无执行数据
   - 当前时间范围内无异常或无地区分布数据

## 一、入口与结构联调

### 1. 统计入口

- [ ] 统计图表作为独立入口可进入
- [ ] 统计图表入口与司机画像页入口未混用
- [ ] 允许角色可以看到统计入口
- [ ] 无权限角色不显示统计入口，或进入后有明确权限提示

### 2. 页面结构

- [ ] 进入统计图表页后，第一页结构为 4 大分组
- [ ] 分组顺序为：
  - 执行概览
  - 风险概览
  - 司机与资源
  - 区域与质量
- [ ] 页面不是图表无序平铺
- [ ] 页面头部存在标题区
- [ ] 页面头部存在轻量筛选栏
- [ ] 页面头部存在刷新动作

---

## 二、全局筛选与页面级交互验收

### 1. 全局筛选栏

- [ ] 存在时间范围筛选
- [ ] 如当前实现支持粒度切换，存在按 `日 / 周 / 月` 切换
- [ ] 筛选栏未堆叠过多对象级复杂筛选器
- [ ] 当前未出现未冻结的多层联动筛选器

### 2. 页面状态反馈

- [ ] 页面允许先出整体骨架，再逐区块加载
- [ ] 图表页优先采用区块级空态，不出现整页空白
- [ ] 图表页优先采用区块级错误，不因单图失败拖垮整页
- [ ] 无权限态文案为：`当前账号暂无查看统计图表的权限。`

## 三、4 大分组与图表验收

### 1. 执行概览区

- [ ] 存在 `运单量趋势折线图`
- [ ] 存在 `运单签收率 + 超时率双折线图`
- [ ] 本区只承接执行量和履约质量，不混入司机个人趋势图
- [ ] 本区空态文案为：`当前时间范围内暂无执行数据。`
- [ ] 本区错误态文案为：`执行概览加载失败，请稍后重试。`

### 2. 风险概览区

- [ ] 存在 `异常总量趋势折线图`
- [ ] 存在 `异常类型分布图`
- [ ] 存在 `高风险批次排行图`
- [ ] 本区空态文案为：`当前暂无风险相关统计数据。`
- [ ] 本区错误态文案为：`风险概览加载失败，请稍后重试。`

### 3. 司机与资源区

- [ ] 本区第一版只保留 `司机月均异常率排行图`
- [ ] 本区未放入司机个人趋势图
- [ ] 点击司机排行项可进入司机画像详情页
- [ ] 本区空态文案为：`当前暂无可展示的司机风险排行。`
- [ ] 本区错误态文案为：`司机与资源统计加载失败，请稍后重试。`

### 4. 区域与质量区

- [ ] 存在 `地区运单量分布图`
- [ ] 存在 `地区异常率排行图`
- [ ] 存在 `地区签收率对比图`
- [ ] 存在 `缺证据率 + 缺证据运单数双指标趋势图`

- [ ] 本区空态文案为：`当前暂无地区与质量相关统计数据。`
- [ ] 本区错误态文案为：`区域与质量统计加载失败，请稍后重试。`

## 五、图表交互与下钻闭环验收

### 1. 趋势图下钻

- [ ] 点击 `运单量趋势折线图` 的时间点，可进入对应时间范围运单列表
- [ ] 点击 `运单签收率 + 超时率双折线图` 中签收率点位，可进入签收相关运单列表
- [ ] 点击 `运单签收率 + 超时率双折线图` 中超时率点位，可进入超时运单列表
- [ ] 点击 `异常总量趋势折线图` 的时间点，可进入对应时间范围异常列表
- [ ] 点击 `缺证据率 + 缺证据运单数双指标趋势图` 的时间点，可进入缺证据运单列表

### 2. 分布图下钻

- [ ] 点击 `异常类型分布图` 某分类，可进入对应异常类型列表
- [ ] 点击 `地区运单量分布图` 某地区，可进入对应地区运单列表

### 3. 排行图下钻

- [ ] 点击 `高风险批次排行图` 某批次，可进入批次详情或批次异常运单列表
- [ ] 点击 `司机月均异常率排行图` 某司机，可进入司机画像详情页
- [ ] 点击 `地区异常率排行图` 某地区，可进入地区异常运单列表
- [ ] 点击 `地区签收率对比图` 某地区，可进入地区签收 / 未签收运单列表

### 4. 下钻表现

- [ ] 下钻目标优先进入可继续处理的列表页或详情页
- [ ] 不出现大量跳往抽象中间页的情况
- [ ] 返回上一页后，尽量保留原筛选和阅读位置

## 六、图表组件与视觉规则验收

### 1. 图表卡容器

- [ ] 所有图表都放在统一图表卡容器中
- [ ] 图表标题位置统一
- [ ] 副标题或小说明位置统一
- [ ] 图表卡内边距统一
- [ ] 空态与错误态占位位置统一

### 2. 趋势图卡

- [ ] `运单签收率 + 超时率双折线图` 支持图例开关或等价交互
- [ ] `缺证据率 + 缺证据运单数双指标趋势图` 支持双指标展示
- [ ] 趋势图 tooltip 样式统一
- [ ] 双指标图颜色区分清楚，不出现两条线难辨识问题

### 3. 分布图卡

- [ ] 分类标签清楚可读
- [ ] 点击态明确
- [ ] 不存在过重装饰和过多分类颜色

### 4. 排行图卡

- [ ] 排行项对象名称清楚
- [ ] 数值与标签层级清晰
- [ ] 排行项点击态明显

### 5. 风险色使用

- [ ] 风险色使用克制，不出现整页高饱和警告色
- [ ] 风险色主要用于异常、排行对象和风险点

## 八、指标口径与页面边界验收

### 1. 指标口径

- [ ] 运单、司机、地区相关统计默认按 `delivery_date`
- [ ] 异常总量和异常类型按 `exception.report_time`
- [ ] 客户与地区相关统计按 `customer_line`
- [ ] 地区主口径统一挂在 `门店地区`
- [ ] 缺证据统一包含 `missing + partial`

### 2. 高风险批次排序口径

- [ ] 高风险批次排行按 `批次异常率 -> 严重异常数 -> 超时运单数`
- [ ] 当前实现未擅自改成单纯按异常数排序

### 3. 司机边界

- [ ] 全局统计页中的司机图表只保留 `司机月均异常率排行图`
- [ ] 司机个人趋势图未被放回全局统计页
- [ ] 点击司机排行后进入司机画像详情页，而不是继续在统计页内堆单司机趋势

## 九、建议联调顺序

建议按下面 4 个阶段推进：

1. `L1` 页面骨架与分组  
   先联入口、页面头部、4 大分组和基础骨架

2. `L2` P0 图表与基础下钻  
   先联 `P0 8 张图` 和它们的基础下钻

3. `L3` P1 图表与双指标表现  
   再联 `地区签收率对比图` 与 `缺证据双指标趋势图`

4. `L4` 口径回归与边界核验  
   最后核验指标字典、司机边界、地区口径和异常处理回归
