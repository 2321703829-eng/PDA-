# 2026-04-16 三期统计图表第一版保留清单

## 文档定位

- 本文件用于收口三期统计图表模块第一版的候选保留清单
- 当前结论基于三期方向讨论形成，用于后续继续细化图表专题方案

## 当前范围

本轮清单重点覆盖：

- 运单执行质量
- 批次风险
- 司机管理与绩效
- 异常与证据
- 客户与地区维度风险

本轮不展开：

- 最终图表样式稿
- 指标字典正式定义
- 接口字段和聚合 SQL 细节

## 1. 第一版保留清单

说明：

- 本清单中的“统计图表第一版”专指全局统计图表页面
- 司机个人趋势图已从全局统计页中拆出，转入司机画像详情页承接

### 1.1 运单执行类

1. `运单量趋势折线图`
   - 目的：看整体业务量变化
   - 统计口径：按日 / 周 / 月统计运单数
   - 下钻：点击时间点进入对应时间范围的运单列表

2. `运单签收率 + 超时率双折线图`
   - 目的：同时看履约质量和执行风险
   - 统计口径：按日 / 周 / 月统计签收率、超时率
   - 下钻：点击时间点进入对应时间范围的已签收 / 超时运单列表

### 1.2 批次风险类

3. `高风险批次排行图`
   - 目的：快速锁定最需要关注的批次
   - 统计口径：按异常率、异常数或风险分排序
   - 下钻：点击批次进入批次详情或批次异常运单列表

### 1.3 司机管理类

4. `司机月均异常率排行图`
   - 目的：看司机风险表现
   - 统计口径：按司机统计月均异常率
   - 下钻：点击司机进入司机画像页或司机关联异常列表

### 1.4 异常与证据类

5. `异常总量趋势折线图`
    - 目的：看问题总量变化
    - 统计口径：按日 / 周 / 月统计异常数
    - 下钻：点击时间点进入对应时间范围的异常列表

6. `异常类型分布图`
    - 目的：看问题主要集中在哪些类型
    - 统计口径：按异常类型统计数量占比
    - 下钻：点击某异常类型进入对应异常列表

7. `缺证据率 + 缺证据运单数双指标趋势图`
   - 目的：同时看缺证据问题的比例和规模
   - 统计口径：按日 / 周 / 月统计缺证据率和缺证据运单数
   - 下钻：点击时间点进入对应时间范围的缺证据运单列表

### 1.5 客户与地区类

8. `地区运单量分布图`
    - 目的：看各地区业务量分布
    - 统计口径：按门店地区统计运单数
    - 下钻：点击地区进入该地区运单列表

9. `地区异常率排行图`
    - 目的：看各地区风险差异
    - 统计口径：按地区统计异常率
    - 下钻：点击地区进入该地区异常运单列表

10. `地区签收率对比图`
    - 目的：看各地区履约质量差异
    - 统计口径：按地区统计签收率
    - 下钻：点击地区进入该地区签收 / 未签收运单列表

## 4. 当前补充结论

1. 原先讨论中的 `运单来源/类型分布图`，当前不再按获客渠道或业务来源理解
2. 结合物流公司管理视角，统一调整为地区维度统计
3. 当前建议统一采用“门店地区”作为地区统计主口径
4. 司机相关图表中，全局统计页只保留 `司机月均异常率排行图`
5. 司机个人趋势图改为放入司机画像详情页，不再放进全局统计图表页
6. 证据相关指标已统一围绕“缺证据运单”口径收口，不再分散使用“补齐率 / 缺失率 / 缺失订单数”三套平级概念
7. 全局统计页第一页已明确按 `执行概览 / 风险概览 / 司机与资源 / 区域与质量` 四组组织
8. 当前正式保留图表已收口为 `10 张`，并按 `P0 8 张 + P1 2 张` 推进
