# 三期页面逐项勾验记录模板

## 用途

- 本模板用于记录三期页面人工验收过程中的逐项勾验结果。
- 适合配合：
  - `../02_验收与联调/三期界面系统化美化人工验收执行顺序.md`
  - `../02_验收与联调/三期界面系统化美化联调与验收清单.md`

## 使用建议

1. 每个页面复制一份本模板
2. 每个宽度单独记录一次
3. 有问题就写清“问题现象 + 优先级 + 是否阻断”

---
