## Current Understanding

当前三期统计图表方向已经冻结了下面这些前提：

1. 全局统计页第一页统一按 `执行概览 / 风险概览 / 司机与资源 / 区域与质量` 4 组组织
2. 第一版正式保留图表共 `10 张`
3. `P0` 先做 `8 张`，`P1` 再补 `2 张`
4. 全局统计页中的司机图只保留 `司机月均异常率排行图`
5. 司机个人趋势图统一留在司机画像详情页
6. 统计图表必须支持下钻，但应优先下钻到可继续行动的列表页或对象页

因此本文件的核心任务，不是重新讨论统计专题范围，而是把这些结论变成可直接指导页面设计和开发实现的交互规则。

## 1. 页面级交互规则

### 1.1 页面定位

全局统计页统一定位为：

- 物流分析中心
- 运营管理与管理层的全局分析入口
- 先看趋势和风险，再下钻对象和列表的页面

它不是：

- 单对象画像页
- 简单的 dashboard 摘要页
- 可自由拼报表的 BI 工具台

### 1.2 页面头部

页面头部固定由下面 3 类组件组成：

- 页面标题区
- 全局筛选栏
- 刷新动作

标题区建议承担：

- 页面命名
- 一句副标题，告诉用户先看什么

### 1.3 全局筛选栏

第一版建议保留轻量筛选，不把统计页做成复杂查询器。

建议保留：

- 时间范围
- 粒度切换（按日 / 周 / 月，如当前实现需要）
- 刷新

当前不建议第一版强行放入：

- 过多对象筛选器
- 多层联动筛选
- 自定义报表维度组合器

说明：

- 对象维度下钻优先通过点图进入列表，不优先在统计页先堆一排复杂筛选

### 1.4 页面状态反馈

加载态：

- 允许整页先出骨架布局，再逐区块填充

空态：

- 统计页原则上优先使用区块级空态，不建议整页直接空白

错误态：

- 区块级错误优先，不要一张图加载失败就拖垮整页

无权限态：

- `当前账号暂无查看统计图表的权限。`

## 2. 页面分组与区块组件

全局统计页第一页固定由 4 组图表区组成：

1. 执行概览
2. 风险概览
3. 司机与资源
4. 区域与质量

---

## 3. 执行概览区

### 3.1 组件组成

执行概览区建议由下面 2 张图表卡组成：

1. `运单量趋势折线图`
2. `运单签收率 + 超时率双折线图`

### 3.2 交互规则

- 2 张图都应支持时间点下钻
- `签收率 + 超时率双折线图` 需支持图例开关
- tooltip 中建议同时展示时间点和核心值

### 3.3 下钻目标

- `运单量趋势折线图` -> 对应时间范围的运单列表
- `运单签收率 + 超时率双折线图`
  - 点击签收率点位 -> 对应时间范围的签收相关运单列表
  - 点击超时率点位 -> 对应时间范围的超时运单列表

### 3.4 空态 / 错误态

空态：

- `当前时间范围内暂无执行数据。`

错误态：

- `执行概览加载失败，请稍后重试。`

---

## 4. 风险概览区

### 4.1 组件组成

风险概览区固定由下面 3 张图表卡组成：

1. `异常总量趋势折线图`
2. `异常类型分布图`
3. `高风险批次排行图`

### 4.2 交互规则

- 异常总量趋势图支持时间点下钻
- 异常类型分布图支持点分类下钻
- 高风险批次排行图支持点排行对象下钻

### 4.3 下钻目标

- `异常总量趋势折线图` -> 对应时间范围的异常列表
- `异常类型分布图` -> 对应异常类型的异常列表
- `高风险批次排行图` -> 批次详情页或批次异常运单列表

### 4.4 空态 / 错误态

空态：

- `当前暂无风险相关统计数据。`

错误态：

- `风险概览加载失败，请稍后重试。`

---

## 5. 司机与资源区

### 5.1 组件组成

本区第一版固定只保留 1 张图：

- `司机月均异常率排行图`

### 5.2 交互规则

- 图表使用排行卡或横向条形排行图均可
- 每项必须可点击
- 本区只做横向比较，不承接单司机纵向趋势

### 5.3 下钻目标

- 点击司机 -> 司机画像详情页

### 5.4 空态 / 错误态

空态：

- `当前暂无可展示的司机风险排行。`

错误态：

- `司机与资源统计加载失败，请稍后重试。`

---

## 6. 区域与质量区

### 6.1 组件组成

本区由下面 4 张图表卡组成：

1. `地区运单量分布图`
2. `地区异常率排行图`
3. `地区签收率对比图`
4. `缺证据率 + 缺证据运单数双指标趋势图`

### 6.2 交互规则

- 地区维度图统一围绕 `门店地区`
- 点地区 -> 下钻地区相关列表
- `缺证据率 + 缺证据运单数双指标趋势图` 需支持双指标展示与时间点下钻

### 6.3 下钻目标

- `地区运单量分布图` -> 地区运单列表
- `地区异常率排行图` -> 地区异常运单列表
- `地区签收率对比图` -> 地区签收 / 未签收运单列表
- `缺证据率 + 缺证据运单数双指标趋势图` -> 对应时间范围的缺证据运单列表

### 6.4 空态 / 错误态

空态：

- `当前暂无地区与质量相关统计数据。`

错误态：

- `区域与质量统计加载失败，请稍后重试。`

## 7. 统一下钻规则

全局统计页统一遵守下面 3 条下钻规则：

1. 点趋势图时间点 -> 进入对应时间范围的业务列表
2. 点排行对象 -> 进入对象详情页或对象关联列表
3. 点分布图分类 -> 进入该分类筛选后的列表

设计原则：

- 优先跳“可继续处理”的列表页或详情页
- 不优先跳抽象中间页
- 返回上一页时，应尽量保留原筛选与原阅读位置

## 8. 图表组件样式规则

### 8.1 页面层级

视觉层级统一为：

1. 页面标题
2. 分组标题
3. 图表标题
4. 图表主值 / 排行值
5. 辅助说明

### 8.2 图表卡容器

全局统计页所有图都应放入统一图表卡容器中。

统一规则：

- 标题位置一致
- 副标题或小说明位置一致
- 图表内边距一致
- 空态与错误态占位位置一致

### 8.3 趋势图卡

适用：

- 运单量趋势图
- 签收率 + 超时率双折线图
- 异常总量趋势图
- 缺证据双指标趋势图

统一规则：

- 顶部包含图表标题
- tooltip 样式统一
- 双指标图颜色对比清楚
- 图例开关位置固定

### 8.4 分布图卡

适用：

- 异常类型分布图
- 地区运单量分布图

统一规则：

- 分类标签清楚
- 点击态明确
- 不使用过重装饰和过多分类颜色

### 8.5 排行图卡

适用：

- 高风险批次排行图
- 司机月均异常率排行图
- 地区异常率排行图
- 地区签收率对比图

统一规则：

- 排行项主对象名称清晰
- 数值和标签分层明确
- 点击态明显

### 8.6 风险色使用规则

建议统一使用克制的风险配色：

- 正常 / 中性：基础色
- 中风险：橙色
- 高风险：红色

说明：

- 不要整页大量高饱和风险色
- 风险色优先用于排行对象、风险点和异常相关图

## 10. 与司机画像页的边界说明

为避免和司机管理专题冲突，全局统计页中的司机相关图表固定遵守下面结论：

1. 全局统计页只保留 `司机月均异常率排行图`
2. 司机个人趋势图不再放入全局统计页
3. 单司机纵向趋势统一转入司机画像详情页

结论：

- 统计页负责横向比较
- 画像页负责单对象纵向解释
