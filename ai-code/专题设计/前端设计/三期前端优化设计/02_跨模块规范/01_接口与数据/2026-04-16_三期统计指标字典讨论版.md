## 1. 全局冻结规则

### 1.1 有效对象范围

默认排除：

- `draft`
- `cancelled`

### 1.2 时间基准

- 运单类：`delivery_date`
- 批次类：按批次关联运单的 `delivery_date`
- 异常总量 / 异常类型：`exception.report_time`
- 异常关闭时长：`exception.close_time`
- 司机类：运单 `delivery_date`
- 客户与地区类：`customer_line.delivery_date`

### 1.3 司机归属规则

- 按执行时归属司机统计
- 优先取运单 / 批次上的最终有效司机归属

### 1.4 客户与地区统计粒度

- 按 `customer_line` 统计

### 1.5 地区统计主口径

- 统一挂在 `门店地区`

### 1.6 证据统一口径

核心概念统一为：

- `缺证据运单`

定义：

- 证据状态为 `missing` 或 `partial` 的有效运单

### 1.7 图表下钻规则

- 趋势图点时间点：跳带时间筛选的列表
- 排行图点对象：跳对象详情或对象关联列表
- 分布图点分类：跳该分类筛选后的列表

## 2. 核心指标口径

### 2.1 运单量

- 统计对象：`waybill`
- 定义：统计周期内有效运单数
- 时间基准：`delivery_date`

### 2.2 运单签收率

- 统计对象：`waybill`
- 定义：已签收运单数 / 有效运单数
- 时间基准：`delivery_date`

### 2.3 运单超时率

- 统计对象：`waybill`
- 定义：超时运单数 / 有效运单数
- 时间基准：`delivery_date`
- 超时判定：超过承诺时效仍未完成签收

### 2.4 批次异常率

- 统计对象：`batch`
- 定义：有异常的批次数 / 有效批次数
- 时间基准：批次关联运单的 `delivery_date`

### 2.5 高风险批次

- 统计对象：`batch`
- 定义：按批次风险排序的结果集
- 当前排序规则：
  1. 批次异常率
  2. 严重异常数
  3. 超时运单数

### 2.6 司机月度运单量

- 统计对象：司机归属运单
- 定义：某司机在某自然月关联的有效运单数
- 时间基准：`delivery_date`

### 2.7 司机异常率

- 统计对象：司机归属运单
- 定义：有异常的司机归属运单数 / 司机有效运单数
- 时间基准：`delivery_date`

### 2.8 司机月均异常率

- 统计对象：司机归属运单
- 定义：统计周期内，司机每月异常率的平均值
- 计算方式：`avg(每月有异常运单数 / 每月有效运单数)`
- 时间基准：按自然月

### 2.9 司机签收率

- 统计对象：司机归属运单
- 定义：已签收司机归属运单数 / 司机有效运单数
- 时间基准：`delivery_date`

### 2.10 司机超时率

- 统计对象：司机归属运单
- 定义：超时司机归属运单数 / 司机有效运单数
- 时间基准：`delivery_date`

### 2.11 异常总量

- 统计对象：`exception record`
- 定义：统计周期内异常记录总数
- 时间基准：`report_time`

### 2.12 异常类型分布

- 统计对象：`exception record`
- 定义：各异常类型记录数占比
- 时间基准：`report_time`

### 2.13 异常关闭时长

- 统计对象：已关闭异常记录
- 定义：`close_time - report_time` 的平均值
- 时间基准：`close_time`

### 2.14 缺证据运单

- 统计对象：`waybill`
- 定义：证据状态为 `missing` 或 `partial` 的有效运单
- 时间基准：`delivery_date`

### 2.15 缺证据运单数

- 定义：`count(缺证据运单)`

### 2.16 缺证据率

- 定义：缺证据运单数 / 有效运单数

### 2.17 缺证据对象排行

- 统计对象：按图表维度切换
- 第一版建议支持：
  - 按司机
  - 按批次
- 定义：对象下缺证据运单数排行

### 2.18 客户异常率

- 统计对象：`customer_line`
- 定义：有异常的客户明细数 / 有效客户明细数
- 时间基准：`delivery_date`

### 2.19 地区运单量

- 统计对象：`customer_line`
- 定义：按门店地区统计配送量
- 时间基准：`delivery_date`

### 2.20 地区异常率

- 统计对象：`customer_line`
- 定义：有异常的地区客户明细数 / 有效地区客户明细数
- 时间基准：`delivery_date`

### 2.21 地区签收率

- 统计对象：`customer_line`
- 定义：已签收地区客户明细数 / 有效地区客户明细数
- 时间基准：`delivery_date`

## 3. 当前已冻结结论

1. 客户和地区按 `customer_line` 统计
2. 司机按执行归属统计
3. 超时按“超过承诺时效仍未签收”统计
4. 缺证据统一包含 `missing + partial`
5. 地区主口径挂 `门店地区`
6. 高风险批次排行按：
   1. 批次异常率
   2. 严重异常数
   3. 超时运单数
