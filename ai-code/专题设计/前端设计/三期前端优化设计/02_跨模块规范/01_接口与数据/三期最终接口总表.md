# 三期最终接口总表

适用范围：
- `专题设计/前端设计/三期前端优化设计/` 中需要新增或升级接口支持的页面
- 当前重点包括：司机管理、全局统计图表

当前状态：
- **本文件只负责三期相较前两期的升级补充**
- 一期、二期已稳定的基础接口，继续以前两期资料为准
- 当前如果只想看三期新增什么、哪些页面需要新接口，优先看本文件
- 与二期可承接收尾项相关的导入结果页补充，继续看 `三期接口口径统一与结果页补充说明.md`

---

## 1. 文档定位

这份文档用于回答三期接口层最关键的问题：

1. 前两期哪些接口继续沿用
2. 三期哪些能力必须新增接口
3. 哪些页面只是界面优化，不需要误判成重开一整套接口
4. 三期新增接口优先走 RPC 还是 JSON controller

---

## 2. 前两期与三期的关系

### 2.1 继续复用的接口域

继续复用前两期主接口口径：

- 运单基础列表与详情
- 批次基础列表与详情
- 异常基础列表与详情
- 导入中心链路接口

说明：

- 这些能力在三期仍然有效
- 若只是界面、层级、按钮和文案优化，不默认重开接口

### 2.2 三期明确新增或升级的接口域

三期新增接口主要集中在下面 2 组：

1. 司机管理
2. 全局统计图表

同时补一组继续复用现有路由的收尾项：

3. 导入结果页页面化与接口口径统一

---

## 3. 三期统一升级结论

### 3.1 接口路线口径

- 标准对象列表、详情读取：优先 `RPC`
- 司机画像聚合卡片、趋势图和全局统计图表：优先 `JSON controller`

### 3.2 API 前缀口径

三期新增后台接口统一优先按后台前缀设计：

- `admin`：`/api/admin/logistics/...`

### 3.3 命名口径

- 读取类：`getXxx...`
- 下钻上下文类：`getXxxDrilldown...`

---

## 4. 三期接口升级总表

| 能力 | 前两期状态 | 三期动作 | 推荐路线 |
|---|---|---|---|
| 司机列表页 | 无正式专题接口域 | 新增 | RPC |
| 司机画像详情页 | 无正式专题接口域 | 新增 | JSON controller |
| 司机个人趋势图 | 无 | 新增 | JSON controller |
| 全局统计图表页 | 二期有统计入口，但三期继续扩展 | 新增/升级 | JSON controller |
| 导入结果详情 / 回看页 | 二期有结果查询与页内展示，但未完全页面化 | 复用并扩字段 | JSON controller |
| 三期界面系统化美化 | 无统一设计线 | 当前不默认新开接口 | 视情况而定 |

## 5. 三期核心接口总表

## 5.1 司机管理域

### `getDriverList`

用途：
- 司机列表页主查询

推荐路线：
- RPC

请求参数：
- `keyword`
- `status`
- `has_own_vehicle`
- `vehicle_id`
- `sort_by`
- `sort_order`
- `page`
- `page_size`

核心返回字段：
- `driver_id`
- `driver_name`
- `mobile`
- `status`
- `current_vehicle_label`
- `has_own_vehicle`
- `latest_execution_at`
- `waybill_count`
- `month_avg_exception_rate`

### `getDriverProfileOverview`

用途：
- 司机画像页顶部对象头与执行概览

推荐路线：
- JSON controller

建议路径：
- `GET /api/admin/logistics/drivers/{driver_id}/profile`

核心返回字段：
- 司机基础信息
- 当前所属车辆
- 最近使用车辆
- 执行概览摘要

### `getDriverKpiCards`

用途：
- 司机画像页 KPI 卡片

建议路径：
- `GET /api/admin/logistics/drivers/{driver_id}/kpis`

核心返回字段：
- `month_waybill_count`
- `month_avg_exception_rate`
- `current_month_signed_rate`
- `current_month_timeout_rate`
- `missing_evidence_rate`
- `exception_count`

### `getDriverRiskSummary`

用途：
- 司机画像页风险与异常区

建议路径：
- `GET /api/admin/logistics/drivers/{driver_id}/risk-summary`

核心返回字段：
- `exception_waybill_count`
- `severe_exception_count`
- `timeout_waybill_count`
- `missing_evidence_waybill_count`
- `top_exception_types`

### `getDriverTrendMetrics`

用途：
- 司机画像页个人趋势图

建议路径：
- `GET /api/admin/logistics/drivers/{driver_id}/trends`

核心支持指标：
- `month_waybill_count`
- `exception_rate`
- `signed_rate`
- `timeout_rate`

## 5.2 全局统计图表域

### `getStatsPageOverview`

用途：
- 全局统计图表页首屏总览

推荐路线：
- JSON controller

建议路径：
- `GET /api/admin/logistics/stats/overview`

### `getStatsTrendMetrics`

用途：
- 趋势图与双指标趋势图

建议路径：
- `GET /api/admin/logistics/stats/trends`

核心支持指标：
- `waybill_count`
- `signed_rate`
- `timeout_rate`
- `exception_count`
- `missing_evidence_rate`
- `missing_evidence_waybill_count`

### `getStatsDistributionMetrics`

用途：
- 分布图

建议路径：
- `GET /api/admin/logistics/stats/distributions`

核心支持指标：
- `exception_type_distribution`
- `region_waybill_distribution`

### `getStatsRankingMetrics`

用途：
- 排行图与对比图

建议路径：
- `GET /api/admin/logistics/stats/rankings`

核心支持指标：
- `high_risk_batch_ranking`
- `driver_month_avg_exception_rate_ranking`
- `region_exception_rate_ranking`
- `region_signed_rate_ranking`

### `getStatsDrilldownContext`

用途：
- 图表点击后的下钻筛选上下文

建议路径：
- `POST /api/admin/logistics/stats/drilldown-context`

说明：
- 当前为可选接口
- 如果前端能直接拼装筛选条件，可不单独实现

## 5.3 导入结果补充域

### `getWaybillImportResult`

用途：
- 导入结果页主读取
- 导入结果详情 / 回看页页面化

推荐路线：
- JSON controller

建议路径：
- `GET /api/admin/logistics/imports/waybill-standard/result`

当前处理建议：
- 路由继续沿用二期已落地路径
- 优先扩现有结果查询返回，不建议为结果页另起新路径

建议扩充后的核心返回字段：
- `import_batch_no`
- `status`
- `status_label`
- `template_code`
- `template_version`
- `file_name`
- `total_row_count`
- `passed_row_count`
- `failed_row_count`
- `created_waybill_count`
- `created_customer_line_count`
- `created_goods_line_count`
- `updated_record_count`
- `skipped_record_count`
- `failed_record_count`
- `confirmed_at`
- `finished_at`
- `error_report_url`
- `failure_reason`

### `downloadWaybillImportErrorReport`

用途：
- 结果页错误报告下载

推荐路线：
- file download

建议路径：
- `GET /api/admin/logistics/imports/waybill-standard/error-report`

## 6. 当前不建议误判为“必须新增接口”的事项

下面这些三期改动不默认要求新业务接口：

- 首页顶部栏颜色调整
- 首页右上角按钮区重组
- 列表页字体、行高、按钮样式统一
- 详情页区块留白与标题层级优化
- 导入结果页纯展示层排版优化

说明：

- 这些优先通过前端壳层、样式、组件规则和页面结构承接
- 若后续实现中发现需要环境标识或顶栏配置接口，再补最小接口
- 导入结果页如只做版式和信息重组，优先扩现有结果接口，不重开结果体系
