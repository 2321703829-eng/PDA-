## 目录说明

- `00_导航与总纲/`：放五期总目标、范围、阅读顺序、结论摘要。
- `01_专题方案/`：放导出能力、字段补齐、页面或流程改造等专题设计稿。
- `02_跨模块规范/01_接口与数据/`：放字段映射、导出口径、SQL/DTO/API 约束。
- `02_跨模块规范/02_交互与组件/`：放前端交互、按钮入口、导出结果页规范。
- `02_验收与联调/`：放开发拆分、联调清单、验收清单、口径确认记录。
- `03_模板与样例/`：放 Excel 样表、导出目标样例、字段来源样例。
- `04_来源资料与历史草图/`：放外部来源资料、旧版草图、过程记录。
- `05_提交包/`：放阶段总结、评审摘要、汇报材料。
- `99_待归档/`：放临时文件与待归档材料。
