# 五期模板与样例

本目录存放五期前端优化设计阶段使用的 Excel 样表、目标导出样例与字段核对材料。

## 当前文件分组

### 导出目标样例

- `排线-订单详情_名创+遇见0429.xlsx`
- `排线-门店详情_名创+遇见0429.xlsx`
- `排线-门店货物信息三联单名创+遇见0429.xlsx`

### 参考字段样例

- `商品列表-齐速达修改0427.xlsx`
- `客户信息完整版-齐速达修改0427.xlsx`

## 使用口径

- `0429` 三张表是当前导出能力设计与开发的直接目标样表。
- `0427` 两张表当前不作为五期直接导出目标，但保留为字段扩展与底表覆盖分析参考。
