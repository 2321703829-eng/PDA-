# 企业隔离设计

本目录用于承接企业隔离专题的正式设计资料，是与 `docs/` 主文档体系并行的专题设计包入口。

## 统一命名

- 统一专题名：`企业隔离设计`
- 当前物理目录：`专题设计/企业隔离设计/`

## 专题定位

- 主题：企业隔离、多租户边界与分期落地方案
- 当前阶段：已进入 `P1` 设计收口、差距盘点和开发拆分阶段
- 与主文档体系关系：
  - 当前物流系统主线仍以单套 Odoo 物流能力建设为基线
  - 本目录讨论的是更高一层的平台级企业隔离能力，不应误读为当前一期主线已经全部采用

当前 `P1` 需要默认兼容的业务口径：

- 执行与数据主链：`wave -> batch -> waybill -> customer_line -> order_line -> goods_line`
- 页面主阅读入口：`waybill`
- 页面主阅读链：`waybill -> order_line`
- 图片阅读链：`waybill -> 图片预览 / 留痕 / 证据`
- 导入审计链：`import_source_file -> import_task -> import_task_line -> import_error_line`
- 主数据任务与图片任务应区分 `dispatch_main` 与 `image_package`
- `customer_line` 当前按“一运单一门店”强约束收口为运单下的兼容 / 扩展结构层，不再作为 `P1` 主阅读入口
