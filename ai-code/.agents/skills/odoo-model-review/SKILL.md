# odoo-model-review

## 目的

检查模型设计是否符合当前 Odoo 物流项目约束。

## 使用场景

- 新增模型
- 扩展官方模型
- 设计订单、留痕、异常关系

## 审查步骤

1. 判断该对象应该扩展官方模型还是新建自定义模型
2. 检查字段是否越过一期边界
3. 检查是否需要状态字段
4. 检查是否需要 chatter / 附件 / 活动
5. 检查是否预留了搜索、统计和追溯所需字段
6. 检查是否与现有上下文文档一致

## 检查项

- 模型命名是否清晰
- 是否复用了正确的官方底座
- 是否需要继承 `mail.thread`
- 字段关系是否符合一期边界
- 是否引入了不必要的复杂度
