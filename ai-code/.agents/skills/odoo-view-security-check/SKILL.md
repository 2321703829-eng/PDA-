# odoo-view-security-check

## 通用协作约束

1. 完成编码工作后，默认需要向用户提供详细的人工复核操作流程，除非用户已明确说明“不需要核实”或“不需要复核”。
2. 开启设计文档编写工作前，默认需要先与用户讨论编写思路；未得到用户确认前，不开始正式编写，除非用户已明确说明“不需要讨论”或直接要求开始编写。
3. 每次完成文档编写或编码后，默认需要回扫当前所处阶段对应的设计文档，并对其中已过期、已冲突或已不再符合当前实现/方案的内容进行同步修正，除非用户已明确说明“不需要更改”。
4. 若无法明确当前工作属于哪一期或哪个阶段，在进行上述设计文档回扫和修改前，默认需要先询问用户确认；只有在用户已明确说明无需询问或无需更改时，才可以跳过。

## 目的

检查视图、菜单和权限是否完整。

## 使用场景

- 新增 tree / form / search
- 新增菜单与 action
- 新增或调整权限

## 检查步骤

1. 检查模型是否已定义
2. 检查 `ir.model.access.csv` 是否存在并引用正确模型
3. 检查 tree / form / search 是否都已准备
4. 检查菜单与 action 是否可达
5. 检查角色是否符合一期业务分工
6. 检查验证清单是否需要同步更新

## 检查项

- 视图是否已纳入 manifest
- 菜单和 action 是否可达
- `ir.model.access.csv` 是否齐全
- 是否存在明显越权或缺权
- 列表、表单、搜索是否能支撑业务录入和查询
