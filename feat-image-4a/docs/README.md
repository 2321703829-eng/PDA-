# feat-image-4a Docs

本目录只放 `feat-image-4a` 这条功能线自己的说明文档。

当前文档已经按“先看入口，再看边界，再看验收”的方式收口，便于后续总装和交接。

## 推荐阅读顺序

1. `协作边界说明.md`
   先看这条线负责什么、不负责什么。
2. `接入与验收说明.md`
   再看如何接入 Odoo、如何做正式验收。
3. `当前完成度与下一步清单.md`
   查看当前做到哪里、还差哪些收尾动作。
4. `模块有效性验证方法.md`
   需要逐项核验时，再按这份方法执行。
5. `命名与结构纠偏清单.md`
   需要继续开发或对齐总规范时，再看这份纠偏清单。

## 当前目录说明

- `协作边界说明.md`
  当前唯一的边界口径文档。
- `接入与验收说明.md`
  当前唯一的接入与阶段验收口径文档。
- `当前完成度与下一步清单.md`
  当前状态与后续待办。
- `模块有效性验证方法.md`
  面向模块层面的验证步骤。
- `命名与结构纠偏清单.md`
  记录当前实现与总规范之间的对齐情况。
- `归档说明.md`
  原 `archive/` 文件夹的说明（扁平化后保留）。
- `2026-04-XX-XXX-*.md`
  按日期前缀排序的变更记录（原 `change-notes/` 内容，扁平化后上提到本目录）。

## 执行口径

- 所有代码统一放在 `feat-image-4a/addons/`。
- 所有说明文档统一放在 `feat-image-4a/docs/`。
- `feat-image-4a` 交付的是 Odoo 侧真实可安装、可运行的 addon，不是接口占位目录。
- 后续总装时，把 `feat-image-4a/addons/` 加入 Odoo 的 `addons_path` 即可。
