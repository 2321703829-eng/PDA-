# 最少主数据录入清单

这份清单只面向 `odoo_logistics_prod` 的第一阶段主链联调，不碰当前正在运行的 `logistics_trace_real`。

## 1. 仓库

- 至少 1 个仓库
- 需要补：
  - 仓库名称
  - 仓库代码
  - 联系人
  - 联系电话
  - 运行备注

入口：
- `Logistics Master Data -> Warehouses`

## 2. 司机 / 员工

- 至少 1 个司机
- 需要补：
  - 姓名
  - `logistics_role = driver`
  - 员工编号
  - 工作状态
  - 默认仓库
  - 是否可接单

入口：
- `Logistics Master Data -> Drivers`

## 3. 车辆

- 至少 1 台车辆
- 需要补：
  - 车辆名称
  - 车牌号
  - 司机
  - 所属公司
  - 车辆类型

入口：
- `Logistics Master Data -> Vehicles`

说明：
- 这里直接复用 Odoo 原生 `fleet.vehicle`

## 4. 客户

- 至少 1 个物流客户
- 需要补：
  - 客户名称
  - `is_logistics_customer = True`
  - 客户编码
  - 客户级别
  - 客户状态

入口：
- `Logistics Master Data -> Customers`

## 5. 门店 / 配送点

- 至少 1 个物流门店
- 需要补：
  - 门店名称
  - `is_logistics_store = True`
  - 门店编码
  - 门店状态
  - 地址
  - 经纬度
  - 配送时间窗
  - 是否需要签收
  - 卸货要求

入口：
- `Logistics Master Data -> Stores`

## 6. 第一阶段最小验收组合

建议至少录入这组最小数据：

- 1 个仓库
- 1 个司机
- 1 台车辆
- 1 个客户
- 1 个门店

这样就可以继续往下验证：

- `wave`
- `batch`
- `waybill`
- `waybill_order_line`
- `waybill_stop`

以及后续的：

- `trace_event`
- `evidence`
- 图片上传链
