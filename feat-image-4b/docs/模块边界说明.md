# feat-image-4b 模块边界说明

## 一、定位

`feat-image-4b` 是主业务链补全线，不是图片留痕线的重复拷贝。

## 二、负责内容

### `logistics_base`

负责：

- 基础主数据扩展
- 仓库、门店、司机等基础字段扩展
- 后续主链共享基础能力

### `logistics_dispatch`

负责：

- `wave`
- `batch`
- `waybill`
- `waybill_order_line`
- 调度执行主链关系

## 三、不负责内容

- 图片上传
- 证据文件存储
- 小程序图片上传接口
- 证据预览与下载

这些继续由：

- `logistics_trace_core`
- `logistics_trace_evidence`
- `feat-image-4a`

负责。
