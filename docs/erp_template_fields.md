## 6. 关键业务规则总结

### 6.1 单据编号规则

| 单据类型 | 前缀 | 示例 |
|----------|------|------|
| 采购订单 | CG | CG1002026052500029 |
| 采购入库单 | RK | RK1002026052500001 |
| 采购退货单 | CT | CT1002026052400001 |
| 采购退货出库单 | CC | CC1002026052400001 |
| 销售订单 | XS | XS1002026052500128 |
| 销售出库单 | XC | XC1002026052500389 |
| 销售退货单 | XT | XT1002026052500004 |

### 6.2 多单位体系

商品支持**小/中/大**三个单位:
- **小单位**: 零售最小单位（如: 瓶、袋）
- **中单位**: 组合单位（如: 箱 = 24瓶）
- **大单位**: 批发单位（如: 托 = 60箱）

### 6.3 状态机

```
单据状态: 草稿 → 待审核 → 已审核 → 已执行 → 已完成
```

### 6.4 关联关系

```
采购订单 → 采购入库单 → (采购退货单 → 采购退货出库单)

销售订单 → 销售出库单 → (销售退货单 → 销售退货入库单)
```
