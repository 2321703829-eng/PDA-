# kebi 企业入口收口说明

## 目的

本次调整把 `kebi` 新系统的业务入口收口到 `天枢科技企业系统` 下，避免用户在顶层菜单同时看到原生 Odoo 菜单和企业业务菜单，减少入口混乱。

## 当前入口结构

- 首页
- 基础资料
  - 客户/供应商
  - 商品资料
  - 司机管理
  - 车辆管理
- 订单经营 ERP
  - 销售订单
  - 采购订单
- 仓库作业 WMS
  - 收货任务
  - 出库任务
  - 出入库单
  - 库存查询
- 配送调度 TMS
  - 调度工作台
  - 批次
  - 波次
  - 运单列表
  - 配送节点明细
  - 订单明细
  - 货物明细
  - 派车单
  - 司机任务
  - 导入中心
  - 配送异常
  - 留痕证据
    - 仓库证据
    - 司机证据
    - 证据汇总
- 数据看板 BI
  - 管理看板
  - 统计图表中心

## 隐藏的原生顶层入口

以下原生或旧入口不再作为顶层菜单展示，但底层模型和动作仍保留，供企业菜单调用：

- 物流
- 销售
- 采购
- 库存
- 联系人
- 发票
- 员工
- 车队

`设置` 保留给管理员进行用户、权限、技术参数和系统配置维护。

## 使用说明

日常业务人员只从 `天枢科技企业系统` 进入业务模块。留痕相关入口统一在 `配送调度 TMS > 留痕证据` 下查看，不再作为独立顶层模块出现。
