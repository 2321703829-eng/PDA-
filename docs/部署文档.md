## 三、部署步骤

### 3.1 安装 Docker

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | bash

# 安装 Docker Compose 插件
apt install -y docker-compose-plugin

# 验证
docker --version
docker compose version
```

### 3.2 创建项目目录

```bash
mkdir -p /opt/odoo-lite-test/{config,extra-addons,odoo-data,postgres-data}
cd /opt/odoo-lite-test
```

### 3.3 配置文件

#### 3.3.1 `compose.yaml`

```yaml
services:
  db:
    image: postgres:16-alpine
    container_name: odoo-lite-test-db
    restart: unless-stopped
    environment:
      POSTGRES_USER: odoo
      POSTGRES_PASSWORD: odoo_test_pass_2026
      POSTGRES_DB: postgres
    command:
      - postgres
      - -c
      - shared_buffers=128MB
      - -c
      - effective_cache_size=512MB
      - -c
      - maintenance_work_mem=64MB
      - -c
      - work_mem=4MB
      - -c
      - max_connections=60
    volumes:
      - ./postgres-data:/var/lib/postgresql/data
    healthcheck:
      test: ['CMD-SHELL', 'pg_isready -U odoo -d postgres']
      interval: 10s
      timeout: 5s
      retries: 10

  web:
    image: odoo:18.0
    container_name: odoo-lite-test-web
    restart: unless-stopped
    depends_on:
      db:
        condition: service_healthy
    ports:
      - '18069:8069'
    volumes:
      - ./config/odoo.conf:/etc/odoo/odoo.conf:ro
      - ./odoo-data:/var/lib/odoo
      - ./extra-addons:/mnt/extra-addons
    command: ['odoo', '-c', '/etc/odoo/odoo.conf']
```

#### 3.3.2 `config/odoo.conf`

```ini
[options]
admin_passwd = odoo_master_test_2026
db_host = db
db_port = 5432
db_user = odoo
db_password = odoo_test_pass_2026
db_name = odoo_logistics_prod
dbfilter = ^odoo_logistics_prod$
list_db = False
proxy_mode = True
workers = 0
max_cron_threads = 1
limit_time_cpu = 300
limit_time_real = 600
limit_memory_soft = 1073741824
limit_memory_hard = 1342177280
data_dir = /var/lib/odoo
addons_path = /usr/lib/python3/dist-packages/odoo/addons,/mnt/extra-addons
```

> **配置说明：**
> - `admin_passwd`：Odoo 数据库管理密码（创建/备份/恢复数据库时使用）
> - `dbfilter`：限制只能操作指定数据库，防止误操作
> - `proxy_mode = True`：启用反向代理模式（配合 Caddy/Nginx 使用）
> - `workers = 0`：开发模式单进程，生产环境建议设为 CPU 核数
> - `limit_memory_*`：内存限制（1GB 软限制 / 1.25GB 硬限制）

## 四、Caddy 反向代理配置

文件路径：`/etc/caddy/Caddyfile`

```caddy
# 仓库管理系统（主站）
tianshuchain.cn, www.tianshuchain.cn {
    reverse_proxy 127.0.0.1:18069 {
        header_up Host {host}
    }
}

# 其他业务站点（另一个 Odoo 实例）
hq.tianshuchain.cn, kebi.tianshuchain.cn, template.tianshuchain.cn {
    reverse_proxy 127.0.0.1:19109 {
        header_up Host {host}
    }
}
```

重载配置：

```bash
systemctl reload caddy
```

## 七、常用运维命令

```bash
# === 服务管理 ===

# 启动所有服务
cd /opt/odoo-lite-test && docker compose up -d

# 停止所有服务
cd /opt/odoo-lite-test && docker compose down

# 重启 Odoo
docker restart odoo-lite-test-web

# 查看 Odoo 日志
docker logs odoo-lite-test-web --tail 100 -f

# 查看数据库日志
docker logs odoo-lite-test-db --tail 50

# === 数据库操作 ===

# 进入数据库命令行
docker exec -it odoo-lite-test-db psql -U odoo -d odoo_logistics_prod

# 备份数据库
docker exec odoo-lite-test-db pg_dump -U odoo odoo_logistics_prod > backup_$(date +%Y%m%d).sql

# 恢复数据库
docker exec -i odoo-lite-test-db psql -U odoo -d odoo_logistics_prod < backup.sql

# === Caddy ===

# 重载配置
systemctl reload caddy

# 查看状态
systemctl status caddy

# === frp ===

# 查看状态
systemctl status frps

# 重启
systemctl restart frps
```

## 九、注意事项

1. **端口 8069 vs 18069**：容器内部 Odoo 监听 8069，对外映射为 18069。访问时请用 18069。
2. **proxy_mode**：使用 Caddy/Nginx 反向代理时必须开启 `proxy_mode = True`，否则 Odoo 会生成错误的 URL。
3. **workers**：生产环境建议设为 CPU 核数，当前为 0（开发模式，单进程）。
4. **数据库密码**：`odoo.conf` 和 `compose.yaml` 中的密码需保持一致。
5. **Caddy 自动 HTTPS**：Caddy 会自动申请 Let's Encrypt 证书，无需手动配置。
6. **frp 隧道**：7080 端口依赖 frpc 客户端在线，如果本地服务器关机则隧道断开。
