> 源文件: 安得智联 ERP 管理系统模板

> 说明: 按业务流顺序提取的表结构和示例数据，用于与 odoo-reconstruct 系统做字段级对比

## 业务流程

```
基础档案 → 采购订单 → 采购入库 → 采购退货 → 采购退货出库
    ↓
B2B商城下单 → 销售订单 → 销售出库 → 销售退货 → 销售退货入库
    ↓
财务结算（对账/应收应付）
    ↓
报表分析（采购4张 + 销售6张 + 看板5张）
```
