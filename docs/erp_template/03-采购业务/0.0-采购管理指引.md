# 采购管理指引（截图索引）

> 文件: 采购管理指引.png

## 流程（从截图分析）

1. 新增采购订单 → 选择供应商 → 选择商品 → 填写数量/单价
2. 确认提交 → 系统自动流转
3. 供应商送货 → 采购入库单（收货验收）
4. 入库完成 → 自动更新库存
5. 如有退货 → 采购退货单 → 采购退货出库单
6. 系统监控：智能补货（安全库存触发）

## 关键节点

| 环节 | 状态 | 触发条件 |
|------|------|----------|
| 采购订单创建 | 草稿 | 人工创建 |
| 采购订单提交 | 已提交 | 提交审核 |
| 采购入库 | 已入库 | 收货验收 |
| 采购退货 | 已退货 | 退货原因成立 |
| 智能补货 | 待采购 | 库存 ≤ 安全库存 |
