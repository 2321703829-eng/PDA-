# 仓库移动端服务端接口设计

> 版本: v1.0
> 日期: 2026-06-05
> 说明: 服务端接口设计，终端形态无关（PDA/手机/平板/扫码枪+屏幕均可对接）

---

## 一、设计原则

### 1.1 终端无关性

服务端 API 只关心"数据进出"，不关心终端是什么设备：

```
终端层（可替换）          服务端（稳定）
┌─────────────┐       ┌─────────────────┐
│ PDA 硬件扫码 │       │                 │
│ 手机摄像头   │──HTTP──│  Odoo API       │
│ 平板触屏     │  JSON  │  Controller     │
│ PC+扫码枪    │       │                 │
└─────────────┘       └─────────────────┘
```

### 1.2 接口设计原则

- RESTful 风格，JSON 格式
- 条码作为输入参数，服务端负责解析（商品码/库位码/任务码）
- 幂等性：重复提交不产生副作用
- 分页：列表接口支持 offset/limit
- 错误码统一：`{code, message, data}`

## 三、功能列表（按模块）

### 3.1 认证与基础

| # | 功能 | 说明 |
|---|------|------|
| 1 | 登录 | 账号密码 → 返回 token + 用户信息 + 可用仓库列表 |
| 2 | 切换仓库 | 选择当前操作仓库（后续请求自动带仓库上下文） |
| 3 | 条码解析 | 输入任意条码 → 返回类型（商品/库位/任务/单据）+ 对应记录 |
| 4 | 获取基础配置 | 退货原因列表、库位类型列表等下拉选项 |

### 3.2 入库收货

| # | 功能 | 说明 |
|---|------|------|
| 5 | 查询待收货任务列表 | 当前仓库的 receipt task（按日期排序） |
| 6 | 获取收货任务明细 | 任务下所有 stock.move 行（商品/预期数量/已收数量） |
| 7 | 确认收货行 | 扫商品码 + 输入实收数量 → 回写 move.quantity |
| 8 | 完成收货 | 标记任务完成 → 触发创建上架任务 |

### 3.3 上架作业

| # | 功能 | 说明 |
|---|------|------|
| 9 | 查询待上架任务列表 | 当前仓库的 putaway task |
| 10 | 确认上架（扫库位） | 扫目标库位码 + 确认数量 → 执行库存移动 |
| 11 | 完成上架 | 标记上架完成 |

### 3.4 出库拣货

| # | 功能 | 说明 |
|---|------|------|
| 12 | 查询待拣货任务列表 | 当前仓库的 pick task（按优先级/创建时间） |
| 13 | 获取拣货任务明细 | 所有拣货行（商品/需求数量/库位），按 pick_path_sequence 排序 |
| 14 | 确认拣货行 | 扫商品码 + 扫库位码 + 输入实拣数量 |
| 15 | 完成拣货 | 标记拣货完成 → 触发后续流程（复核/交接） |
| 16 | 查询拣货任务汇总 | 当前任务的进度统计（已拣/未拣/异常） |

### 3.5 退库操作（补货退货）

| # | 功能 | 说明 |
|---|------|------|
| 17 | 创建退库单 | 选择类型（退供应商/退仓） → 创建 inventory.operation |
| 18 | 添加退库行 | 扫商品码 + 输入数量 + 选择原因 |
| 19 | 提交退库单 | 确认提交 → 生成内部 picking |

### 3.6 退货入库（客户退货）

| # | 功能 | 说明 |
|---|------|------|
| 20 | 查询待退货入库任务 | 来源为 sale_return 的 receipt task |
| 21 | 确认退货收货行 | 扫商品码 + 实收数量 + 品质状态 |
| 22 | 完成退货收货 | 标记完成 → 触发上架（按品质分流） |

### 3.7 库存查询

| # | 功能 | 说明 |
|---|------|------|
| 23 | 按商品查库存 | 扫商品码 → 返回各库位数量分布 |
| 24 | 按库位查库存 | 扫库位码 → 返回该库位所有商品及数量 |

## 四、接口交互模式

### 4.1 通用流程模式

所有作业类功能都遵循同一个交互模式：

```
查询任务列表 → 选择/扫描进入 → 逐行确认 → 完成提交
```

### 4.2 状态流转对照

| 业务动作 | WMS 模型状态变化 | 库存影响 |
|----------|-----------------|---------|
| 开始收货 | receipt_task: waiting → receiving | 无 |
| 确认收货行 | stock.move.quantity 更新 | 无（尚未validate） |
| 完成收货 | receipt_task: → received | picking.button_validate() 入库 |
| 确认上架 | putaway_task: → putaway_done | internal move 执行 |
| 确认拣货行 | pick_task_line.done_qty 更新 | 无 |
| 完成拣货 | pick_task: → picked | done_qty → stock.move.quantity |
| 出库完成 | outbound: → task_done | picking.button_validate() 扣减 |
| 提交退库 | inventory.operation: → confirmed | 生成 internal picking |

## 五、数据流向图

```
┌─ 入库链路 ─────────────────────────────────────────────────┐
│                                                            │
│  [查任务] → [逐行扫码确认数量] → [完成收货] → [上架扫库位]  │
│      ↓              ↓                ↓             ↓       │
│  receipt.task   move.quantity    validate()   internal move │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─ 出库链路 ─────────────────────────────────────────────────┐
│                                                            │
│  [查任务] → [按路径拣货] → [扫码确认数量] → [完成拣货]      │
│      ↓           ↓              ↓              ↓           │
│  pick.task   path排序     line.done_qty    validate扣减    │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─ 退库链路 ─────────────────────────────────────────────────┐
│                                                            │
│  [创建退库] → [逐行扫码添加] → [提交]                       │
│       ↓             ↓             ↓                        │
│  operation      add line      生成picking                  │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 六、预留扩展点

为适配不同终端形态和未来功能扩展，预留以下设计余地：

| 扩展点 | 说明 |
|--------|------|
| 条码解析服务 | 统一入口，后续可扩展 RFID、NFC 等输入方式 |
| 推送通知 | 预留 WebSocket/长轮询接口，终端可接收任务推送 |
| 离线队列 | 接口支持批量提交（终端可本地缓存后批量同步） |
| 多语言 | 响应中 message 支持 i18n |
| 图片上传 | 退货/异常时可附带拍照（预留文件上传接口） |
| 语音播报 | 响应中附带 tts_text 字段，终端决定是否播报 |
