# odoo-19.0 文档总览

这一层现在按“先总后分”的方式重新组织了文档目录。

建议阅读顺序是：

1. 先看整体定位和范围
2. 再看业务结构和模块设计
3. 再看数据、接口、索引、事件规范
4. 最后看页面改造、协作分工和专题评估
