# odoo-reconstruct

Odoo 物流留痕系统重构与规划文档仓库。

当前已整理的核心文档放在 [odoo-19.0](odoo-19.0) 目录下，分为两层：

- 根目录文档：重构摘要、范围收缩、商用合规检查原始材料、分工方案
- `doc/` 文档：系统总览、扩展规划、模块重设、商用合规影响评估
