# odoo-reconstruct

Odoo 物流留痕系统重构与规划文档仓库。

当前主文档已经按“先总后分”的方式整理到 [odoo-19.0](odoo-19.0) 目录下。

建议直接从这里开始阅读：

- [odoo-19.0/README.md](odoo-19.0/README.md)

`odoo-19.0` 下面现在按 6 个层次组织：

- `00-总览`：先理解系统定位、边界和总纲
- `01-治理与范围`：范围收缩、商用合规和阶段边界
- `02-业务与模块`：业务流程、模块划分、运单与批次组织
- `03-数据与规范`：表结构、索引、事件、接口和命名规范
- `04-页面与体验`：后台页面和司机端体验改造
- `05-协作与实施`：分工安排、协作边界、实施资料

团队共享 skill 也已经放进仓库：

- `.codex/skills/odoo-logistics-spec-first`

这个 skill 用来约束团队开发流程，核心原则是：

- 设计先行
- 验证先行
- 先 OBB，再规格，再计划，再实现
- 每次改动都要沉淀 Markdown 文档
