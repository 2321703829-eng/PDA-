# image-main-4b 安装验证通过说明

## 一、定位

`image-main-4b` 是在 `feat-image-4a` 之外新增的主链补全工作目录，承接后续正式主业务链对象和基础模块，不再把后续工作继续堆在图片上传子线上。

当前目录下主要包含：

- `logistics_base`
- `logistics_dispatch`
- 配套说明文档

## 二、主要实现内容

### 1. `logistics_base`

负责基础主数据扩展，给后续主链模块提供共享底座。

当前主要覆盖：

- `res.partner` 相关物流基础字段扩展
- `hr.employee` 相关司机/员工字段扩展
- `stock.warehouse` 相关仓库字段扩展

### 2. `logistics_dispatch`

负责正式主业务执行链对象。

当前已包含模型：

- `logistics.dispatch.wave`
- `logistics.dispatch.batch`
- `logistics.dispatch.waybill`
- `logistics.dispatch.waybill.order.line`

承接的业务方向包括：

- 波次组织
- 批次执行
- 运单主对象
- 运单下订单明细
- 批次/运单统计与状态聚合
