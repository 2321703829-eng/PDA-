# image-main-4b 数据库与主链对齐说明

## 一、目标

本功能线的数据库目标，是把当前项目主业务库从“底座 + 留痕证据图片”推进到更完整的正式主链。

目标主链：

`wave -> batch -> waybill -> waybill_order_line -> trace_event -> evidence -> evidence_image`

## 二、当前承接对象

本功能线当前直接承接：

- `logistics.dispatch.wave`
- `logistics.dispatch.batch`
- `logistics.dispatch.waybill`
- `logistics.dispatch.waybill.order.line`

## 三、与现有留痕链关系

- `waybill` 是留痕主对象
- `trace_event` 记录行为事实
- `evidence` 记录证据对象
- `evidence_image` 记录图片元数据

也就是说：

- `image-main-4b` 负责主对象和调度执行层
- `feat-image-4a` 负责留痕证据图片层

## 四、当前原则

- 优先复用 Odoo 原生底座
- 通过正式模块落库，不手工补业务主表
- 外部编号和内部主键分离
- 前端、小程序、后台统一围绕正式主链收口
